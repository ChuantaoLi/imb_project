## 一、研究背景与动机

### 1.1 多类不平衡问题的来源

在现代工业过程中，系统在绝大多数时间里运行在正常工况下，只有在极少数情况下才会出现故障。因此，从分布式控制系统（DCS）中采集到的数据天然呈现出**长尾分布**：

- **多数类（majority class）**：大量正常工况数据
- **少数类（minority classes）**：各类故障数据，数量稀缺

这是典型的**多类不平衡（multi-class imbalance）**问题。

### 1.2 类重叠问题的来源

仅仅解决类别不平衡是不够的，因为工业数据还存在严重的**类重叠（class overlap）**问题：

1. **早期故障与正常数据的相似性**：故障的演变往往是渐进的，早期故障的特征与正常运行状态非常相似。这些早期故障数据恰恰是对系统维护最有价值的数据，但它们却淹没在大量正常样本中。
2. **不同故障类型之间的相关性**：现代工业系统非常复杂，不同类型的故障可能表现出相似的特征，导致不同故障类之间也存在重叠。

### 1.3 不平衡+重叠的耦合效应

现有研究表明，当类别不平衡与类别重叠**同时存在**时，分类器的性能会急剧下降：

- 少数类样本的稀缺使得模型无法充分学习其分布特征，决策边界被多数类主导
- 类别重叠进一步加剧了区分不同类的不确定性
- 有限的信息更难被有效提取和识别

**核心洞见**：类别不平衡并不是导致分类性能下降的唯一因素。真正的性能退化发生在**类别不平衡与其他因素（尤其是类重叠）耦合**时。

### 1.4 现有方法的局限

| 方法类别 | 代表方法 | 局限性 |
|---------|---------|--------|
| 过采样 | SMOTE及其变体（FW-SMOTE, NaNSMOTE, DeepSMOTE, OEGFCM-SMOTE） | 适合解决不平衡，但容易在重叠区域生成噪声样本 |
| 欠采样 | Tomek Link, MGRU, SDCU | 适合解决类重叠，但会丢失大量有用信息 |
| 混合采样 | CDBH, EHSO | 初步尝试同时解决两个问题，但缺乏自适应性 |
| 集成方法 | SPE, MESA, UnderBagging | 利用了不同子集的多样性，但未显式处理重叠区域 |

**研究空白**：现有方法大多只关注类别不平衡，很少有针对性地处理**重叠区域**。虽然一些算法声称对重叠具有鲁棒性，但很少有方法**显式地识别和处理重叠区域**。

## 二、核心贡献与方法概述

### 2.1 主要贡献

1. **提出DEAHS框架**：将动态分层采样与Boosting集成相结合，统一解决类别不平衡与类别重叠的耦合问题。
2. **外层MDP自适应欠采样**：将多数类的采样过程建模为马尔可夫决策过程（MDP），训练智能采样器根据当前分类性能动态调整采样权重，确保多样性。
3. **内层重叠区域识别与加权过采样**：基于隶属度熵（membership entropy）识别重叠区域，利用类间散度矩阵（between-class scatter matrix）指导少数类样本的加权过采样。

### 2.2 整体架构

DEAHS采用**Boosting集成框架**，每轮迭代通过**自适应分层混合采样**生成一个"平衡且分离良好"的训练子集来训练一个新的基分类器：

```
┌─────────────────────────────────────────────────────┐
│                  DEAHS 框架总览                       │
│                                                      │
│  原始不平衡+重叠数据集                                 │
│         │                                            │
│         ▼                                            │
│  ┌──────────────────────────┐                        │
│  │  外层：MDP自适应欠采样     │  ← 解决类别不平衡       │
│  │  (对多数类加权欠采样)      │                        │
│  └──────────┬───────────────┘                        │
│             ▼                                        │
│  ┌──────────────────────────┐                        │
│  │  内层：重叠区域识别与      │  ← 解决类别重叠         │
│  │  加权过采样               │    + 进一步缓解不平衡    │
│  │  1. 隶属度熵划分离                      │
│  │  2. 类间散度矩阵加权过采样 │                        │
│  └──────────┬───────────────┘                        │
│             ▼                                        │
│     平衡且分离良好的子集                               │
│         │                                            │
│         ▼                                            │
│  训练基分类器 → 加入集成                               │
│         │                                            │
│         ▼                                            │
│  (迭代，直至达到指定基分类器数量)                       │
│         │                                            │
│         ▼                                            │
│  最终集成分类器 F_t(x) = (1/t) Σ f_i(x)               │
└─────────────────────────────────────────────────────┘
```

**为什么是Boosting而非Bagging？** Boosting的序贯训练特性使得分类器能够逐步聚焦于"难分样本"，这天然适合处理类重叠问题。

## 三、方法具体实现

### 3.1 问题形式化描述

给定一个多类不平衡数据集 $\mathcal{D}: \{X, y\} = \{x_i, y_i\}_{i=1}^N$，其中 $x_i \in \mathbb{R}^d$。

- $N = \sum_{k=0}^{C-1} n_k$ 为总样本数，$n_k$ 为第 $k$ 类的样本数，$C$ 为总类别数
- **多数类** $\mathcal{M}: \{(x_i, y_i) \mid y_i = 0\}$（正常数据）
- **少数类** $\mathcal{F}: \{(x_i, y_i) \mid y_i = 1, 2, \ldots, C-1\}$（各类故障数据）
- **不平衡率 IR** = $|\mathcal{M}| / |\mathcal{F}|$
- 数据被划分为训练集 $\mathcal{D}_{tr}$、验证集 $\mathcal{D}_{val}$ 和测试集 $\mathcal{D}_{test}$，保持相同的IR

**目标**：学习一个鲁棒的故障分类器 $F: x_i \in \mathbb{R}^d \rightarrow y_i \in \{0, 1, \ldots, C-1\}$，克服不平衡与重叠的耦合挑战。

### 3.2 MDP基础（前置知识）

MDP用五元组描述：

- **状态空间 $S$**：所有可能状态的集合
- **动作空间 $A$**：所有可能动作的集合
- **状态转移概率矩阵 $P$**：在状态 $s$ 执行动作 $a$ 后转移到状态 $s'$ 的概率
- **奖励函数 $R$**：在状态 $s$ 执行动作 $a$ 后获得的即时奖励
- **折扣因子 $\gamma$**：用于计算长期累积奖励

MDP的解是**策略 $\pi$**，是从状态空间到动作空间的映射，表示在每个状态下选择各动作的概率分布：

$$\pi(a \mid s) = p(A_t = a \mid S_t = s) \quad \text{(1)}$$

### 3.3 集成策略

DEAHS采用简单的**平均策略**来融合所有基分类器：

$$F_t(x) = \frac{1}{t}\sum_{i=1}^{t} f_i(x) \quad \text{(2)}$$

其中 $F_t(x)$ 是由 $t$ 个基分类器组成的集成分类器，$f_i(x)$ 表示第 $i$ 个基分类器。

---

### 3.4 外层：基于MDP的自适应欠采样（解决类别不平衡）

#### 3.4.1 核心思想

将多数类的采样过程建模为MDP，训练一个**智能采样器（Sampler）**，使其能够根据当前集成分类器的表现，自主决定下一轮应该选择哪些多数类样本。这类似于一个"强化学习"的过程：采样器是一个Agent，集成训练过程是Environment。

通俗理解：采样器像一个"教练"，观察当前分类器对各类样本的表现（状态），决定下一轮训练集中应该包含哪些多数类样本（动作），如果分类器表现变好就获得奖励。

#### 3.4.2 状态（State）设计

**(a) 交叉熵损失直方图**

对于多数类中的每个样本 $(x_i, y_i)$，其交叉熵损失为：

$$L_{x_i} = -\sum_{k=1}^{C} y_{i,k} \log(F_t(x_i)_k) \quad \text{(3)}$$

将多数类样本集 $\mathcal{M}$ 上所有样本的损失值划分为 $b$ 个区间（bins），构建损失直方图向量 $\hat{L}^{\mathcal{M}} \in \mathbb{R}^b$：

$$\hat{L}^{\mathcal{M}}_j = \frac{\left| \left\{(x_i, y_i) \mid \frac{j-1}{b} \leq L_{x_i} \leq \frac{j}{b}, (x_i, y_i) \in \mathcal{M}\right\} \right| }{|\mathcal{M}|}, \quad 1 \leq j \leq b \quad \text{(4)}$$

**(b) 少数类准确率**

同时记录每个少数类的分类准确率，构成向量 $Acc^{\mathcal{F}} \in \mathbb{R}^{C-1}$。

**(c) 完整状态向量**

将训练集和验证集上的损失直方图与少数类准确率拼接：

$$s_t = [\hat{L}^{\mathcal{M}_{tr}}, \hat{L}^{\mathcal{M}_{val}}, Acc^{\mathcal{F}}] \in \mathbb{R}^{2b + (C-1)} \quad \text{(5)}$$

> **直观理解**：状态向量综合反映了当前模型在多数类（损失分布）和少数类（分类准确率）上的表现，使采样器能全面感知环境。

#### 3.4.3 动作（Action）设计

采样器输出高斯函数的参数——均值 $\mu_t$ 和标准差 $\sigma_t$：

$$a_t = [\mu_t, \sigma_t] \quad \text{(6)}$$

> **为什么用高斯函数？** 高斯函数具有良好的平滑性和可控性：均值控制权重分布的中心位置，标准差控制分布的宽度。

#### 3.4.4 采样权重分配

根据采样器输出的参数，使用高斯分布和均匀分布的混合来为每个多数类样本分配采样权重：

$$\omega_{\mu_t, \sigma_t}(x_i, y_i) = \alpha \cdot \frac{1}{\sigma_t\sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{L_{x_i} - \mu_t}{\sigma_t}\right)^2} + (1 - \alpha) \cdot \frac{1}{|\mathcal{M}|}, \quad (x_i, y_i) \in \mathcal{M} \quad \text{(8)}$$

其中 $\alpha = 0.95$ 为混合权重，控制"聚焦采样"（高斯分量）与"探索采样"（均匀分量）之间的平衡。

> **设计巧妙之处**：
> - **$\mu_t$ 的作用**：控制对哪些难度的样本更感兴趣。$\mu_t$ 较小时，优先选择上一轮分类错误较小的样本（帮助巩固已有知识）；$\mu_t$ 较大时，优先选择上一轮分类错误较大的样本（攻克难点）。
> - **$\sigma_t$ 的作用**：控制采样的集中程度。$\sigma_t$ 较小时，只采样错误值非常接近 $\mu_t$ 的样本，子集更"专注"；$\sigma_t$ 较大时，采样范围更广，子集更多样化。
> - **$\alpha = 0.95$**：保留5%的随机探索，避免采样策略过于贪心而陷入局部最优。

#### 3.4.5 奖励（Reward）设计

奖励定义为：在验证集上执行动作后，分类指标加权变化量：

$$r_t = \sum_{i=1}^{M} \lambda_i \cdot [M_i(F_{t+1}, \text{val}) - M_i(F_t, \text{val})] \quad \text{(7)}$$

其中 $\lambda_i$ 为第 $i$ 个指标的权重，$\sum \lambda_i = 1$；$M_i(\cdot)$ 表示第 $i$ 个评价指标的值。

> **直观理解**：如果采取动作后模型在验证集上变好了，就给正奖励；变差了就给负奖励。

#### 3.4.6 训练方法

使用**SAC（Soft Actor-Critic）**强化学习算法来训练自适应欠采样器，学习最优策略 $\pi: S \rightarrow A$。

**为什么选择SAC？**
- SAC是Off-policy算法，可以复用历史经验，样本效率高
- SAC的最大熵框架天然鼓励探索，有助于避免陷入局部最优策略
- SAC在连续动作空间上表现优异，正好适合输出高斯参数

### 3.5 内层：重叠区域识别与加权过采样（解决类别重叠）

外层采样后，数据不平衡得到缓解，但仍存在两个问题：(1) 类别重叠仍然存在；(2) 残留的不平衡。内层的任务就是解决这些问题。

#### 3.5.1 基于隶属度熵的区域划分

**步骤一：计算隶属度（Membership Degree）**

隶属度表示样本属于某个类的概率，范围在 $[0, 1]$ 之间，且一个样本对所有类的隶属度之和为1。

样本 $x_i$ 对类别 $j$ 的隶属度定义为：

$$m_i^j = \frac{1}{\sum_{k=1}^{C}\left(\frac{d_i^j}{d_i^k}\right)^{\frac{2}{n-1}}} \quad \text{(9)}$$

其中 $d_i^j$ 表示 $x_i$ 到类别 $j$ 中心向量的距离，$n$ 是模糊化参数（通常设为2）。

> **直观理解**：如果 $x_i$ 离A类中心近、远离B类和C类中心，那么它对A的隶属度就高。如果 $x_i$ 到三个类中心的距离差不多，那么它对三个类的隶属度也差不多。

**步骤二：计算隶属度熵（Membership Entropy）**

隶属度熵衡量样本隶属度在各分类上的不确定性：

$$H(x_i) = -\sum_{k=1}^{C} m_i^k \log m_i^k \quad \text{(10)}$$

- **熵高**：样本在各类上的隶属度比较平均，说明该样本处于类边界或重叠区域（分类不确定）
- **熵低**：样本对某个类有明显的高隶属度，说明该样本在安全区（容易分类）

> **类比**：想象三个重叠的圆形区域。圆心的点显然属于该圆，隶属度熵低；三个圆交叉处的点到三个圆心距离差不多，隶属度熵高。

**步骤三：区域划分**

设定隶属度熵阈值 $T_{ov} = \mu_H + \sigma_H$（即所有样本隶属度熵的均值加一个标准差），将数据集划分：

- **重叠区域** $\mathcal{D}_{ov}$：$H(x_i) > T_{ov}$ 的样本（分类困难的样本）
- **安全区域** $\mathcal{D}_{safe}$：$H(x_i) \leq T_{ov}$ 的样本（分类容易的样本）

$$\mathcal{D}_{safe} = \mathcal{D} - \mathcal{D}_{ov} \quad \text{(12)}$$

> **为什么用均值+标准差？** 这是一种自适应的阈值选择方式：不同数据集的熵分布不同，使用相对阈值可以自动适应不同的数据分布，而不需要人工调参。

#### 3.5.2 基于类间散度的加权过采样

**安全区域**：直接使用经典SMOTE方法对少数类进行过采样。

**重叠区域**：基于每个少数类样本对**类间散度矩阵**的贡献进行加权过采样。

**步骤一：计算类间散度矩阵**

$$\mathbf{S}_B = \sum_{k=1}^{C} n_k (\boldsymbol{\mu}_k - \boldsymbol{\mu})(\boldsymbol{\mu}_k - \boldsymbol{\mu})^T \quad \text{(13)}$$

其中 $\boldsymbol{\mu}_k$ 是第 $k$ 类的均值向量，$\boldsymbol{\mu}$ 是所有样本的总体均值向量。

> **直观理解**：$\mathbf{S}_B$ 衡量的是各类中心相对于全局中心的散布程度。类间散度越大，说明不同类的中心离得越远，分类越容易。

**步骤二：计算每个样本对类间散度的贡献**

对于属于类别 $j$ 的样本 $x_i$，其对类间散度的贡献 $\alpha_i$ 定义为：

$$\alpha_i = (x_i - \boldsymbol{\mu}_j)^T \mathbf{S}_B (x_i - \boldsymbol{\mu}_j) \quad \text{(14)}$$

> **直观理解**：$\alpha_i$ 是将"样本到其类中心的偏移"投影到类间散度矩阵上得到的值。$\alpha_i$ 越大，说明该样本在"有利于区分不同类别的方向"上偏离其类中心越远，即该样本对类间区分更重要。在重叠区域中，这些样本恰好是那些处于边界、对分类器决策边界影响最大的样本。

**步骤三：计算过采样权重**

$$\omega_{x_i} = \frac{\alpha_i}{\sum_{x_j \in \mathcal{F}} \alpha_j} \quad \text{(15)}$$

> **核心思想**：在重叠区域中，对类间散度贡献大的少数类样本获得更高权重（被合成更多的SMOTE样本），从而增强类别可分离性。

### 3.6 算法完整流程（Algorithm 1 中文伪代码解析）

```
算法1: DEAHS训练过程

输入: 不平衡且重叠的数据集 D, 基分类器 f, 基分类器数量 m,
      直方图区间数 b, 神经网络自适应欠采样器 AUSampler(·)
输出: 集成分类器 F_m

1.  将 D 划分为训练集 D_tr、验证集 D_val 和测试集 D_test
    [保持相同的IR分布]

2.  将 D_tr 划分为多数类 M 和少数类 F

3.  用随机平衡子集训练第一个基分类器 f_1
    [第一个分类器采用简单的随机平衡策略启动]

4.  for t = 1, 2, ..., m do:
        [开始逐轮Boosting迭代]

5.      当前集成分类器 F_t(x) = (1/t) Σ_{i=1}^t f_i(x)
        [对所有已训练的基分类器进行平均]

6.      根据公式(5)获取当前状态 s_t
        [计算多数类的交叉熵直方图 + 少数类准确率]

7.      获取训练好的自适应欠采样器，输出 μ_t 和 σ_t
        [通过SAC训练的Agent根据当前状态决策]

8.      根据公式(8)对 M 进行加权欠采样，得到 M'
        [以高斯混合分布为权重抽样多数类样本]

9.      获得相对平衡的子集 M' ∪ F

10.     根据公式(11)(12)将子集划分为安全区域 D_safe 和重叠区域 D_ov
        [基于隶属度熵 + 自适应阈值]

11.     根据公式(13)计算类间散度矩阵 S_B

12.     if F 中的 x_i 属于 D_ov then
13.         根据公式(14)(15)计算样本权重并进行加权过采样
            [在重叠区，优先合成对类间区分贡献大的样本]
14.     else if F 中的 x_i 属于 D_safe then
15.         使用标准SMOTE方法进行过采样
            [在安全区，普通SMOTE即可]
16.     end if

17.     合并 F 与重叠区和安全区的过采样样本，得到 F'
        [F' 现在既平衡又分离良好]

18.     获得平衡子集 M' ∪ F'

19.     用该子集训练新的基分类器 f_{t+1}

20. end for

21. 获得最终集成分类器 F_m
```

### 3.7 复杂度分析

**空间复杂度**：$O(Nd + TM + h(d + C))$

- $O(Nd)$：存储特征矩阵
- $O(h(d+C))$：SAC智能Agent的网络参数（$h$ 为隐藏层维度）
- $O(TM)$：存储 $T$ 个基分类器

**时间复杂度**：$O(I \cdot (Nd^2 + T \cdot f(N, d)))$

- $O(NC)$：状态计算（计算交叉熵损失和准确率）
- $O(N)$：外层采样
- $O(NC^2)$：计算隶属度
- $O(Nd^2)$：计算类间散度矩阵
- $T \cdot f(N, d)$：训练 $T$ 个基分类器
- $I$：自适应迭代次数

因为工业故障数据集中类别数 $C$ 通常远小于样本数 $N$ 和特征维度 $d$，所以总时间复杂度简化为 $O(I \cdot (Nd^2 + T \cdot f(N, d)))$。

**局限性**：对特征维度 $d$ 存在二次依赖，高维数据场景下可能需要先降维。

## 四、实验结果与分析

### 4.1 实验设置

#### 评价指标

论文使用了四个适合不平衡分类的评价指标（公式(16)-(19)）：

$$BA = \frac{1}{n}\sum_{i=1}^{n} Recall_i \quad \text{(16)}$$

$$G\text{-}mean = \sqrt[n]{\prod_{i=1}^{n} Recall_i} \quad \text{(17)}$$

$$F1_{macro} = \frac{1}{n}\sum_{i=1}^{n} F1_i \quad \text{(18)}$$

$$F1_{micro} = 2 \times \frac{Precision_{micro} \cdot Recall_{micro}}{Precision_{micro} + Recall_{micro}} \quad \text{(19)}$$

> **为什么不用Accuracy？** 在不平衡数据上，Accuracy具有欺骗性——即使把所有样本都预测为多数类，也能获得很高的准确率。BA、G-mean和F1_macro对每个类别平均对待，能更好地反映模型对少数类的识别能力。

#### 重叠率（Overlap Ratio, OR）量化指标

论文还定义了衡量类别重叠程度的指标：

$$OR_k = \frac{n_k^{ov}}{n_k}, \quad OR_{(i,j)} = \frac{1}{2}\left(\frac{n_{i,j}^{ov}}{n_i} + \frac{n_{j,i}^{ov}}{n_j}\right), \quad OR_{dataset} = \frac{1}{C}\sum_{k=1}^{C} OR_k \quad \text{(20)}$$

#### 对比方法（5种）

| 方法 | 类型 | 入选原因 |
|------|------|---------|
| **SPE** [36] | 自步集成 | 通过分类难度度量自适应采样，适合处理类重叠和大规模不平衡 |
| **DBCF** [33] | 深度级联+混合采样 | 数据层与算法层结合的改进，适用于复杂工业故障分类 |
| **WGAN-GP** [39] | GAN生成模型 | 生成高保真多样本，适合数据稀缺和类重叠场景 |
| **DDPM** [40] | 扩散生成模型 | 逐步加噪去噪生成高质量数据，有效缓解边界重叠 |
| **DeepSMOTE** [24] | 深度编码器+SMOTE | 在深度特征空间中进行SMOTE，适合高维不平衡数据 |

**基分类器选择**：Random Forest (RF)。选择RF而不是更复杂的深度学习模型，体现了框架的**分类器解耦性**——自适应分层采样策略仅依赖数据分布特征，不依赖特定分类器的结构。

**基分类器数量**：默认为20（在敏感性分析中验证了这一选择的合理性）。

**定性分析**：热力图显示，内层采样后各类之间的重叠像素颜色明显变浅，说明类别可分离性显著增强。

#### 噪声鲁棒性分析

引入三种噪声（高斯噪声、周期噪声、椒盐噪声），各设4个强度级别（5%/10%/15%/20%），在Group 1上测试：

- DEAHS在各类噪声和强度下表现稳定，特别是在周期噪声和高斯噪声下几乎不受影响
- 椒盐噪声（模拟传感器突变失效）对模型影响最大，但DEAHS仍能有效缓解
- 鲁棒性来源于：外层动态调整采样权重 + 内层精确识别处理重叠区域

#### 消融实验（Ablation Study）

在Line A上进行三组消融实验，每次移除不同的组件：

| 配置 | 描述 | BA (%) | G-mean (%) | F1_macro (%) | F1_micro (%) |
|------|------|--------|------------|-------------|-------------|
| Ablation 1 | 全随机欠采样（移除内外层） | 73.75 | 70.83 | 70.86 | 86.66 |
| Ablation 2 | 仅外层MDP欠采样（移除内层） | 82.71 | 79.73 | 79.16 | 91.00 |
| Ablation 3 | 仅内层过采样（外层用随机代替） | 91.05 | 95.12 | 87.95 | 94.68 |
| **DEAHS** | 完整框架 | **94.24** | **96.86** | **91.62** | **96.20** |

**深度分析**：

- **Ablation 1 → Ablation 2**（增加外层MDP欠采样）：前三个关注不平衡的指标显著提升，说明外层MDP自适应欠采样有效缓解了正常样本对故障样本的负面影响
- **Ablation 2 → Ablation 3**（增加内层重叠处理）：所有四个指标都有大幅提升，说明内层对重叠区域的精确识别和加权过采样有效增强了类别可分离性
- **Ablation 3 → DEAHS**（内外层协同）：性能进一步提升，说明两个组件的协同作用优于单独使用

> **最重要结论**：消融实验证实了论文的核心论点——**类别不平衡不是分类性能下降的唯一甚至主要原因，类别不平衡与类别重叠的耦合才是更大的挑战。**

#### 敏感性分析

**基分类器数量**：从3递增到50
- 从个位数增加到10时性能显著提升
- 10→30略有提升
- 超过30后出现轻微下降（可能过拟合）
- **建议值**：10-20（精度与效率的平衡点）

**不平衡率（IR）**：5:1 / 10:1 / 20:1 / 30:1 / 50:1
- BA、G-mean、F1_macro随IR增大略有下降（正常，因为不平衡更严重）
- F1_micro几乎不变（因为整体样本量足够大）
- DEAHS能有效处理各种IR的数据集
- **再次验证**：仅增加IR不是性能下降的主要原因，类重叠才是

## 五、总结与展望

### 5.1 方法论总结

DEAHS框架的核心创新在于**分层、自适应、协同**：

| 层级 | 解决的问题 | 技术方法 | 关键创新点 |
|------|-----------|---------|-----------|
| 外层 | 类别不平衡 | MDP建模+SAC训练的智能欠采样器 | 根据分类表现动态调整采样策略，确保子集多样性 |
| 内层 | 类别重叠+残留不平衡 | 隶属度熵划区+类间散度加权过采样 | 自适应阈值识别重叠，优先增强边界样本 |

### 5.2 论文局限性

1. **特征空间限制**：采样和重叠区域识别均在原始特征空间进行，未充分增强特征表示。在高度复杂的工业场景中可能受限。
2. **缺乏增量学习机制**：无法适应数据分布的动态变化，对数据漂移敏感。

### 5.3 未来工作方向

1. **改进特征表示**：在原始特征空间之外，探索更深层次的特征提取
2. **迁移学习**：利用迁移学习应对数据漂移问题
3. **增量模型更新**：开发在线实时处理的增量学习机制
