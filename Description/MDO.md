## 一、研究背景与动机

### 1.1 类别不平衡问题

在现实世界的许多应用中，数据集中不同类别的样本数量往往是不相等的。这种数据分布的不均衡被称为**类别不平衡问题（Class Imbalance Problem）**。在一个不平衡的数据集中，某些类别（多数类）拥有大量样本，而另一些类别（少数类）只有极少的样本。

对于典型的机器学习算法而言，这种偏态分布会带来严重的困难：分类器倾向于将所有样本预测为多数类，从而导致少数类样本被错误分类。正如论文中所指出的，学习的核心目标是**在不严重损害多数类分类精度的前提下，提高少数类的分类精度**。

### 1.2 多类不平衡问题的特殊挑战

相比于二分类不平衡问题，多类不平衡问题面临更多的挑战：

- **决策边界更复杂**：多个类别之间的决策边界更难学习。
- **类别重叠更严重**：不同类别区域之间的重叠是多类问题中普遍存在的严重问题。
- **现有方法效果不佳**：Zhou 和 Liu 的研究表明，几乎所有技术对二分类问题都有效，但大多数技术在多分类任务上效果不佳，甚至可能产生负面影响。

### 1.3 为什么欧氏距离不够好？

传统的过采样方法（如 SMOTE）基于**欧氏距离（Euclidean Distance）**来度量样本之间的相似性。然而，欧氏距离有一个关键的局限性：

**欧氏距离假设数据在各个方向上的变异是等同的**。在数学上，所有与原点的欧氏距离为常数 $c$ 的观测点满足：

$$x_1^2 + x_2^2 + \cdots + x_d^2 = c^2$$

这是一个**球面（spheroid）**方程——它意味着所有维度对距离的贡献是相等的。

但在实际数据中，不同特征的变异程度（方差）通常是不同的，而且特征之间还存在相关性。欧氏距离忽视了这些统计特性，因此它无法准确反映数据的真实分布结构。

**直观类比**：想象一张橡胶片，上面印有一个圆形。如果你沿着某个方向拉伸这张橡胶片，圆形会变成椭圆形。在这个拉伸后的空间中，"真正的距离"应该考虑拉伸的程度——沿着拉伸方向，"实际距离"比看起来要大。欧氏距离就像用一把固定刻度的尺子去测量这张被拉伸的橡胶片，而马氏距离则像一把能随橡胶片变形而自适应调整的尺子。

### 1.4 "概率轮廓"与数据形状

论文中提出了一个重要的概念：**概率轮廓（Probability Contours）**。

在马氏距离的视角下，具有相同马氏距离的点构成的是一个**椭球面（ellipsoid）**，而不是欧氏距离下的球面。这个椭球面的形状由数据的协方差结构决定：

- 椭球面的**主轴方向**反映了特征之间的相关性（协方差）
- 椭球面的**轴长**反映了每个方向上的变异程度（方差）

因此，沿着概率轮廓（即等马氏距离的椭球面）生成合成样本，意味着新样本保持了原始少数类的协方差结构，即保持了数据的"形状"。这种生成方式使合成样本更自然地融入少数类的分布区域，而不是随意地散布在特征空间中。

### 1.5 类别重叠问题

论文特别强调了类别重叠（Overlapping）的危害："类别不平衡本身似乎并不成问题，但当与高度重叠的类别结合时，它会显著减少被正确分类的少数类样本数量。"

大多数现有的过采样技术仅根据特征空间中的相似性来生成合成样本，或者使用边界样本进行过采样。在多类情况下，这些做法会增加不同类别区域之间的重叠概率，反而恶化了学习算法的处境。

MDO 的核心动机正是：**在保持少数类协方差结构的同时，在数据密集区域生成合成样本，从而减少类间重叠的风险。**

## 二、核心贡献与方法概述

### 2.1 主要贡献

1. **提出了一种新的过采样技术 MDO**：基于马氏距离（Mahalanobis distance），专为多类不平衡问题设计。

2. **保持协方差结构**：通过沿概率轮廓生成合成样本，MDO 保留了少数类的协方差结构，使合成样本更好地代表原始数据分布。

3. **减少类间重叠**：MDO 选择位于该类数据密集区域的样本进行过采样，有效减少了不同类别区域之间的重叠风险。

4. **分类器无关**：MDO 是一种数据层面的预处理方法，可以独立于分类器使用。

5. **全面的实验验证**：在 20 个多类不平衡基准数据集上，使用 3 种不同的分类器进行实验，与 4 种主流过采样方法对比，在 MAUC 和 Precision 指标上取得了统计显著的优势。

### 2.2 方法总览

MDO 的核心思想可以概括为：

> **生成与对应类别均值具有相同马氏距离的合成样本。**

具体来说，MDO 的整体流程如下：

1. **样本选择**：从少数类中选择位于密集区域的样本（即周围有较多同类近邻的样本）。
2. **数据中心化**：将选中的少数类样本减去其类均值，使数据中心化到原点。
3. **PCA 变换**：通过特征值分解，将数据变换到主成分空间，使各维度之间不相关。
4. **合成样本生成**：在主成分空间中，沿椭球方程生成新的合成样本。
5. **逆变换**：将生成的合成样本变换回原始空间，并加上类均值。

论文用一幅框图（Fig. 2）展示了这一流程，包括：选择候选样本 → 归一化 → 映射到 PC 空间 → 生成合成样本 → 变换回原始空间 → 加上类均值。

## 三、方法具体实现

### 3.1 马氏距离的定义与直观理解

#### 3.1.1 数学定义

对于一个 $d$ 维向量 $\mathbf{x} = (x_1, x_2, \ldots, x_d)^T$，它与均值为 $\boldsymbol{\mu} = (\mu_1, \mu_2, \ldots, \mu_d)^T$、协方差矩阵为 $\mathbf{S}$ 的分布之间的马氏距离定义为：

$$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^T \mathbf{S}^{-1} (\mathbf{x} - \boldsymbol{\mu})}$$

如果协方差矩阵是单位矩阵（即 $\mathbf{S} = \mathbf{I}$），马氏距离退化为欧氏距离：

$$D_E(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^T (\mathbf{x} - \boldsymbol{\mu})}$$

#### 3.1.2 为什么马氏距离能"感知"数据形状？

要理解马氏距离，可以从欧氏距离的标准化推广来看。

假设我们首先对数据进行标准化：将每个分量除以其标准差，得到 $\mathbf{u} = (\frac{x_1}{\sigma_1}, \ldots, \frac{x_d}{\sigma_d})$。那么两个标准化后向量的欧氏距离为：

$$D(\mathbf{x}, \mathbf{y}) = \sqrt{\left(\frac{x_1 - y_1}{\sigma_1}\right)^2 + \cdots + \left(\frac{x_d - y_d}{\sigma_d}\right)^2} = \sqrt{(\mathbf{x} - \mathbf{y})^T \mathbf{S}^{-1} (\mathbf{x} - \mathbf{y})}$$

其中 $\mathbf{S} = \text{diag}(\sigma_1^2, \ldots, \sigma_d^2)$。此时，与原点的距离为常数的点满足：

$$\left(\frac{x_1}{\sigma_1}\right)^2 + \cdots + \left(\frac{x_d}{\sigma_d}\right)^2 = c^2$$

这是**以坐标轴为主轴的椭球方程**。

但仅考虑方差还不够——特征之间可能存在**相关性**。当特征之间有相关性时，数据点形成的"云团"不仅是椭圆形的，而且是**旋转的**——即椭球的主轴不再与坐标轴对齐。

马氏距离通过协方差矩阵的逆 $\mathbf{S}^{-1}$ 来同时处理方差和相关性，使得等距离面成为一个**可以任意旋转的椭球**，其形状恰好反映了数据的协方差结构。

#### 3.1.3 直观类比

- **欧氏距离**：就像在一个均匀的空间中测量直线距离，无论方向如何，"一米就是一米"。这相当于假设数据在所有方向上以相同程度"展开"。
- **马氏距离**：就像在一個被不均匀拉伸的橡胶片上测量距离。在高度拉伸的方向上，两个点之间可能比看起来"更近"（因为该方向的变异大，偏离均值在该方向上并不那么异常）；在未拉伸的方向上，两个点可能比看起来"更远"。马氏距离以标准差为单位来衡量距离——它与数据的"概率轮廓"对齐。

### 3.2 马氏距离与 PCA 的关系

马氏距离与主成分分析（PCA）有着深刻的数学联系。PCA 的核心步骤是对协方差矩阵进行特征值分解：

$$\mathbf{S} = \mathbf{U} \boldsymbol{\Lambda} \mathbf{U}^T$$

其中：
- $\mathbf{U}$ 是特征向量矩阵（正交矩阵，$\mathbf{U}^T\mathbf{U} = \mathbf{I}$），每一列是一个主成分方向
- $\boldsymbol{\Lambda} = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_d)$ 是特征值对角矩阵，$\lambda_i$ 表示第 $i$ 个主成分方向上的方差

可以将马氏距离的平方重写为：

$$D_M^2(\mathbf{x}) = (\mathbf{x} - \boldsymbol{\mu})^T \mathbf{S}^{-1} (\mathbf{x} - \boldsymbol{\mu}) = (\mathbf{x} - \boldsymbol{\mu})^T \mathbf{U} \boldsymbol{\Lambda}^{-1} \mathbf{U}^T (\mathbf{x} - \boldsymbol{\mu})$$

令 $\mathbf{z} = \mathbf{U}^T (\mathbf{x} - \boldsymbol{\mu})$，即经过中心化和旋转后的坐标（PC 空间中的坐标），则：

$$D_M^2(\mathbf{x}) = \mathbf{z}^T \boldsymbol{\Lambda}^{-1} \mathbf{z} = \frac{z_1^2}{\lambda_1} + \frac{z_2^2}{\lambda_2} + \cdots + \frac{z_d^2}{\lambda_d}$$

在 PC 空间中，各维度是**不相关**的，且第 $i$ 维的方差恰好是 $\lambda_i$。因此，等马氏距离方程变为：

$$\frac{z_1^2}{\lambda_1} + \frac{z_2^2}{\lambda_2} + \cdots + \frac{z_d^2}{\lambda_d} = c^2$$

这正是一个**以坐标轴为主轴、半轴长分别为 $c\sqrt{\lambda_i}$ 的椭球方程**。

**关键洞察**：PCA 变换将这个问题大大简化了——在原始空间中，等马氏距离面是一个任意旋转的椭球；在 PC 空间中，它变成了一个轴对齐的椭球。这使得合成样本的生成变得简单而高效。

### 3.3 PCA 变换过程详解

在 MDO 的算法 1（Algorithm 1）中，步骤 8-13 详细描述了 PCA 变换的过程：

**步骤 1：计算类均值（Step 9）**

$$\boldsymbol{\mu}_i = \frac{1}{n_i} \sum_{j=1}^{n_i} \mathbf{x}_j^i$$

**步骤 2：中心化（Step 10）**

将每个样本减去类均值，使数据变为零均值：

$$\tilde{\mathbf{x}}_j^i = \mathbf{x}_j^i - \boldsymbol{\mu}_i$$

**步骤 3：特征值分解（Step 11）**

计算协方差矩阵 $\mathbf{S}_i = \frac{1}{n_i} \mathbf{Z}_i^T \mathbf{Z}_i$，并进行特征值分解，得到特征向量矩阵 $\mathbf{U}_i$ 和特征值对角矩阵 $\boldsymbol{\Lambda}_i$。

**步骤 4：变换到 PC 空间（Step 12）**

$$\mathbf{T}_i = \mathbf{Z}_i \mathbf{U}_i$$

在 PC 空间中，各维度之间是不相关的，每个维度的方差等于对应的特征值。

**步骤 5：获取方差系数向量（Step 13）**

$$\mathbf{V} = \text{diag}(\text{covariance}(\mathbf{T}_i)) = (\lambda_1, \lambda_2, \ldots, \lambda_d)^T$$

这里需要注意：经过 PCA 变换后，协方差矩阵是对角矩阵，对角线上的元素就是各主成分的方差（即特征值 $\lambda_j$）。

### 3.4 椭球方程与合成样本生成

#### 3.4.1 从二维椭圆到 d 维椭球

在二维空间中，以 $(h, k)$ 为中心的椭圆满足方程：

$$\frac{(x - h)^2}{a^2} + \frac{(y - k)^2}{b^2} = 1$$

推广到 $d$ 维空间，以原点为中心的椭球（超椭球）方程为：

$$\frac{x_1^2}{a_1^2} + \frac{x_2^2}{a_2^2} + \cdots + \frac{x_i^2}{a_i^2} + \cdots + \frac{x_d^2}{a_d^2} = 1$$

#### 3.4.2 用方差参数化椭球方程

在 MDO 中，$a_i$（椭球的"半径"系数）被替换为 $\alpha \cdot V_i$，其中 $V_i$ 是第 $i$ 维的方差，$\alpha$ 是一个全局缩放参数。这给出了 MDO 的核心生成方程：

$$\frac{x_1^2}{\alpha V_1} + \frac{x_2^2}{\alpha V_2} + \cdots + \frac{x_i^2}{\alpha V_i} + \cdots + \frac{x_d^2}{\alpha V_d} = 1$$

这个方程的含义是：
- **$V_i$（方差）**：决定了椭球在第 $i$ 维方向上的"基础形状"——大方差意味着该方向上的数据更分散，椭球在该方向上的轴更长。
- **$\alpha$（缩放参数）**：控制椭球的整体大小——$\alpha$ 越大，椭球越大，生成的合成样本离类均值越远。
- **在 PC 空间中**，$V_i = \lambda_i$（第 $i$ 个特征值）。

#### 3.4.3 确定 α 的值

给定一个现有的少数类样本 $\mathbf{x}_{\text{temp}}$，我们希望生成的合成样本与它有相同的马氏距离。由于 $\mathbf{x}_{\text{temp}}$ 满足椭球方程：

$$\frac{x_{\text{temp},1}^2}{\alpha V_1} + \frac{x_{\text{temp},2}^2}{\alpha V_2} + \cdots + \frac{x_{\text{temp},d}^2}{\alpha V_d} = 1$$

可以解出 $\alpha$：

$$\alpha = \sum_{j=1}^{d} \frac{x_{\text{temp},j}^2}{V_j}$$

这等价于 $\alpha = D_M^2(\mathbf{x}_{\text{temp}})$（在 PC 空间中，$\mathbf{S} = \boldsymbol{\Lambda}$，$\mathbf{S}^{-1} = \text{diag}(1/\lambda_1, \ldots, 1/\lambda_d)$）。

#### 3.4.4 生成合成样本的过程（Algorithm 3 详解）

MDO 使用以下步骤在 PC 空间中生成一个合成样本：

**Step 1**：根据权重分布 `weights_i` 随机选择一个样本 $\mathbf{x}_{\text{temp}}$。

**Step 2**：计算 $\mathbf{x}_{\text{temp}}$ 的平方值（元素级）：$\mathbf{X} = \mathbf{x}_{\text{temp}}^2$。

**Step 3**：计算 $\alpha$（从椭球方程）：

$$\alpha = \sum_{j=1}^{d} \frac{X_j}{V_j}$$

**Step 4**：计算 $\boldsymbol{\alpha}_V = \alpha \cdot \mathbf{V} = (\alpha V_1, \alpha V_2, \ldots, \alpha V_d)^T$。这些值是椭球方程中各维度的分母，即 $\alpha_V(j)$ 是第 $j$ 维的"最大平方值"（椭球在第 $j$ 维的半轴长的平方）。

**Step 5**：对前 $d-1$ 个维度，随机生成新样本的值：

对于 $j = 1, 2, \ldots, d-1$：
$$r \sim \text{Uniform}\left(-\sqrt{\alpha_V(j)},\; +\sqrt{\alpha_V(j)}\right)$$
$$x_{\text{new}, j} = r$$

这里 $r$ 在第 $j$ 维的合法区间 $[-\sqrt{\alpha V_j}, +\sqrt{\alpha V_j}]$ 中均匀随机选取。

**Step 6**：计算前 $d-1$ 维的累积和：

$$s = \sum_{j=1}^{d-1} \frac{x_{\text{new}, j}^2}{\alpha_V(j)}$$

**Step 7**：通过椭球方程求解最后一维的值：

由于总方程必须满足 $\sum_{j=1}^{d} \frac{x_{\text{new}, j}^2}{\alpha_V(j)} = 1$，而前 $d-1$ 维已经贡献了 $s$，所以：

$$\frac{x_{\text{new}, d}^2}{\alpha_V(d)} = 1 - s$$

$$x_{\text{new}, d} = \pm \sqrt{\alpha_V(d) \cdot (1 - s)}$$

**Step 8**：随机选择最后一维的符号，从 $\{+\text{LastFeaVal}, -\text{LastFeaVal}\}$ 中等概率选取。

**Step 9**：将生成的合成样本加入集合 $S_{\text{temp}}$。

**Step 10**：重复上述过程，直到生成所需数量（$O_{\text{rate}, i}$）的合成样本。

#### 3.4.5 为什么要这样生成？

这个生成过程保证了：
1. **新样本与原始样本具有相同的马氏距离**（因为它们满足相同的椭球方程）
2. **新样本位于原始数据的概率轮廓上**（沿椭球面生成）
3. **新样本的协方差结构与原始数据一致**（椭球形状由协方差矩阵决定）
4. **新的合成样本具有一定的随机多样性**（前 $d-1$ 维随机选取，最后一维由方程约束）

### 3.5 样本选择策略（Algorithm 2 详解）

不是所有少数类样本都适合用于过采样。MDO 通过 `chooseSamples` 函数精心选择用于生成合成样本的"种子"样本。

#### 算法流程（中文解释）

**输入**：整个数据集 $S$ 和考虑的少数类样本集 $S_{\text{minor}, i}$

**输出**：被选中的样本集 $SC_{\text{minor}, i}$ 及其对应的选择权重 `weights_i`

**步骤说明**：

1. 对于 $S_{\text{minor}, i}$ 中的每一个样本 $\mathbf{x}_j$：
   - 计算 $\mathbf{x}_j$ 与数据集中**所有**样本（不仅仅是少数类）的欧氏距离
   - 找出 $\mathbf{x}_j$ 的 $K_2$ 个最近邻（论文中 $K_2 = 10$）
   - 统计这些近邻中有多少个样本与 $\mathbf{x}_j$ 属于同一类别，记为 `num`
   - 如果 `num` ≥ $K_1$（论文中 $K_1 = 5$），则：
     - 将 $\mathbf{x}_j$ 加入被选中的样本集 $SC_{\text{minor}, i}$
     - 赋予 $\mathbf{x}_j$ 一个权重：$w_j = \frac{\text{num}}{K_2}$

2. 对所有选中的样本的权重进行归一化，使其成为一个概率分布（权重之和为 1）。

**直观理解**：如果一个少数类样本周围有很多同类样本（即在 $K_2$ 个最近邻中至少有 $K_1$ 个是同类），说明它位于该类的**密集区域**，远离决策边界。在这样的位置生成合成样本，更不容易"入侵"到其他类的区域，从而减少类间重叠。

### 3.6 完整算法总结

下面以中文伪代码形式给出 MDO 的完整流程：

---

**算法 1：MDO 过采样技术**

```
输入: 数据集 S = {(x₁,y₁), ..., (xₘ,yₘ)}, 多数类样本数 n_maj
输出: 平衡后的数据集

1.  t = 少数类的数量
2.  S_New = 空集  （存放所有新生成的合成样本）
3.  对于每个少数类 i = 1 到 t:
4.      S_minor_i = 类别 i 的所有样本
5.      
6.      [SC_minor_i, weights_i] = chooseSamples(S, S_minor_i)
        // 选择位于密集区域的高质量少数类样本及其权重
7.      
8.      n_i = SC_minor_i 中的样本数
9.      μ_i = (1/n_i) * Σ xⱼⁱ  // 计算类均值
10.     Z_i = {xⱼⁱ - μ_i}  // 中心化：所有样本减去均值
11.     对 Z_i 进行特征值分解，获得主成分
12.     T_i = Z_i 变换到 PC 空间  // 使各维度不相关
13.     V = diag(covariance(T_i))  // 各维度方差的向量
14.     O_rate_i = n_maj - n_i  // 需要生成的合成样本数量
15.     S_temp = MDO-oversampling(T_i, V, O_rate_i)
        // 在 PC 空间中生成合成样本
16.     将 S_temp 中的合成样本变换回原始空间
17.     将类均值 μ_i 加回合成样本
18.     将新样本加入 S_New
19. 结束循环
20. 返回平衡后的数据集 S ∪ S_New
```

---

**算法 2：chooseSamples 函数 — 选择高质量样本**

```
输入: 整个数据集 S, 考虑的少数类样本集 S_minor_i
输出: 被选中的样本集 SC_minor_i 及其权重 weights_i

1.  m_i = S_minor_i 中的样本数
2.  对于 j = 1 到 m_i:
3.      Xⱼ = S_minor_i 中的第 j 个样本
4.      对于 k = 1 到 m (数据集中所有样本):
5.          计算 Xⱼ 与 Xₖ 的欧氏距离
6.      找出 Xⱼ 的 K₂ 个最近邻
7.      num = 这些近邻中与 Xⱼ 同类的样本数
8.      如果 num ≥ K₁:
9.          将 Xⱼ 加入 SC_minor_i
            // 该样本位于密集区域，适合用于过采样
10.         weights(j) = num / K₂  // 权重为同类近邻的比例
11. 结束循环
12. 归一化 weights，使其成为一个概率分布（总和为 1）
13. 返回 SC_minor_i 和 weights_i
```

---

**算法 3：MDO-oversampling 函数 — 在 PC 空间中生成合成样本**

```
输入: PC 空间中的样本 T_i, 方差向量 V, 过采样率 O_rate_i
输出: 合成样本集 S_temp

1.  Num_attrs = 数据维度 d
2.  当 O_rate_i ≠ 0 时循环:
3.      根据权重分布 weights_i 从 T_i 中随机选择一个样本 X_temp
4.      X = X_temp 的逐元素平方
5.      从椭球方程 Σ(Xⱼ/(α·Vⱼ)) = 1 计算 α
        // 即 α = Σ(Xⱼ/Vⱼ)
6.      AlphaV = α · V  // 得到各维度的分母向量
7.      s = 0
8.      对于 j = 1 到 Num_attrs - 1:  // 前 d-1 维
9.          r = 从 [-√AlphaV(j), +√AlphaV(j)] 中均匀随机选取
10.         X_new(j) = r
11.         s = s + r²/AlphaV(j)
12.     结束循环
13.     求解最后一维:
        LastFeaVal = √(AlphaV(last) · (1 - s))
14.     X_new(last) = 随机选择 +LastFeaVal 或 -LastFeaVal
15.     将 X_new 加入 S_temp
16.     O_rate_i = O_rate_i - 1
17. 结束循环
18. 返回合成样本集 S_temp
```

### 3.8 计算复杂度分析

MDO 算法中最耗时的部分是特征值分解（Eigenvalue Decomposition），其理论上界为 $O(n^3)$。但论文指出：

- 实际中，Demmel 等人已证明标准线性代数运算可以在 $O(n^{\omega + \eta})$ 的复杂度内稳定完成（其中 $\omega$ 是矩阵乘法指数，$\eta > 0$ 为任意小的正数）。
- 由于输入数据的维度通常不高，特征值分解可以快速完成。
- 每个合成样本的生成需要解两次形式为方程 (4) 的计算：第一次是求解 $\alpha$（线性方程），第二次是求解最后一维的特征值（含一次平方根运算），都可以在 $O(n^{\omega + \eta})$ 内完成。

### 4.2 对比方法

MDO 与以下四种主流过采样方法进行了对比：

1. **随机过采样（ROS, Random Over-Sampling）**：随机复制少数类样本
2. **SMOTE**：经典的合成少数类过采样技术，基于样本间的线性插值
3. **Borderline-SMOTE**：仅对边界样本进行 SMOTE 过采样
4. **ADASYN**：自适应合成采样，根据数据分布自动决定每个样本的合成数量

### 4.3 分类器

使用了三种不同的基分类器（均在 Weka 中实现）：

1. **C4.5 决策树**：使用信息增益作为分裂准则
2. **RIPPER**：基于规则的算法（Repeated Incremental Pruning to Produce Error Reduction）
3. **KNN（K=5）**：基于实例的惰性学习算法

### 4.4 评估指标

论文使用了以下评估指标：

**单类指标（针对少数类）**：

- **精确率（Precision）**：$\text{Precision} = \frac{TP}{TP + FP}$
  衡量分类器预测为某类的样本中真正属于该类的比例。

- **召回率（Recall）**：$\text{Recall} = \frac{TP}{TP + FN}$
  衡量某类中所有真实样本被正确找出的比例。

- **F-measure**：$F\text{-measure} = \frac{(1 + \beta^2) \cdot \text{Recall} \cdot \text{Precision}}{\beta^2 \cdot \text{Recall} + \text{Precision}}$
  精确率与召回率的调和平均（$\beta = 1$）。

**多类指标**：

- **G-mean（扩展版）**：$ \text{G-mean} = \left(\prod_{i=1}^{c} \text{Recall}_i\right)^{1/c} $
  所有类别召回率的几何平均数。如果任何一个类别的召回率为 0，G-mean 就变为 0。

- **MAUC（M-measure）**：$ \text{MAUC} = \frac{2}{c(c-1)} \sum_{i < j} \frac{A(i, j) + A(j, i)}{2} $
  所有类别对之间 AUC 的平均值。其中 $A(i, j)$ 是类 $i$ 对类 $j$ 的 AUC。需要注意，在多类场景下 $A(i, j)$ 和 $A(j, i)$ 可能不相等，因此两者都需要考虑。

### 4.5 主要实验结果

论文使用 **Friedman 检验**（非参数统计检验）+ **Bonferroni-Dunn post-hoc 检验**来评估结果的统计显著性。以下按分类器和评估指标总结：

#### 使用 C4.5 分类器时：

- **MAUC**：MDO 排名第 1（平均排名 1.175），显著优于 ROS、Borderline-SMOTE 和 ADASYN
- **Precision**：MDO 排名第 1（平均排名 1.725），显著优于所有对比方法
- **G-mean**：MDO 排名第 1（平均排名 1.950），显著优于 Borderline-SMOTE 和 ADASYN
- **F-measure**：MDO 排名第 1（平均排名 1.900），显著优于 Borderline-SMOTE 和 ADASYN
- **Recall**：MDO 排名第 1（平均排名 2.025），显著优于 Borderline-SMOTE

#### 使用 KNN 分类器时：

- **MAUC**：MDO 排名第 1（平均排名 1.200），显著优于所有对比方法
- **Precision**：MDO 排名第 1（平均排名 1.400），显著优于所有对比方法
- **G-mean**：MDO 排名第 1（平均排名 2.100），显著优于 Borderline-SMOTE 和 ADASYN
- **F-measure**：MDO 排名第 1（平均排名 1.900），显著优于 ROS、Borderline-SMOTE 和 ADASYN

#### 使用 RIPPER 分类器时：

- **MAUC**：MDO 排名第 1（平均排名 1.200），显著优于 ROS、Borderline-SMOTE 和 ADASYN
- **Precision**：MDO 排名第 1（平均排名 1.450），显著优于所有对比方法
- **F-measure**：MDO 排名第 1（平均排名 1.600），显著优于 ROS、ADASYN 和 Borderline-SMOTE
- **G-mean**：MDO 排名第 1（平均排名 2.100），显著优于 Borderline-SMOTE 和 ADASYN
- **Recall**：MDO 排名第 1（平均排名 2.100），显著优于 Borderline-SMOTE

#### 核心结论

1. **MDO 在 Precision 指标上全面碾压**：在所有三种分类器下，MDO 在 Precision 上都显著优于所有对比方法。这是因为 MDO 生成的合成样本更好地建模了少数类的分布，减少了过拟合和过泛化。

2. **MDO 在 MAUC 指标上表现突出**：MAUC 衡量的是分类器区分任意类别对的能力。MDO 通过减少类间重叠，使分类器能更好地分离不同类别。

3. **KNN 和 RIPPER 是 MDO 的最佳搭配分类器**：MDO 与这两种分类器配合使用时，在 MAUC 和 Precision 上取得了统计显著的优势。

4. **SMOTE 类方法加剧了类间重叠**：通过人工数据可视化（Fig. 5），论文清楚地展示了 SMOTE、Borderline-SMOTE 和 ADASYN 生成的合成样本侵入了其他类别的决策区域，而 MDO 的合成样本保持在各自类别内部。

### 4.6 MDO 为何有效——深入分析

MDO 的优势源于以下几点：

1. **保持协方差结构**：通过沿概率轮廓生成样本，合成样本保持了原始少数类的协方差结构，使生成的数据与原始数据在统计特性上一致。

2. **在密集区域生成样本**：通过 `chooseSamples` 函数选择周围有足够多同类近邻的样本作为种子，确保合成样本生成在该类别的"安全区域"，而非边界区域。

3. **减少类间重叠**：综上两点，MDO 避免了合成样本"溢出"到其他类别的区域，从而改善了学习算法的处境。在其他过采样方法中，合成样本往往产生在不合适的区域，增加了类别之间的重叠，反而使分类任务更加困难。

4. **更好的泛化能力**：MDO 生成的合成样本覆盖了少数类的更广泛区域（沿概率轮廓），为分类器提供了比简单的线性插值更丰富的信息，从而提高了分类器的泛化能力。

## 五、局限性与未来工作

论文在结论部分指出了 MDO 的一些局限性和未来改进方向：

1. **高维数据的效率问题**：当数据维度很高时，MDO 为不同维度选取合适的随机数可能需要较长时间。未来可以通过特征选择预处理来减少维度，只从最具信息量的特征子集中生成合成样本。

2. **对非数值属性的支持**：论文所用的数据集都是数值型的。未来需要研究如何将 MDO 扩展到名义属性（nominal）和混合类型（数值/名义）的数据集。

3. **其他距离度量的探索**：可以尝试使用其他距离度量（如 Hellinger 距离）来进行过采样，可能取得更优的结果。Hellinger 距离在不平衡问题上展示了有利的性质。

4. **与 OAA/OAO 策略的结合**：需要进一步研究 MDO 与其他二分类过采样方法在 One-vs-All（OAA）和 One-vs-One（OAO）策略下的性能对比。
