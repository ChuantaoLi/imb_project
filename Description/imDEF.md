## 一、研究背景与动机

### 1.1 类别不平衡问题

在现实世界的分类任务中，经常会出现**类别不平衡（Class Imbalance）**问题：某些类别（多数类，Majority Classes）的样本数量远超其他类别（少数类，Minority Classes）的样本数量。例如：

- 疾病诊断中，患病人数远少于健康人数
- 缺陷检测中，有缺陷的产品远少于正常产品
- 欺诈检测中，欺诈交易远少于正常交易

类别不平衡问题通常还会与**数据复杂性因素**（如类别重叠、噪声样本等）纠缠在一起，使得学习任务更加困难。标准的分类算法通常以整体准确率为优化目标，会自然地偏向多数类，导致少数类样本被大量误分类。然而在实际应用中，正确识别少数类样本往往才是关键需求。

### 1.2 动态集成 vs 静态集成

在不平衡学习领域，**集成学习（Ensemble Learning）**被认为是最有效的方法类型之一。现有的集成方案可分为两大类：

- **静态集成（Static Ensemble）**：始终使用所有基分类器（Component Classifier）对测试样本进行投票预测。它的决策逻辑是：做出正确预测的基分类器必须在投票权重中占多数。然而，在类别不平衡场景下，基分类器天然偏向多数类，导致少数类样本可能只能被少数基分类器正确分类，静态集成很难修正这种偏差。

- **动态集成（Dynamic Ensemble）**：首先估计每个基分类器在当前测试样本上的"胜任水平（Competent Level）"，然后只选择最胜任的那些分类器进行预测。动态集成的优势在于：只要存在至少一个基分类器能够正确预测测试样本，就有可能产生正确的集体决策。因此，动态集成在面对不平衡数据时具有**显著更大的潜力**。

然而，现实情况是：**动态集成方法在不平衡学习领域的表现远不如静态集成方法**，几乎没有可信的证据表明动态集成方案优于静态集成方案。

### 1.3 动态集成的行为特征分析（五大观察）

为了探究动态集成表现不佳的原因，作者进行了全面的行为特征分析。他们将测试样本按照"正分类器比例"（Positive Classifier Proportion，即能够正确预测该样本的基分类器占分类器池的比例 $p(x_i)$）划分为五个片段：

- $Te_1$: $0 \leq p(x_i) \leq 0.15$
- $Te_2$: $0.15 < p(x_i) \leq 0.3$
- $Te_3$: $0.3 < p(x_i) \leq 0.5$
- $Te_4$: $0.5 < p(x_i) \leq 0.7$
- $Te_5$: $0.7 < p(x_i) \leq 1$

通过分析不同片段上的统计量，作者得出以下**五个关键观察**：

**观察一（过估计问题）**：现有动态集成方案通常将训练数据本身作为DSEL（Dynamic Selection Data，即用来定义测试样本的胜任区域RoC的数据集）。但这不可避免地导致基分类器胜任水平的高估（Overestimation），因为同样的样本既被用于训练基分类器，又被用于评估它们的胜任水平。

**观察二（偏差问题）**：少数类样本更多分布在低正分类器比例的片段中（$Pmin_s > Pmaj_s$，当 $s \leq 4$ 时）。这表明少数类样本更容易被误分类，基分类器对多数类存在偏倚。

**观察三（难度关联）**：正分类器比例越低的样本，其 $Nmin_s$ 和 $Nmaj_s$（基于k-近邻的难度度量）越高，即这些样本具有更高的学习难度。

**观察四（胜任力冲突问题，Competence Conflict）**：现有的动态选择技术（DST）可能会给"负分类器"（错误预测的基分类器）分配比"正分类器"（正确预测的基分类器）更高的胜任水平，尤其是对于困难样本。这是因为困难样本的RoC（通常由k近邻定义）往往被相反类别的样本主导——基分类器只要正确分类了RoC中的大多数样本，即使误分类了测试样本本身，也能获得高的胜任评分。

**观察五（误分类风险）**：正分类器比例越低的样本，其被误分类的可能性越高（$Emaj_s$ 和 $Emin_s$ 均随 $s$ 减小而增大）。原因有二：(1) 这些样本需要更精确的胜任力估计，小的估计误差就可能导致错误的集体决策；(2) DST可能因胜任力冲突问题恶化对困难样本的分类。

### 1.4 五大改进方向

基于以上观察，作者提出了提升动态集成性能的**五大着力点**：

| 问题 | 描述 | 来源 |
|------|------|------|
| **Problem i** | 缓解胜任水平的高估问题 | 观察一 |
| **Problem ii** | 处理不平衡的类别分布，纠正分类器池对多数类的偏倚 | 观察二 |
| **Problem iii** | 在训练基分类器时加强对困难样本的学习，增加其正分类器比例 | 观察三、五 |
| **Problem iv** | 避免胜任力冲突问题 | 观察四 |
| **Problem v** | 为难以分类的样本（低正分类器比例的样本）提供可靠的胜任力估计 | 观察五 |

### 1.5 现有方法的局限

传统动态集成方案主要通过三种改进来应对类别不平衡：
1. 使用不平衡静态集成方法生成低偏倚的分类器池（应对Problem ii）
2. 使用重采样技术平衡DSEL（使少数类在RoC中更频繁出现）
3. 设计对偏斜不敏感的DST

然而，**Problem i、iii、iv、v 至今未被解决**，严重削弱了动态集成在不平衡学习中的表现。

## 二、核心贡献与方法

### 2.1 主要贡献

1. **深度行为分析**：首次深入分析了动态集成在处理不平衡数据时的分类行为特征，挖掘出若干提升动态集成方案的着力点。

2. **OREM_G 数据生成**：使用数据生成方法 OREM_G 从原始训练数据创建多个人工合成数据集，这些数据集具有不同的类别分布（通过减少多数类样本、增加少数类样本来逐步改变分布），从而纠正分类器池对多数类的偏倚（解决 Problem ii）。同时，使用合成数据（而非原始数据）训练基分类器，可以缓解胜任水平的高估问题（解决 Problem i）。

3. **SPSE_CE 分类器池构建**：设计了**分类错误感知的自步采样集成方法（Classification Error-aware Self-Paced Sampling Ensemble, SPSE_CE）**，基于每个合成数据集创建基分类器。SPSE_CE 通过自步学习过程逐步加强对高难度样本的学习，增加困难样本的正分类器数量（解决 Problem iii）。

4. **裁判系统（Referee System）**：为每个基分类器构建一个"裁判委员会"来完成胜任力估计，而非使用传统的基于邻域的方法（避免 Problem iv）。设计了**集成间隔感知的自步采样集成方法（Ensemble Margin-aware Self-Paced Sampling Ensemble, SPSE_EM）**来构建裁判系统，逐步聚焦于具有大负集成间隔的样本，从而为困难样本提供更精确的胜任力估计（解决 Problem v）。

5. **全面的实验验证**：在30个二分类和18个多分类不平衡数据集上验证了 imDEF 的有效性。

## 三、方法具体实现

### 3.1 算法1：imDEF 主算法

**输入**：
- $Tr = [X_{tr}, Y_{tr}] = \{(x_i, y_i)\}_{i=1}^{|Tr|}$：训练数据，$y_i \in L$（$L$ 为类别集合）
- $Te$：测试数据
- $n$：基分类器数量
- $q$：OREM_G 的参数
- $\alpha_1, \alpha_2, b, \beta$：自步采样集成的参数

**输出**：测试数据的预测结果

**算法伪代码及中文解释**：

```
1.  for r ← 1 to ⌊√n⌋ do
2.      使用公式(1)获取第r个合成数据集的类别分布 dp_r
3.      生成合成数据集: Tr_r ← OREM_G(Tr, dp_r, q)
4.      计算该数据集上的分类器数量:
        n_r ← (r ≤ n - ⌊√n⌋×⌊n/⌊√n⌋⌋) ? ⌊n/⌊√n⌋⌋ + 1 : ⌊n/⌊√n⌋⌋
5.      创建分类器集合: P_r ← SPSE_CE(Tr_r, n_r, α₁, b)
6.      P ← P ∪ P_r
7.  end for
8.  获取所有基分类器的胜任力标签:
    CL ← isequal(predict(P, Xtr), Ytr)
9.  构建裁判系统: RS ← SPSE_EM(Xtr, Ytr, CL, α₂, b, β)
10. for all x ∈ Te do
11.     for all C_t ∈ P do
12.         使用 C_t 及对应的裁判委员会 RC_t 预测 x
13.     end for
14.     使用公式(13)获得 x 的最终预测结果
15. end for
```

**各行详解**：

- **第1-7行（分类器池生成）**：循环 $\lfloor\sqrt{n}\rfloor$ 次，每次生成一个具有不同类别分布的合成数据集，然后基于该数据集用一个 SPSE_CE 集成创建约 $n/\lfloor\sqrt{n}\rfloor$ 个基分类器。所有分类器集合合并成大小为 $n$ 的分类器池 $P$。

- **第4行**：这是一个C语言风格的三元运算符。作用是尽可能均匀地将 $n$ 个分类器分配到 $\lfloor\sqrt{n}\rfloor$ 个数据集中——前几个数据集分配 $\lfloor n/\lfloor\sqrt{n}\rfloor\rfloor + 1$ 个分类器，其余分配 $\lfloor n/\lfloor\sqrt{n}\rfloor\rfloor$ 个。

- **第8行**：在训练数据上运行分类器池 $P$，将预测结果与真实标签 $Y_{tr}$ 比较，得到每个基分类器在每个训练样本上的"胜任力标签"（0表示预测错误，1表示预测正确）。

- **第9行**：SPSE_EM 基于训练数据和胜任力标签构建裁判系统。裁判系统从纵向看由多个"世代裁判集体"（Generational Referee Collective）组成，从横向看由 $n$ 个"裁判委员会"（Referee Committee）组成，每个裁判委员会专门为一个基分类器提供胜任力估计。

- **第10-15行（动态预测）**：对每个测试样本 $x$，每个基分类器 $C_t$ 给出预测，其对应的裁判委员会 $RC_t$ 给出胜任力估计。最终结果是所有基分类器预测的加权组合。

### 3.2 分类器池的生成

与传统动态集成直接使用原始训练数据构建 $n$ 个基分类器不同，imDEF 首先生成 $\lfloor\sqrt{n}\rfloor$ 个具有不同类别分布的人工合成数据集，然后在每个合成数据集上运行 SPSE_CE。

#### 3.2.1 类别分布的计算

第 $r$ 个合成数据集的类别分布由公式(1)确定（$r = 1, 2, ..., \lfloor\sqrt{n}\rfloor$）：

$$dp_r = \text{normalization}(dp \circ cf_r) = \left(\frac{p_1 \cdot cf_r}{\sum_{j=1}^{|L|} p_j \cdot cf_r}, \frac{p_2 \cdot cf_r}{\sum_{j=1}^{|L|} p_j \cdot cf_r}, ..., \frac{p_{|L|} \cdot cf_r}{\sum_{j=1}^{|L|} p_j \cdot cf_r}\right) \tag{1}$$

其中 $p_j$ 是类别 $l_j$ 在原始训练数据中的样本比例，$cf_r$ 是类别分布的调整因子。

**直观理解**：$dp$ 是原始数据中各类别的比例向量，$cf_r$ 是一个缩放因子（对多数类起缩小作用、对少数类起放大作用，或反过来），两者逐元素相乘后再归一化，得到目标合成数据集的类别分布。

调整因子 $cf_r$ 由公式(2)更新：

$$cf_r = 1 - \frac{2 \times (r - 1)}{\lfloor\sqrt{n}\rfloor - 1} \tag{2}$$

**直观理解**：随着 $r$ 从 $1$ 增加到 $\lfloor\sqrt{n}\rfloor$，$cf_r$ 从 $1$ 线性下降到 $-1$。
- 当 $cf_r = 1$（$r = 1$）时：维持原始类别分布
- 当 $cf_r = 0$（$r = (\lfloor\sqrt{n}\rfloor+1)/2$）时：各类别等比例（平衡分布）
- 当 $cf_r = -1$（$r = \lfloor\sqrt{n}\rfloor$）时：原始多数类被转化为少数类，原始少数类被转化为多数类（分布反转）

这意味着：随着 $r$ 增大，合成数据集中原始多数类的样本越来越少，原始少数类的样本越来越多，多数类逐渐变为实际上的"弱类"，少数类逐渐变为实际上的"强类"。

#### 3.2.2 这种方式的优势

1. **缓解高估问题（Problem i）**：基分类器使用合成数据训练，而非原始训练数据；裁判系统使用原始数据学习胜任区域。训练数据和胜任力评估数据被分离，避免了"既当运动员又当裁判"。

2. **纠正偏倚（Problem ii）**：所有合成数据集上各类别的平均比例接近相等，因此生成的分类器池对多数类的偏倚较低。

3. **增加多样性**：不同合成数据集中"强势类别"及其主导程度不同，这鼓励了各个 SPSE_CE 集成之间的多样性，有助于为来自任何类别的测试样本创建一定数量的正分类器。

4. **聚焦困难样本（Problem iii）**：SPSE_CE 使基分类器逐步更加关注困难样本。

### 3.3 OREM_G：可靠的插值数据生成方法

#### 3.3.1 设计目标

合成数据需要服从原始训练数据的底层分布，这样才能使构建的基分类器泛化到原始分类任务。一个合格的数据生成方法应当：
- 产生**多样化的合成样本**，充分覆盖原始数据的代表性样本
- 尽可能**减少噪声样本**的生成

OREM_G 是一种**插值式数据生成方法**——合成样本是两个原始样本之间的插值点。它先根据 $dp_r$ 计算每个类别需要生成的合成样本数量，然后应用过采样方法 OREM 为每个类别生成合成样本。

#### 3.3.2 OREM 的三步生成过程

对于类别 $l$ 中的任意样本 $x_i$，OREM 通过以下三步生成合成样本：

**第一步：找到候选辅助种子集 $C(x_i)$**

$C(x_i)$ 由 $x_i$ 的 $p$ 近邻（p-nearest neighbors）组成，其中 $p$ 是满足以下条件的最小值：$x_i$ 随后的 $q$ 个近邻（即 $x_i^{(p+1)}, x_i^{(p+2)}, ..., x_i^{(p+q)}$）全部不是来自类别 $l$。

这一步的目的是探索 $x_i$ 附近的**候选生成区域（Candidate Generation Region, CGR）**。这种CGR可能是类别重叠区域，也可能是类别 $l$ 的纯净区域。

**直观类比**：想象以 $x_i$ 为中心，逐渐扩大搜索半径。一开始（小半径内）可能会找到同类别样本；当半径扩大到某个程度后，连续 $q$ 个邻居都是其他类别的样本，说明已经超出了类别 $l$ 的"势力范围"。取这个临界半径内的区域作为CGR——它最大化了同类别样本的覆盖范围，但又不会过度侵入其他类别的领地。

**第二步：识别可靠辅助种子 $A(x_i)$**

从 $C(x_i)$ 中进一步筛选可靠辅助种子。判断规则为：如果 $C(x_i)$ 中的某样本与 $x_i$ 之间的超球体区域不包含任何其他类别的样本，则该样本被视为可靠辅助种子。

这一步旨在发现 $x_i$ 的 CGR 内的**纯净子区域（Clean Subregions）**，并用它们来放置类别 $l$ 的合成样本。纯净子区域中出现非 $l$ 类测试样本的概率很低。

**第三步：生成合成样本**

每个合成样本是 $x_i$ 与其某个辅助种子之间的随机插值点：
$$\text{synthetic sample} = x_i + \lambda \cdot (a - x_i)$$

其中 $a \in A(x_i)$ 是任意一个辅助种子，$\lambda \in [0, 1]$ 是随机插值系数。

#### 3.3.3 OREM 的优势

与传统插值方法（如SMOTE，辅助种子通常是同类的k近邻）相比：

- **更多样性**：OREM的辅助种子集可以包含不同类别的样本，且大小可变，可以打破"合成样本只能位于同类别原始样本形成的凸包内"的限制。

- **更少噪声**：OREM只在CGR内的纯净子区域生成合成样本，有效防止合成样本落入有争议的区域（如类别重叠区），从而减少噪声样本的生成。

### 3.4 SPSE_CE：分类错误感知的自步采样集成

#### 3.4.1 算法2：SPSE_CE

**输入**：合成数据集 $Tr_r$；分类器数量 $n_r$；自步调节参数 $\alpha_1$；分箱数 $b$

**输出**：分类器集合 $P_r$

```
1.  S₀ ← RandomSampleReplacement(Tr_r, |Tr_r|)
2.  C₀ ← TrainAClassifier(S₀)
3.  P_r ← P_r ∪ {C₀}
4.  for t ← 1 to n_r do
5.      使用公式(3)计算每个样本的分类难度 H(x_i, y_i, P_r)
6.      通过公式(4)将 Tr_r 划分为 b 个分箱: B₁, B₂, ..., B_b
7.      计算每个分箱的平均难度: dⱼ = Σ_{i∈Bⱼ} H(x_i,y_i,P_r)/|Bⱼ|, ∀j=1,...,b
8.      更新自步因子: s_t = 1 - (t-1)/(α₁·(n_r-1))
9.      获取第j个分箱的采样权重: swⱼ = (1/dⱼ)^{s_t}
10.     通过加权采样获得样本集 S_t:
        从Bⱼ中随机选择 |Tr_r|·(swⱼ/Σ_l sw_l) 个样本, ∀j=1,...,b
11.     C_t ← TrainAClassifier(S_t)
12.     P_r ← P_r ∪ {C_t}
13. end for
14. P_r ← P_r \ {C₀}   // 移除初始分类器
```

**各行详解**：

- **第1-3行（初始化）**：从合成数据集 $Tr_r$ 中有放回地随机抽取一个Bootstrap样本 $S_0$，训练第一个基分类器 $C_0$，并用它初始化分类器集合 $P_r$。

- **第5行**：计算每个样本 $(x_i, y_i)$ 相对于当前集成 $P_r$ 的分类难度——即当前集成中"错误分类该样本"的平均置信度。

- **第6行**：根据分类难度将样本划分到 $b$ 个分箱中（等距划分）。

- **第7行**：计算每个分箱的平均难度 $d_j$。$d_1$ 最低（最容易的样本），$d_b$ 最高（最难的样本）。

- **第8行**：更新自步因子 $s_t$。随着 $t$ 增加，$s_t$ 从 $1$ 线性下降到 $1 - 1/\alpha_1$。

- **第9-10行**：计算每个分箱的采样权重 $sw_j = (1/d_j)^{s_t}$，并据此从各分箱中采样形成新的训练集 $S_t$。

- **第14行**：移除初始分类器 $C_0$（它只是用简单的Bootstrap样本训练的，不够好）。

#### 3.4.2 核心公式

**公式(3) — 分类难度**：

$$H(x_i, y_i, P_r) = \frac{1}{|P_r|} \sum_{t=0}^{|P_r|-1} \big(1 - C_t(x_i, y_i)\big) \tag{3}$$

其中 $C_t(x_i, y_i)$ 是分类器 $C_t$ 将 $x_i$ 预测为真实标签 $y_i$ 的置信度。该公式本质上计算的是"当前集成对样本 $x_i$ 的平均分类错误率"。

**公式(4) — 分箱定义**：

$$B_j = \left\{(x_i, y_i) \mid \frac{j-1}{b} \leq \hat{H}(x_i, y_i, P_r) < \frac{j}{b}\right\} \tag{4}$$

其中 $\hat{H}$ 是 $H$ 的归一化形式，由公式(5)给出：

$$\hat{H}(x_i, y_i, P_r) = \frac{H(x_i, y_i, P_r) - \min_{x_l \in Tr_r} H(x_l, y_l, P_r)}{\max_{x_l \in Tr_r} H(x_l, y_l, P_r) - \min_{x_l \in Tr_r} H(x_l, y_l, P_r)} \tag{5}$$

$\hat{H}$ 的取值范围为 $[0, 1]$。

#### 3.4.3 自步机制的直观理解

采样权重 $sw_j = (1/d_j)^{s_t}$ 的变化规律：

- **当 $s_t = 1$（初始阶段）**：$sw_j = 1/d_j$。低难度分箱（$d_j$ 小）的采样权重高，高难度分箱（$d_j$ 大）的采样权重低。早期基分类器主要学习"容易"样本。

- **当 $s_t$ 逐渐减小**：高难度分箱的采样权重相对提升。

- **当 $s_t < 0$（当 $\alpha_1 < 1$ 时可能发生）**：关系反转——高难度分箱获得比低难度分箱更高的采样权重。模型开始"攻克"困难样本。

**类比理解**：就像老师教学——先教基础内容（容易样本），等学生打好基础后，再逐步引入难题（困难样本）。$\alpha_1$ 控制这个"过渡速度"：$\alpha_1$ 越小，过渡越快，更早开始聚焦困难样本。

#### 3.4.4 与 AdaBoost 的对比

AdaBoost 虽然也能聚焦困难样本，但存在两个关键问题：
1. **对噪声敏感**：合成数据中不可避免会有噪声样本，AdaBoost 的权重会过度集中在噪声上，降低基分类器质量。
2. **基分类器限制**：AdaBoost 的基分类器不适合强分类器，而自步集成可以与任何类型的分类器配合工作。

SPSE_CE 通过分箱和渐进式权重调整，比 AdaBoost 更加稳健。

### 3.5 裁判系统的构建

#### 3.5.1 为什么需要裁判系统？

传统基于邻域的DST（动态选择技术）在估计胜任水平时存在**胜任力冲突问题（Problem iv）**：由于困难样本的RoC（胜任区域）被相反类别的样本主导，正确分类该困难样本的基分类器反而可能获得低胜任评分（因为它可能误分类了RoC中的邻居），而错误分类该困难样本的基分类器却可能获得高胜任评分（因为它正确分类了RoC中的大多数邻居）。

imDEF 使用**裁判系统（Referee System）**替代基于邻域的胜任力估计。核心思想是：
- 为每个基分类器 $C_t$ 训练一个**裁判委员会** $RC_t$
- 裁判委员会学习 $C_t$ 的"擅长区域"（Area of Expertise）
- 给定测试样本 $x$，$RC_t$ 输出 $C_t$ 在该样本上的胜任水平估计

imDEF 的创新在于：**每个裁判委员会由多个世代的裁判分类器组成**，这些裁判分类器被逐步训练，以逐渐提高对困难样本的胜任力估计精度。

#### 3.5.2 动态集成间隔（Dynamic Ensemble Margin）

首先，定义**动态集成间隔**：

$$M(x_i, RS, CL) = \sum_{t=1}^{n} RC_t(x_i) \cdot \mathbb{I}(CL[i,t]=1) - \sum_{t=1}^{n} RC_t(x_i) \cdot \mathbb{I}(CL[i,t]=0) \tag{6}$$

其中：
- $RC_t(x_i)$：裁判委员会 $RC_t$ 对 $C_t$ 在 $x_i$ 上的胜任水平估计
- $CL[i,t]$：$C_t$ 在 $x_i$ 上的胜任力标签（1 = 正确，0 = 错误）
- $\mathbb{I}(\cdot)$：指示函数

**直观理解**：动态集成间隔 = "能够正确分类 $x_i$ 的基分类器的加权票数" - "错误分类 $x_i$ 的基分类器的加权票数"。
- 大的正间隔：意味着大多数基分类器（以高权重）正确分类了该样本——是一个"自信的正确分类"
- 大的负间隔：意味着大多数基分类器错误分类了该样本——是一个"自信的错误分类"
- 接近0的间隔：正确和错误的基分类器在权重上势均力敌——是"难以分类"的样本

**关键洞察**：对于间隔大的样本（如表II中的集合A），即使裁判系统给出随机的胜任水平，动态集成也大概率能正确分类它们（因为大多数基分类器本身就是正确的）。但对于间隔接近零的样本（如表II中的集合B），**裁判系统必须提供精确的胜任力估计**——只有让正分类器获得高胜任评分、负分类器获得低胜任评分，才能纠正多数基分类器的错误，产生正确的集体决策。

因此，裁判系统应该**更加关注低动态集成间隔样本的学习**。

#### 3.5.3 算法3：SPSE_EM（集成间隔感知的自步采样集成）

**输入**：$X_{tr}$（训练特征），$Y_{tr}$（训练标签），$CL$（胜任力标签集），$\alpha_2$（自步调节参数），$b$（分箱数），$\beta$（世代数）

**输出**：裁判系统 $RS = \{RC_t\}_{t=1}^{n}$

```
1.  对每个 x_i ∈ Xtr, 使用公式(7)计算 M₀(x_i, CL)
2.  对每个 x_i ∈ Xtr, 初始化 CM(x_i) ← M₀(x_i, CL)
3.  对每个 x_i ∈ Xtr, 使用公式(10)赋予类别权重 w(x_i)
4.  对每个基分类器, 初始化其裁判委员会: RC_t ← ∅, t=1,...,n
5.  初始化所有裁判集体: GC_g ← ∅, g=1,...,β
6.  for g ← 1 to β do
7.      对每个 x_i, 使用公式(11)将 CM(x_i) 归一化为 ĈM(x_i)
8.      使用公式(12)根据 ĈM 将 Xtr 划分为 b 个分箱: {B_j}ⱼ₌₁ᵇ
9.      计算分箱平均 ĈM: dⱼ = Σ_{x_i∈Bⱼ} ĈM(x_i)/|Bⱼ|
10.     更新自步因子: s_g = 1 - (g-1)/(α₂·(β-1))
11.     获取各分箱采样权重: swⱼ = (1/dⱼ)^{s_g}
12.     确定各分箱采样数量: δⱼ ← (swⱼ/Σ_l sw_l) × |Xtr|
13.     计算分箱内样本的归一化权重: ŵⱼ(x_i) ← w(x_i)/Σ_{x_l∈Bⱼ} w(x_l)
14.     for t ← 1 to n do
15.         通过加权采样从各分箱获取样本集 S_g^t
16.         从 CL[:,t] 提取 S_g^t 的胜任力标签 L_g^t
17.         R_g^t ← TrainAClassifier((S_g^t, L_g^t))
18.         GC_g ← GC_g ∪ {R_g^t}
19.         RC_t ← RC_t ∪ {R_g^t}
20.     end for
21.     对每个 x_i, 使用公式(9)计算 M_g(x_i, GC_g, CL)
22.     对每个 x_i, 更新 CM(x_i) ← CM(x_i) + M_g(x_i, GC_g, CL)
23. end for
```

**整体流程的直观理解**：
1. 首先，计算每个训练样本相对于分类器池的"初始硬度"（没有任何裁判时的负间隔）
2. 然后，迭代地构建多代裁判集体（共 $\beta$ 代）
3. 每一代中：根据累积负间隔对样本分箱，使用自步机制逐步增加对"高累积负间隔"样本的采样，为每个基分类器训练一个裁判分类器
4. 每一代结束后：使用新训练的裁判集体重新计算每个样本的负间隔，并累积到CM中，指导下一代裁判集体的构建

#### 3.5.4 SPSE_EM 的核心公式

**公式(7) — 初始负集成间隔（初始NEM）**：

$$M_0(x_i, CL) = -\sum_{t=1}^{n} \big(\mathbb{I}(CL[i,t]=1) - \mathbb{I}(CL[i,t]=0)\big) \tag{7}$$

由于此时还没有裁判分类器，我们简单地假设所有基分类器的胜任水平都为1。这实际上计算的是 $x_i$ 的"负分类器数量 - 正分类器数量"——衡量样本相对于分类器池的"原始分类难度"。

**公式(8) — 累积负集成间隔（CNEM）**：

在构建了前 $p$ 代裁判集体之后，样本 $x_i$ 的累积负集成间隔为：

$$CM(x_i) = M_0(x_i, CL) + \sum_{g=1}^{p} M_g(x_i, GC_g, CL) \tag{8}$$

其中 $M_g(x_i, GC_g, CL)$ 是 $x_i$ 相对于第 $g$ 代裁判集体 $GC_g$ 的负集成间隔，由公式(9)定义：

$$M_g(x_i, GC_g, CL) = \sum_{R_g^t \in GC_g} R_g^t(x_i) \cdot \mathbb{I}(CL[i,t]=0) - \sum_{R_g^t \in GC_g} R_g^t(x_i) \cdot \mathbb{I}(CL[i,t]=1) \tag{9}$$

**直观理解公式(9)**：对于第 $g$ 代裁判集体中的每个裁判分类器 $R_g^t$（对应基分类器 $C_t$），如果 $C_t$ 在 $x_i$ 上是错误的（$CL[i,t]=0$），$R_g^t$ 的预测值贡献正项；如果 $C_t$ 是正确的（$CL[i,t]=1$），则贡献负项。因此，
- $M_g$ 越大：意味着该代裁判集体倾向于给"错误分类器"高评分、给"正确分类器"低评分——这是一个危险的信号，说明当前裁判系统在 $x_i$ 上的胜任力估计不够好
- $M_g$ 越小（越负）：说明裁判集体正确地给"正确分类器"高评分、给"错误分类器"低评分

CM越大，说明该样本在当前裁判系统下仍是"难以正确处理"的，需要后续世代更多关注。

**公式(10) — 类别权重**：

$$w(x_i) = \frac{\max_k \sqrt{m_k}}{\sum_{l_k \in L} \mathbb{I}(y_i = l_k) \sqrt{m_k}} \tag{10}$$

其中 $m_k$ 是类别 $l_k$ 在 $X_{tr}$ 中的样本数量。

**设计考量**：传统的不平衡学习方法通常将样本权重设为与类别频率成反比（即少数类权重极高），但这可能导致少数类的过度强调。imDEF 使用了一种**温和版本**：权重与类别频率的平方根成反比（即 $w \propto 1/\sqrt{m_k}$），在"强调少数类"和"不过度强调"之间取得平衡。

**公式(11) — 归一化的累积负集成间隔**：

$$\hat{CM}(x_i) = \frac{CM(x_i) - \min_{x_l \in Tr} CM(x_l)}{\max_{x_l \in Tr} CM(x_l) - \min_{x_l \in Tr} CM(x_l)} \tag{11}$$

$\hat{CM}(x_i)$ 的取值范围为 $[0, 1]$。

**公式(12) — SPSE_EM 的分箱定义**：

$$B_j = \left\{x_i \mid \frac{j-1}{b} \leq \hat{CM}(x_i) < \frac{j}{b}\right\} \tag{12}$$

与 SPSE_CE 的分箱策略类似，但这里基于的是 $\hat{CM}$（归一化累积负间隔），而非分类错误率。

#### 3.5.5 SPSE_CE 与 SPSE_EM 的关键区别

| 方面 | SPSE_CE | SPSE_EM |
|------|---------|---------|
| **用途** | 构建分类器池 | 构建裁判系统 |
| **分箱依据** | 分类错误率 $H(x_i, y_i, P_r)$ | 累积负集成间隔 $\hat{CM}(x_i)$ |
| **样本选择方式** | 简单随机采样 | 加权采样（考虑类别权重） |
| **为什么不平衡处理** | 由合成数据集的平衡分布间接处理 | 通过类别权重 $w(x_i)$ 直接处理 |
| **自步因子范围** | $1$ 到 $1-1/\alpha_1$ | $1$ 到 $1-1/\alpha_2$ |
| **输出结构** | 一组基分类器 | 每个基分类器对应一个裁判委员会 |

### 3.6 动态预测

最终的动态预测由公式(13)给出：

$$\hat{y} = \arg\max_{l_k \in L} \sum_{t=1}^{n} RC_t(x) \cdot C_t(x, l_k) \tag{13}$$

其中：
- $x$：待预测的测试样本
- $C_t(x, l_k)$：基分类器 $C_t$ 将 $x$ 预测为类别 $l_k$ 的概率（置信度）
- $RC_t(x)$：裁判委员会 $RC_t$ 对 $C_t$ 在 $x$ 上的胜任水平估计

而 $RC_t(x)$ 的计算方式为：

$$RC_t(x) = \frac{1}{\beta} \sum_{g=1}^{\beta} R_g^t(x)$$

即 $RC_t(x)$ 是裁判委员会中所有世代裁判分类器预测值的简单平均。

**直观理解**：最终的预测结果是这样产生的——每个基分类器 $C_t$ 对样本 $x$ 给出自己的"意见"（各类别的概率），然后由一个专门的裁判委员会 $RC_t$ 评估这个意见的"可信度"。所有基分类器的意见按可信度加权求和，得分最高的类别即为最终预测。

这就像一个**专家评审系统**：
- 每个基分类器是一个"专家"，给出自己的判断
- 每个裁判委员会是一个"评审团"，评估专家的可信度
- 最终决策基于"专家意见 × 评审团评分"的加权结果

## 四、实验结果与分析

### 4.1 实验设置

#### 数据集

- **二分类实验**：30个数据集，来自UCI和序数回归基准数据，在样本量、特征维度和不平衡率方面具有多样性
- **多分类实验**：18个数据集，考虑了样本量、特征维度、类别数量和应用领域的多样性

#### 评估指标

| 场景 | 指标 | 说明 |
|------|------|------|
| 二分类 | F1, G-mean, AUC | 三者联合评估不平衡学习方法性能 |
| 多分类 | macro-F1, MG, MAUC | 分别为F1/G-mean/AUC的多分类扩展 |

所有方法在每个数据集上使用分层5折交叉验证运行10次，最终性能为50次测试结果的平均值。

#### 基分类器与参数

- **基分类器**：分类回归树（Classification Regression Tree），因为它在现有集成方案中最常用
- **基分类器数量 $n$**：100
- **裁判世代数 $\beta$**：5（实验中小值设置，但imDEF仍显著优于其他方法）
- **统计检验**：Wilcoxon符号秩检验（验证imDEF与各对比方法之间是否存在显著性能差异）

### 4.2 对比方法

#### 静态集成方法（9种）
SMOTEBoost (SMOTEB)、OREMBoost (OREMB)、EasyEnsemble (EasyE)、BalanceCascade (BalanceC)、RBBoost (RBB)、ASE、SPE、DAPS、AdaCC1

#### 动态集成方案（4种两类各两个版本）
B+RM100+KNU（100和600分类器）、OLP+ENN+KNNE、BR+RM+KNU（100和600分类器）、EE+MCB（100和600分类器）

### 4.3 二分类实验结果

**与静态集成对比**：
- imDEF在30个数据集中的8/12/15个上分别取得了最佳F1/G-mean/AUC
- Wilcoxon检验显示imDEF在几乎所有比较项上都取得了统计显著的优势（除与EasyE和SPE在G-mean上的比较外）

**与动态集成对比**：
- imDEF在30个数据集中的15/14/15个上分别取得了最佳F1/G-mean/AUC
- Wilcoxon检验显示几乎所有比较项上存在显著差异

### 4.4 消融实验

为验证imDEF三个关键组件的有效性，设计以下变体：

| 变体 | 修改内容 |
|------|---------|
| imDEF w SM | 用SMOTE_G替代OREM_G生成合成数据 |
| imDEF w/o Gen | 直接从原始训练数据中随机采样替代合成数据生成 |
| imDEF w Bag | 用Bagging替代SPSE_CE |
| imDEF w AdaB | 用AdaBoost.M2替代SPSE_CE |
| imDEF w/o DS | 放弃SPSE_EM，使用所有基分类器投票 |
| imDEF w Sig | 放弃SPSE_EM，用单个分类回归树学习胜任区域 |
| imDEF w KNE/KNU/desP/KnoP/desRRC/desKL/METADES | 用各DST替代SPSE_EM |

结果：imDEF在统计上显著优于所有变体，三个关键组件（OREM_G, SPSE_CE, SPSE_EM）各自发挥了积极作用。

### 4.5 多分类实验结果

- imDEF在18个数据集中的9/8/7个上分别取得了最佳macro-F1/MG/MAUC
- Wilcoxon检验显示imDEF几乎显著优于所有对比方法（包括静态和动态集成）
- 证明imDEF在处理复杂的多分类不平衡问题时也具有很强竞争力

### 4.6 参数敏感性分析

对 $\alpha_1$、$\alpha_2$ 和 $\beta$ 进行敏感性分析：

- **$\alpha_1$ 和 $\alpha_2$**：减小 $\alpha_1$ 或 $\alpha_2$ 会降低 $ACC_{min}$（少数类准确率）但提升 $ACC_{maj}$（多数类准确率）。原因是较小的 $\alpha$ 使自步因子下降更快，更多注意力被分配给困难样本（在合成数据中，边界多数类更容易成为困难样本）。$\alpha_1 \approx 0.7$ 和 $\alpha_2 \approx 1.0$ 是较好的平衡点。

- **$\beta$（裁判数量）**：增大 $\beta$ 有利于获得更精确的胜任力估计。G-mean随 $\beta$ 增大而提升，$\beta = 35$ 是较好的设置。实验中仅使用 $\beta = 5$（节省计算），imDEF仍显著优于其他方法，说明即使裁判系统规模不大也能有效工作。

## 五、总结与展望

### 5.1 方法总结

imDEF是一个三阶段框架：

1. **OREM_G 生成合成数据**：通过调整因子 $cf_r$ 生成具有多样性类别分布的合成数据集，分离了训练数据和胜任力评估数据（解决Problem i），并纠正了分类器池的偏倚（解决Problem ii）。

2. **SPSE_CE 构建分类器池**：使用分类错误感知的自步机制，从容易到困难逐步训练基分类器，增加了困难样本的正分类器数量（解决Problem iii）。

3. **SPSE_EM 构建裁判系统**：使用集成间隔感知的自步机制，逐步聚焦于难以分类的样本，为每个基分类器训练多代裁判委员会来估计胜任水平（避免Problem iv的胜任力冲突，解决Problem v）。

### 5.2 未来方向

1. OREM_G 需要计算任意两个样本之间的距离，且只能处理数值型数据。可以开发更高效且通用的数据生成方法来处理不平衡的大规模混合数据。

2. 可以尝试使用自步Boosting算法来创建分类器池——聚焦于学习不足但可靠的合成样本，同时抑制噪声合成样本的影响。
