# 14 个数据重采样方法 — 技术说明与代码审查

> 对象：综述（Fachrie et al. 2025）涉及的 14 个数据重采样方法，逐一给出论文出处、
> 算法原理、核心组件与参数、以及**论文↔代码保真审查**（含显式近似清单，不静默简化）。
> 全部 14 方法下游统一 `RandomForest(n_estimators=30)`（基类 `common.resampler.Resampler`），
> 因此**性能差异完全归因于重采样步骤本身**——纯净的 apples-to-apples 对比。
> 共享工具：`common.neighbors`（鲁棒 k-NN / SMOTE / safe-level / 球内采样）、`common.dempster`。

---

## 公共设定（14 方法共用）

- **下游分类器**：`RandomForest(n_estimators=30, n_jobs=-1)`，每模型随机种子透传。
- **平衡目标**：过采样到多数类规模（`target = N_majority`），除非方法论文指定均值（SOUP/SCUT/MC-EVHS 用均值）。
- **多类推广**：多数类 = 样本最多的类；所有更小的类为少数类，逐类处理（成对方法除外）。
- **输入**：runner 已 StandardScaler 归一化 + 整数编码（preencoded），重采样在归一化特征上进行。
- **鲁棒性**：k-NN 的 k 自动封顶到 `len-1`；单样本类用复制而非崩溃（`common.neighbors.smote_generate`）。

## 1. SOUP（soup.py）

- **出处**：Janicka, Lango, Stefanowski (2019) *Using information on class interrelations...* AMCS 29(4). DOI 10.2478/amcs-2019-0057
- **原理**：`SOUP` 不是单纯的 `safe level` 排序器。论文摘要明确写到：样本困难度既来自**邻域中的类分布**，也来自**邻近类别的相似度**；作者公开页面还专门比较了 `SOUP SIM1..SIM6` 与 `SOUP Heur` 多种相似度变体。因此，若只计算“同类近邻占比”并静态排序，就把 `SOUP` 的 `Similarity` 这一半机制完全删掉了。目标规模仍取各类样本数的**算术均值**，但多数类 / 少数类的处理顺序应由**相似度感知后的安全度 / 困难度**决定。
- **参数**：`k=5, similarity_mode='heur', update_difficulty=True`。
- **实现**：`_class_similarity_matrix()` 先从全数据 `k-NN` 邻域的**类间混合程度**估计启发式相似度矩阵，并以此实例化作者页面中的 `SOUP Heur` 路径；`_similarity_safe_level()` 不再只把“同类邻居比例”当成安全级，而是对每个邻居按其类别与当前类的相似度赋权，再对整段邻域求平均；`_resample()` 也不再一次性静态排序，而是按相似度感知分数做**priority undersampling / replication oversampling**，并默认在每轮复制 / 删除后重新估计困难度。
- **保真**：均值目标、复制型过采样、优先级欠采样、全局邻域困难度评估、显式引入邻近类别相似度五条主线均已落地；旧版“只有 `safe level`、且文档声称无近似”的偏差已移除。
- **近似**：当前环境无法直接读取正文中 `SIM1..SIM6` 与 `Heur` 的逐式定义，只能从摘要和作者页面确认“相似度变体确实存在且是核心参数化部分”。因此现实现用**互为近邻的类间混合比例**来近似 `SOUP Heur` 的类别相似度，并在代码中显式命名为 `similarity_mode='heur'`。这比旧版完全忽略 `Similarity` 维度更接近论文主线，但仍保留了明确的近似边界。

## 2. MDO（mdo.py）

- **出处**：Abdi, Hashemi (2016) *To combat multi-class imbalanced problems by means of over-sampling.* TKDE 28(1). DOI 10.1109/TKDE.2015.2458858
- **原理**：不是“对整类直接做一次多元高斯抽样”。`MDO` 先在全数据的局部邻域中筛出足够“少数类占优”的 minority seeds，并按其局部少数类占比形成抽样权重；然后只对这些被选种子对应的少数类子集做 `PCA / PC` 变换，在 `PC` 空间中为每个被抽中的种子生成一个与其**到类中心具有相同马氏距离**的新点，也就是沿同一**概率轮廓 / 等马氏轮廓**生成样本，最后再逆变换回原始空间。
- **参数**：`k2=5, k1_frac=0.5, variance_floor=1e-3`。其中 `k2` 为局部邻域规模，`k1_frac` 控制种子筛选阈值 `k1 = floor(k2 * k1_frac)`，`variance_floor` 用于稳定极小方差主成分。
- **实现**：`_oversample_class()` 复现论文中的 `chooseSamples` 思路，在全体样本的局部邻域内统计每个少数类样本周围的同类占比并筛选有效种子；`_generate_samples()` 将所选种子子集投影到 `PC` 空间；`_generate_pc_sample()` 依据被抽中种子的 `alpha = \sum_j t_j^2 / V_j` 生成**同一马氏距离轮廓**上的新点，再通过 `PCA.inverse_transform()` 还原到原空间。
- **保真**：实例级 seed 选择、权重随机挑选、`PC` 空间生成、等马氏距离概率轮廓建模四条主线均已落地。
- **近似**：当前实现按公开实现口径用 `PCA` 子空间方差 `V_j` 与逐维构造法来满足等马氏轮廓约束；对单样本极小类仍保留复制回退，以避免折内样本过少时退化崩溃。

## 3. SMOM（smom.py）

- **出处**：Zhu, Lin, Liu (2017) *Synthetic minority oversampling technique for multiclass imbalance problems.* PR 72. DOI 10.1016/j.patcog.2017.07.024
- **原理**：不是“先给种子实例分权，再像普通 `SMOTE` 那样随机挑一个同类邻居”。论文摘要明确强调：对任一原始少数类实例，合成样本并不是在其 `k` 个近邻方向上等概率生成，而是要给**每一个候选邻居方向**赋选择权重；会导致严重 **over-generalization** 的方向应得到更小权重，从而在 `k` 取大时仍能积极扩展少数类区域而不显著侵入其它类。
- **实现**：`_cluster_and_label()` 先对每个类做一次类内聚类，并给实例继承 `SAFE / TRAPPED` 区域标签；`_direction_weights()` 再对每个 seed 的每个同类候选邻居方向单独算权重，而不是旧版那样只给 seed 算一个 `safe_level` 权重。方向权重由两部分组成：候选方向中点在全数据 `k-NN` 中的**同类占比**，以及该邻居 / seed 所属 `SAFE / TRAPPED` 状态的惩罚因子。最终 `_resample()` 在方向级权重上抽取邻居，再执行线性插值生成样本。
- **参数**：`k=5, cluster_min_samples=3, trapped_penalty=0.2, midpoint_alpha=0.5`。
- **保真**：类内聚类、`SAFE / TRAPPED` 标签继承、邻居方向而非 seed 的选择加权、基于过泛化风险抑制危险方向四条主线均已落地。
- **近似**：论文正文中用于 `safe / trapped` 区域识别的 NBDOS 细节在当前环境无法逐式提取；现实现以**类内 DBSCAN + 全数据邻域纯度**来近似该聚类 / 标签阶段，并用方向中点的同类占比来实例化 `over-generalization factor`。这比旧版“连续 `safe_level` 折叠全部机制”的弱化实现更接近论文主线，且近似边界已显式记录。

## 4. MC-RBO（mc_rbo.py）

- **出处**：Krawczyk, Koziarski, Woźniak (2020) *Radial-based oversampling for multiclass imbalanced data classification.* TNNLS 31(8). DOI 10.1109/TNNLS.2019.2913673
- **原理**：不是“随机选种子后直接加一次高斯噪声”。`MC-RBO` 把每个少数类实例视为 **RBF potential field** 的中心，并显式利用**所有类别**的信息构造 **mutual class potential**；每个合成样本都从一个少数类种子出发，沿各坐标轴方向做迭代搜索，使候选点的 `|mutual potential|` 逐步减小，从而把新样本推向**类间互势较小**的有利区域。多类阶段采用作者公开实现中的 `sampling / complete` 专用流程，而不是简单逐类独立补齐。
- **参数**：`gamma=0.05, step_size=0.001, n_steps=500, approximate_potential=True, n_nearest_neighbors=25, method='sampling'`。其中 `gamma` 控制 RBF 势场宽度，`step_size` 与 `n_steps` 控制势场搜索步长和迭代次数；`approximate_potential=True` 时仅用局部近邻近似势值。
- **实现**：`_mutual_class_potential()` 复现“异类势减同类势”的互势函数；`_generate_from_seed()` 从少数类种子出发，沿坐标轴正负方向迭代试探，仅接受能降低 `|potential|` 的位移；`_resample()` 复现作者仓库中的 `sampling / complete` 多类流程。
- **保真**：互势驱动生成、局部近邻势近似、坐标步进搜索、多类 `sampling / complete` 处理策略均已落地。
- **近似**：当前实现按作者公开仓库口径使用 **axis-aligned greedy search** 与 `L1` 距离来搜索低互势区域，而不是额外改写为连续梯度优化；这是对作者实现的忠实复现，不再保留旧版“单一类级 sigma 高斯撒点”的简化。

## 5. OREM-M（orem_m.py）

- **出处**：Zhu, Liu, Zhu (2023) *Oversampling with reliably expanding minority class regions.* TKDE 35(6). DOI 10.1109/TKDE.2022.3171706
- **原理**：不是“同类插值后做最近邻同类判定”。按作者公开 `MATLAB` 代码，`OREM` 先为每个少数类样本构造其 **candidate minority region (CMR)**：把同类邻居和异类邻居按距离混排，一旦出现连续若干个异类邻居，就在此之前截断得到候选区域；然后在该候选区域里进一步识别 **clean subregion** 对应的 **assistant seeds**，判据是样本与 assistant seed 中点附近不能被更近的多数类样本阻挡；最后只朝这些 assistant seeds 插值生成新样本。若 assistant seed 本身是多数类样本，则只允许向其移动一半距离。`OREM-M` 在多类场景下通过**迭代生成**，使后续类别在扩展时同时避开原始异类样本和前面类别已经生成的合成样本。
- **实现**：`_discover_cmr()` 复现作者代码中的 `discovCMR`，通过“连续 `consecutive_majority` 个异类邻居”截断候选区域；`_identify_clean_regions()` 复现 `idenCleanReg` 的中点 clean-subregion 判定；`_generate_binary()` 复现作者 `Generate` 过程，对 assistant seeds 做逐维随机插值，并在 assistant 为异类时将步长减半；`_resample()` 则把该二分类核心扩展为多类 **iterative generation**，每补完一个类就把其合成样本加入工作集，供后续类别避让。
- **参数**：`consecutive_majority=5, iteration_order='ascending'`。其中 `consecutive_majority` 是作者代码里的候选区域截断条件，`iteration_order` 控制多类迭代生成的类别顺序。
- **保真**：`CMR` 发现、clean subregion 识别、assistant-seed 引导生成、异类 assistant 半步插值、多类迭代生成五条主线均已落地。
- **近似**：作者公开仓库仅给出二分类 `OREM` 代码，未直接提供 `OREM-M` 源码；当前多类版本依据论文摘要中“leveraging an iteration procedure of generating synthetic samples”实现为按类规模顺序迭代补样，并把已生成样本并入后续类别的异类集合，以显式减少不同少数类合成样本之间的重叠。旧版“plain SMOTE 回退”已删除；当 clean subregion 为空时，按作者二分类代码直接返回原样本自身。

## 6. MC-CCR（mc_ccr.py）

- **出处**：Koziarski, Woźniak, Krawczyk (2020) *Combined cleaning and resampling algorithm for multi-class imbalanced data with label noise.* KBS 204. DOI 10.1016/j.knosys.2020.106223
- **原理**：不是固定半径球。对每个少数类实例，先用给定**能量**逐步扩张一个 `p` 范数球：球在未遇到多数类样本前按常规代价扩张；每纳入一个多数类样本，后续扩张代价都会升高。扩张结束后，对球内多数类执行**平移 / 删除 / 忽略**清洗；再在该球内生成少数类合成样本。多类阶段按作者公开代码的专用策略处理，避免传统分解策略丢失类间关系。
- **参数**：`energy=0.25, cleaning_strategy='translate', selection_strategy='proportional', p_norm=1.0, method='sampling'`。
- **实现**：`_binary_ccr()` 逐少数类实例按排序后的异类距离做**能量分段消耗**来求半径；`cleaning_strategy` 支持 `translate/remove/ignore`；`selection_strategy` 支持按 `1/r_i` 比例分配或随机选球；多类阶段复现作者仓库的 `sampling` / `complete` 两种处理流程。
- **保真**：能量驱动球扩张、同步清洗、球内合成、多类专用处理策略均已落地。
- **近似**：作者公开代码本身就在 `p` 范数球内采用随机方向归一化采样，本实现按该公开代码口径复现，而不是额外改成其它球采样分布。

## 7. SHSampler（shsampler.py）

- **出处**：Zheng et al. (2022) *Combating mutuality with difficulty factors...* DSAA. DOI 10.1109/DSAA54385.2022.10032369
- **原理**：混合采样。论文摘要明确写的是先做 **sample similarity / dissimilarity estimation** 识别 `difficulty factors`，再做 **relative majority weakening** 和 **relative minority strengthening**。因此它不应退化成“只找单一全局多数类，其余所有类一律补到最大类”的简单版本。实例层面上，相似性由本类近邻支持度体现，异质性由到异类近邻的距离体现；多数侧按困难度轮盘赌删样，少数侧按安全种子在球形边界内生成。
- **参数**：`k=5, target_mode='mean'`。
- **实现**：`_estimate_similarity()` 用 `safe_level` 估计样本与本类的相似性；`_estimate_dissimilarity()` 用 `cross_class_nn_dist()` 估计样本到异类的分离半径；`_roulette_delete()` 现在按 **delete probability ∝ (1 - safe_level)** 直接抽取被删除样本，而不是旧版那种“高 safe-level 保活采样”的等价替写；类层面不再只处理单一全局多数类，而是以**平均类规模**划分 relative majority / minority：大于均值的类欠采样到均值，小于均值的类过采样到均值，等于均值的类保持不变。
- **保真**：相似性 / 异质性双估计、轮盘赌削弱多数、球形边界增强少数、multi-class 下的相对多数 / 相对少数处理四条主线均已落地。
- **近似**：由于当前环境无法稳定提取论文第 III 节全文，摘要可确认 `relative majority` / `relative minority` 与 similarity / dissimilarity 两级机制，但未能直接读取作者给出的最终类目标公式。现实现以**平均类规模**作为 relative 分组阈值来实例化论文语义，并已在代码 / 文档中显式说明，避免静默保留旧版“补到全局最大类”的强简化。

## 8. MC-NRO（mc_nro.py）

- **出处**：Shen et al. (2024) *Neighborhood repartition-based oversampling algorithm for multiclass imbalanced data with label noise.* Neurocomputing 600. DOI 10.1016/j.neucom.2024.128090
- **原理**：不是“固定半径平移 + 全局高斯噪声”。`MC-NRO` 将 **MC-CCR** 的清洗与 **MC-RBO** 的径向生成融合到**邻域重划分**框架中：先围绕少数类实例做 **energy-based** 邻域扩张并平移其它类样本；再根据平移后的局部邻域归属删除仍表现为**重叠 / 标签噪声 / 离群**的样本；最后仅在对当前类更有利的**mutual-potential 子区域**内接受径向生成的候选样本。
- **参数**：`energy=0.25, spread=None, k=5, p_norm=1.0, potential_tau=1.0`。
- **实现**：`_translate_around_class()` 复现 `MC-CCR` 风格的能量驱动平移；`_repartition_delete()` 用平移后的 `k-NN` 邻域重划分删除仍落在少数类主导区域的其它类样本；`_oversample_class()` 在边界少数类种子周围做径向采样，并用 `_mutual_potential()` 与局部 rival class 的高斯势比较来过滤候选。
- **保真**：`MC-CCR + MC-RBO` 融合、邻域重划分删除、mutual-potential 约束子区域这三条主线均已落地。
- **近似**：论文全文公式未公开到可逐式核验时，mutual potential 采用基于局部 rival class 的高斯核势和式，重划分删除采用平移后 `k-NN` 的类别主导关系来近似论文中的多邻域判定；但已回到“局部势 + 邻域重划分”的论文主线，不再是简单坐标重合检测。

## 9. MC-EVHS（mc_evhs.py）— Dempster-Shafer 证据理论（heavy: DS）

- **出处**：Grina, Elouedi, Lefevre (2022) *Evidential hybrid re-sampling for multi-class imbalanced data.* IPMU, pp 612–623.
- **原理**：不是邻居投票。先按 `CCR` 思路为每个对象构造**软 evidential label**：用**类中心**、**meta-class 中心**（重叠区域）以及**outlier** 命题共同表示其区域属性，质量值由对象到这些中心的**马氏距离**递减决定。随后先对高于均值的多数类做**歧义 / 噪声优先欠采样**，再对低于均值的少数类在**边界区域**执行 evidential SMOTE。目标=均值。
- **实现**：`_build_focals()` 生成类中心与满足约束的 meta-class 中心；`_mass_functions()` 用距离衰减函数为 singleton / meta-class / outlier 分配质量；多数类按 `meta + outlier - own_singleton` 的歧义度优先删样；少数类仅从 `meta-class` 支持较强的边界样本出发做同类 SMOTE 插值。
- **参数**：`k=5, alpha=1.0, t=5`，其中 `alpha` 为距离衰减指数，`t` 为允许考虑的 meta-class 最大阶数。
- **保真**：类中心 / meta-class / outlier 的 evidential label、均值目标、多数类优先欠采样、少数类边界过采样均已落地。
- **近似**：论文 / `CCR` 公式全文未完全公开到可逐式核验时，质量函数采用“马氏距离的反幂衰减 + meta-class 距离均衡惩罚”的实现，并以 pairwise 到 `t` 阶的候选 meta-class 集代替穷举全部 `2^Omega` 焦元；但已回到论文的**中心距离证据建模**主线，不再是 `k-NN` 投票近似。

## 10. NROMM（nromm.py）

- **出处**：Liu et al. (2023) *Noise-robust oversampling for imbalanced data classification.* PR 133. DOI 10.1016/j.patcog.2022.109008
- **原理**：不是“全局多数类上删一部分点，再对少数类做加权 `SMOTE`”。`NROMM` 采用 **one-versus-ensemble** 分解：每次只过采样一个当前类，并把所有比它更大的类合并为当前 majority side；在该二分类子问题里，用 **CFSFDP** 风格聚类把 minority / majority 都划分为 **inland / borderline / trapped** 三组；随后删除 majority 的 `borderline / trapped` 样本以清洗重叠区域，对 minority 三组采用不同生成策略，其中 `trapped` 组通过 **adaptive embedding** 向更安全的 minority 支撑区移动后再生成；最后再检测多类 overlap set，并删除落入 overlap set 的 `inland` 样本来丰富边界。
- **参数**：`k=5, density_percentile=20.0, safe_margin=1.05, max_ratio=20`。其中 `density_percentile` 用于确定 `CFSFDP` 局部密度核尺度，`safe_margin` 控制安全边界对 majority 的排斥强度。
- **实现**：`_density_peak_clusters()` 复现 `CFSFDP` 风格的 `rho / delta / gamma` 密度峰聚类；`_group_points()` 结合类内密度峰簇和跨类邻域安全度划分三组；`_binary_clean_majority()` 删除当前 `OvE` 子问题中 majority 的非 `inland` 样本；`_generate_for_seed()` 对 `inland / borderline / trapped` 使用不同生成逻辑，其中 `trapped` 先执行 `_adaptive_embed()` 再做安全插值；`_remove_overlap_inland()` 在所有类补齐后执行论文摘要对应的 overlap 清洗。
- **保真**：`OvE` 分解、`CFSFDP` 风格分组、`adaptive embedding`、`safe boundary`、最终 overlap 清洗五条主线均已落地。
- **近似**：论文全文公式未能完整逐式提取时，当前以 `CFSFDP` 风格的密度峰聚类加跨类邻域安全度近似原文的三组判定；`adaptive embedding` 采用“先向非 trapped minority 支撑区嵌入，再在安全边界内插值”的工程化实现，但已明显强于旧版“safe-level 阈值 + 普通 SMOTE”的简化壳。

## 11. SCUT（scut.py）

- **出处**：Agrawal, Viktor, Paquet (2015) *SCUT: Multi-Class Imbalanced Data Classification Using SMOTE and Cluster-based Undersampling.* IC3K-KDIR. DOI 10.5220/0005595502260234
- **原理**：混合。不是“多数类先聚类，再按簇大小比例四舍五入分点删样”那么简单。`SCUT` 的核心是先对每个多数类做 **EM / model-based clustering**，再执行**簇感知的随机欠采样**，使 undersampling 后仍保留类内多个子簇；少数类则用 **SMOTE** 直接补到统一目标规模。目标规模取**所有类样本数的算术均值**。
- **参数**：`k=5, max_clusters=9, covariance_types=('full','tied','diag','spherical')`。
- **实现**：`_em_cluster()` 不再把簇数武断限制在 `4`，而是按公开 `scutr` / `Mclust` 口径，对 `k = 1..9` 的候选簇数做 `BIC` 选择；同时在 `sklearn` 可表达的四种协方差结构上共同搜索最优 `GaussianMixture`。`_sample_clusters()` 不再做旧版“按簇大小比例分配 quota”，而是复现 `scutr::sample_classes()` 的**簇分层随机抽样**：先对每个簇抽取 `ceil(target / #clusters)` 个实例（必要时允许极小簇重复抽样），再交错截断到精确 `target`，从而保证多数类欠采样后仍保留各簇表示。
- **保真**：均值目标、EM / GMM 聚类、多数类按簇保结构欠采样、少数类 `SMOTE` 补齐四条主线均已落地；旧版 `max_clusters=4` 与“比例配额删样”偏差已移除。
- **近似**：论文正文未公开可逐句照搬的伪代码，当前实现以作者后续公开 `scutr` 包为可验证实现口径；但由于 `sklearn` 没有 `mclust` 的完整模型族与层次初始化流程，现用 `GaussianMixture + BIC` 在 `('full','tied','diag','spherical') × G=1..9` 上近似 `Mclust(G=1:9)`，这比旧版“单一 `diag` + 4 簇上限”更接近论文 / 公开实现主线。

## 12. GLOS（glos.py）— 复合（heavy: compound）

- **出处**：Han et al. (2023) *Global-local information based oversampling for multi-class imbalanced data.* IJMLC 14(6). DOI 10.1007/s13042-022-01746-w
- **原理**：先为每个少数类同时计算**类级 DID** 与**实例级 DID**（离散度指标）；仅选择 `instance-level DID < class-level DID` 的**难学样本**参与生成，并按两者差值给每个样本分配合成数。随后再按样本的局部分布把这些候选分到 `safe / borderline / small-disjunct` 三组，分别调用 **MMO / AMBO / RRO** 生成更具多样性的样本。
- **实现**：`_did_scores()` 计算类级 / 实例级 DID；`_allocate_counts()` 把 `class-level DID - instance-level DID` 转成逐样本生成预算；`_mmo_seeded()`、`_ambo_seeded()`、`_rro_seeded()` 以被选中的实例为中心分别执行全局、边界和径向生成；GLOS 不再按组规模粗分预算，而是按**样本级难度差值**驱动生成。
- **参数**：`k=5, shrinkage=1e-3`。
- **保真**：`DID` 选样、逐样本生成数分配、`MMO + AMBO + RRO` 三分支编排均已落地。
- **近似**：论文未公开 DID 的闭式细节时，当前以“异类邻居平均距离 / 同类邻居平均距离”近似 DID，并用混合邻域组成划分 `safe / borderline / small-disjunct`。

## 13. S-SMOTE（s_smote.py）— 模态 GA 优化的 RBFNN（heavy: memetic-GA，**嵌入式分类器**）

- **出处**：Fernández-Navarro, Hervás-Martínez, Gutiérrez (2011) *A dynamic over-sampling procedure based on sensitivity for multi-class problems.* PR 44(8). DOI 10.1016/j.patcog.2011.02.019
- **原理（双贡献）**：不是“对每个少数类一次性补到多数类规模”。论文采用 **two-stage dynamic oversampling**：阶段 1 只对**全局 minority class** 做一次部分平衡；随后在模因算法进化的不同代里，持续识别当前**最优 RBFNN** 的 **minimum sensitivity class**，并只对这个“当前最难类”继续生成新样本。第二条主线是**模因优化的 RBFNN 分类器**，即分类器本身与动态过采样协同演化，而不是交给通用 `RF`。
- **实现**：`_initial_stage_resample()` 先对全局最小类执行一次 `SMOTE` 翻倍；`fit()` 中的 GA 不再在固定数据上静态搜索，而是每一代先评估当前种群，再用当前最优个体在验证集上的 per-class sensitivity 找出 **minimum sensitivity class**，随后通过 `_duplicate_class_with_smote()` 在下一代前继续扩增该类；RBFNN 仍采用 `k-means` 中心 + 高斯核 + 岭最小二乘输出权重，其中 LS 解承担 memetic 的局部精修角色。
- **参数**：`k=5, ga_pop=12, ga_gen=8, max_centers=40, ridge=1e-2`。
- **保真**：两阶段动态过采样、按最小 sensitivity 类分代增样、GA 优化 RBFNN 结构 / 宽度 / 岭参数三条主线均已落地。
- **近似**：① 论文完整 memetic 内循环未公开到可逐式照搬时，当前以 `GA + LS` 近似 Lamarckian 局部搜索；② 公开摘要仅明确“first stage partially balance the minority class”和“duplicate the minimum sensitivity class”，当前实现按该口径把每次动态增样落实为**对目标类做一次翻倍式 SMOTE**；③ **下游非 RF(30)**——RBFNN 是嵌入式分类器（论文本体），已显式标注，不替换。

## 14. OCSV-US（ocsv_us.py）— OC-SVM + GA 选择欠采样（heavy: GA）

- **出处**：Krawczyk, Bellinger, Corizzo, Japkowicz (2021) *Undersampling with support vectors for multi-class imbalanced data classification.* IJCNN. DOI 10.1109/IJCNN52387.2021.9533379
- **原理**：纯欠采样，且不是“对全部 `SV` 任意做一个二进制掩码后把验证集再拼回训练集”。`OCSV-US` 先对**每个类**训练 **One-Class SVM**，把该类的支持向量提取出来作为 skew-insensitive 的边界代表；然后只在这些 `SV` 上执行**进化欠采样**，进一步压缩那些 `SV` 数过多的类别，从而得到更平衡、更小的训练集。少数 `SV` 类不会再被继续删除。
- **实现**：`_support_vectors()` 对每个类独立拟合 `OneClassSVM(nu, gamma)` 并提取 `support_`，同时用 `|dual_coef_|` 作为 `SV` 显著度；`_ga_select()` 先在 `SV` 集上划分 `pool / validation`，然后只对超出目标规模的类别建立 `GA` 染色体；`_decode_mask()` 会把每个超标类修复到统一目标规模，若某类被选得过少则按 `SV` 显著度补回，过多则保留显著度更高的 `SV`；最终输出仅为选中的 `SV` 子集，不再把验证集拼回训练集。
- **参数**：`nu=0.1, gamma='scale', ga_pop=12, ga_gen=8, val_size=0.25, target_strategy='min'`。其中 `target_strategy` 控制超标类被压到最小 `SV` 类规模还是均值规模。
- **保真**：每类独立 `OC-SVM` 边界建模、`SV` 代表抽取、仅在 `SV` 集上做进化欠采样、进一步平衡训练集四条主线均已落地。
- **近似**：论文全文未公开到可逐式核验时，当前以 `|dual_coef_|` 近似“支持向量显著度”，并使用类平衡约束下的单目标 `GA` 最大化验证平衡准确率；预算仍采用工程可承受的 `pop=12 / gen=8`，但已不再保留旧版“验证集回拼”和“无类别约束任意删样”的偏差。
