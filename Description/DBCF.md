## 一、研究背景与动机

### 1.1 旋转机械故障诊断中的数据不平衡问题

旋转机械（如轴承、齿轮箱等）在工业中扮演着至关重要的角色。一旦发生故障，将导致长时间停机和高昂的维护成本。因此，对旋转机械进行早期故障检测和正确诊断，对于设备的安全运行和维护至关重要。

然而，在工程实践中存在一个根本性的矛盾：**旋转机械在其大部分服役寿命中处于正常（健康）状态，故障状态极少发生**。这意味着在状态监测数据中：

- **正常状态数据（多数类）**：数量庞大，易于获取
- **故障状态数据（少数类）**：数量极少，采集困难

这就是所谓的**数据不平衡问题（Data Imbalance Problem）**。在故障诊断领域，这一问题的专业术语为**不平衡数据相关故障诊断（Imbalanced Data related Fault Diagnosis, IFD）**。

### 1.2 传统数据驱动方法的局限性

传统的数据驱动诊断方法（如人工神经网络 ANN、支持向量机 SVM 等）在训练时**隐式假设各类别数据分布均衡**。当面对不平衡数据时，这些方法会严重偏向多数类（正常状态），导致：

- **对少数类（故障类）的分类准确率大幅下降**
- **模型产生"宁可漏报、不愿误报"的偏置**
- **少数类的特征被多数类"淹没"，无法有效学习**

直观理解：假设一个二分类问题中有 990 个正常样本和 10 个故障样本。一个"懒惰"的分类器只需将所有样本预测为"正常"，就能获得 99% 的准确率——但这个模型对故障诊断毫无用处。传统方法在不平衡数据上的困境，本质上是由于优化目标（整体准确率）与工程需求（识别故障）之间的错位。

### 1.3 现有解决方案：数据层面 vs. 算法层面

为了解决类别不平衡问题，学术界的现有方法主要分为两大类别：

#### （1）数据层面方法（Data-Level Methods）

通过**重采样（Resampling）** 手段调整各类别的样本数量，使数据集趋于平衡：

- **过采样（Over-sampling）**：
  - 代表性方法：ADASYN（自适应合成采样）、SMOTE（合成少数类过采样技术）
  - 核心思想：在少数类样本之间生成"合成"新样本，缩小多数类与少数类之间的数量差距
  - **优点**：不丢失任何原始信息
  - **缺点**：容易导致**过拟合**——生成的样本是已有样本的线性插值，并没有引入真正的新信息；随着不平衡率和数据量的增加，过拟合问题会更加严重

- **欠采样（Under-sampling）**：
  - 代表性方法：多数类欠采样技术（MUTE）
  - 核心思想：从多数类中**移除部分样本**，使各类别数量趋于平衡
  - **优点**：减少训练数据规模，加快训练速度
  - **缺点**：可能**丢失重要信息**——被移除的多数类样本中可能包含对分类有用的判别性信息

- **混合方法**：结合过采样和欠采样，取长补短

**总结**：数据层面方法虽能改善不平衡状况，但各有缺陷。过采样鼓励过拟合（如同"抄作业"——只是在已有答案上涂改而不是真正学会解题），欠采样则可能丢失关键信息。

#### （2）算法层面方法（Algorithm-Level Methods）

通过设计或修改分类算法本身来处理不平衡问题：

- **代价敏感学习（Cost-sensitive Learning）**：
  - 核心思想：为少数类的错误分类分配**更高的误分类代价**，迫使模型"重视"少数类
  - **优点**：不需要修改数据，直接在算法层面处理不平衡
  - **缺点**：代价权重的设定高度依赖具体问题和数据分布，在复杂的机械系统中合理设定代价权重本身就是一大难题

- **专用分类模型设计**：
  - 如残差学习算法、核 Fisher 判别分析、最优间隔分布机等
  - **优点**：针对特定问题精心设计，效果可以很好
  - **缺点**：**泛化能力弱**，核心参数的设置是影响方法有效性的关键，这意味着大量的手工调参工作

**总结**：算法层面方法通常对问题依赖性强，难以在不同场景间迁移，参数设置繁琐。

### 1.4 集成学习：融合两层面的优势

论文作者敏锐地观察到：**单一策略和单一分类算法往往因自身缺陷而导致不理想的分类结果**。而一种名为**集成学习（Ensemble Learning）** 的机器学习范式——通过训练多个分类器并组合使用——通常能优于单一方法。

基于这一思路，论文提出**将数据层面方法和算法层面方法集成到统一框架中**，以提升不平衡分类的准确性和稳定性。实现这一目标的关键在于：

1. 设计合适的**采样方法**（数据层面）
2. 设计合适的**基础分类器**（算法层面）
3. 确保两者之间产生**良好的协同效应（Good Synergy）**

### 1.5 gcForest 的优势与不足

#### 为什么选择 gcForest 作为基础？

- 决策树算法结构简单、分类性能好，是集成方法中常用的基础分类器
- 已证明决策树在构建不平衡数据分类的集成模型方面表现优异
- 深度学习模型在故障模式识别中已展现出强大的能力
- **gcForest（多粒度级联森林）** 是由 Zhou 和 Feng (2019) 提出的一种**基于决策树集成的非神经网络深度学习模型**，具有以下特点：
  - 采用**级联结构**（Cascade Structure），实现逐层特征处理
  - 每层接收上一层输出，处理后传给下一层，类似神经网络的反向传播
  - 层间使用**类向量（Class Vector）** 传递信息，类似于 Stacking 方法
  - 最后一层平均所有随机森林的概率分布，取最高概率作为分类结果

#### gcForest 在 IFD 中的三个核心不足：

**问题一：单一通道（Single Channel）**。gcForest 在整个模型中使用**同一批数据**训练所有随机森林，即模型中只有一条数据流的"通道"。然而，已有研究表明，采样技术与集成技术的**正向协同作用（Positive Synergy）** 有助于增强训练数据的多样性，从而提高不平衡分类的准确率。

**问题二：缺少对不同数据的集成学习**。gcForest 没有在不同数据上实现集成学习。Bagging 策略的核心优势——通过多样化数据训练多样化分类器——在 gcForest 中未能充分发挥。

**问题三：基础分类器在不平衡数据上的性能瓶颈**。决策树的传统属性选择度量（如信息增益和增益比）高度依赖数据的统计分布特性，因此受数据分布的影响很大。在不平衡数据中，**少数类对属性评估的影响力远小于多数类**（想象一下，在 990:10 的数据中，少数类的统计信号几乎被多数类完全掩盖）。

> 综上，这三方面不足——缺乏数据多样性、缺乏通道多样性、基础分类器受分布偏置影响——是设计 DBCF 的直接动机。

## 二、核心贡献与方法总览

### 2.1 三大核心贡献

**贡献一：多通道级联框架（Multi-Channel Cascade Framework）**

提出了一种面向旋转机械故障诊断的新型多通道级联框架。在这个框架中，数据层面的方法和算法层面的方法**协同工作**，各自发挥优势，共同提升不平衡分类的效果。

**贡献二：Up-down Sampling 混合采样方法**

提出了一种名为 **Up-down Sampling** 的混合采样方法，为级联森林的每个通道提供**重平衡数据集**。该方法通过以下两个步骤降低过拟合风险并提高数据多样性：
- **Up（向上采样）**：在少数类样本之间生成新样本
- **Down（向下采样）**：以一定概率丢弃类别分布边缘的样本

**贡献三：平衡森林（Balanced Forest, BF）**

设计了一种新型的**平衡森林**作为级联森林的基础分类器。其核心创新在于提出了一种新的**平衡信息熵（Balanced Information Entropy）** 作为属性评估指标，该指标基于数据的类别比例统计量进行计算，有效地消除了数据不平衡对信息熵计算的不利影响。

### 2.2 方法整体架构

DBCF 的整体架构如下图所示，从左到右的数据流展示了方法的完整流程：

```
不平衡数据
    │
    ▼
┌─────────────────────────────────────────────┐
│           Up-down Sampling                   │
│  (执行 C 次，对应 C 个通道的输入数据)          │
│                                              │
│  Step 1: 计算接受率 (Acceptance Rate)         │
│  Step 2: 生成新样本 (Up-sampling)             │
│  Step 3: 丢弃边缘样本 (Down-sampling)         │
└─────────────────────────────────────────────┘
    │          │                │
    ▼          ▼                ▼
┌────────┐ ┌────────┐     ┌────────┐
│ 通道 1  │ │ 通道 2  │ ... │ 通道 C  │   ← 每个通道是独立的级联平衡森林
│ 数据1   │ │ 数据2   │     │ 数据C   │
└────────┘ └────────┘     └────────┘
    │          │                │
    │  (每个通道自适应生成深层级联结构)   │
    │          │                │
    ▼          ▼                ▼
┌─────────────────────────────────────────────┐
│              输出合成                         │
│        (平均所有通道的最终结果)                 │
└─────────────────────────────────────────────┘
    │
    ▼
  最终分类结果
```

**核心设计理念**：
- Up-down Sampling 为每个通道提供独立的、具有差异性的重平衡训练数据
- 每个通道独立训练，自适应地生成级联层数（不同通道的层数可以不同）
- 多通道机制结合 Bagging 思想，实现了**数据多样性**和**分类器多样性**的双重保障
- 平衡森林采用平衡信息熵，确保基础分类器不受数据分布偏置的影响

## 三、方法具体实现

### 3.1 Up-down Sampling（上下采样）

Up-down Sampling 是基于**重要性采样（Importance Sampling）** 和**拒绝采样（Rejection Sampling）** 的思想设计的一种新型混合采样方法。该方法包含"向上采样"和"向下采样"两个相继执行的阶段，目标是重平衡数据分布，同时避免少数类信息的丢失。

#### 3.1.1 计算接受率（Acceptance Rate）

接受率的本质是衡量**一个样本能在多大程度上反映其所属类别的特征**。直观地说，位于类别分布中心的样本应具有高接受率（更具有类别代表性），而位于类别边缘的样本接受率较低（可能是噪声或异常值）。

接受率的计算公式为：

$$r_i = \frac{\sum_{j=1}^{n} d(x_i, x_j)}{\sum_{k=1}^{N} d(x_i, x_k)}$$

其中：
- $r_i$ 是样本 $x_i$ 的接受率
- $d(x_i, x_j)$ 是样本 $x_i$ 与 $x_j$ 之间的欧氏距离
- $n$：在距 $x_i$ 最近的 $N$ 个样本中，与 $x_i$ **同类别**的样本数量
- $N$：考虑的最近邻样本总数

**直观解释**：分子 $\sum_{j=1}^{n} d(x_i, x_j)$ 是样本 $x_i$ 到**同类别最近邻**的距离之和，反映了 $x_i$ 与该类别的"亲和度"；分母 $\sum_{k=1}^{N} d(x_i, x_k)$ 是 $x_i$ 到**所有最近邻**（不论类别）的距离之和。两者之比越大，说明 $x_i$ 的邻居中同类的比例越高（即它的分布位置更能反映"自己人"的特征），因此接受率越高。

> **类比理解**：想象一个社区中有不同国籍的人。对于某个人，如果离他最近的 10 个人中有 8 个与他同国籍，说明他住在"本国聚集区"的中心，比例 8/10 类似于接受率中同类近邻占比的权重。如果只有 2 个同国籍，那他可能生活在混居区的边缘，不是该国籍文化的"典型代表"。

#### 3.1.2 向上采样：生成新样本（Up-sampling）

向上采样过程在两个随机选择的**同类少数类样本**之间生成新的合成样本。新样本的位置由两个父样本的接受率决定，接受率高的父样本对新样本的位置贡献更大。生成公式为：

$$x' = \frac{x_i \times r_i + x_j \times r_j}{r_i + r_j}$$

其中：
- $x'$ 是生成的新样本
- $x_i$ 和 $x_j$ 是随机选择的两个少数类同类样本
- $r_i$ 和 $r_j$ 分别是 $x_i$ 和 $x_j$ 的接受率

**关键洞察**：这个公式是加权平均，权重由接受率决定。接受率高的样本更接近类别中心，因此新生成的样本会**向类别中心"靠拢"**，而不是在整个空间内任意生成。这种机制有效地减少了生成噪声样本的风险。

> **与 SMOTE 的区别**：SMOTE 在两个样本之间随机插值，而 Up-down Sampling 的插值方向由接受率加权，使得新样本更倾向于分布在"靠谱"的区域。

#### 3.1.3 向下采样：丢弃边缘样本（Down-sampling）

上采样之后，数据集近似平衡，但会存在模糊的类别边界。向下采样的目的是**使类别边界更清晰**，从而有利于后续分类。

向下采样的操作方式是：以一定概率丢弃样本，**丢弃概率等于接受率的倒数**（$1/r_i$）。这意味着：

- 接受率**高**的样本（靠近类别中心）→ 丢弃概率**低** → 大概率被保留
- 接受率**低**的样本（位于类别边缘）→ 丢弃概率**高** → 大概率被丢弃

**效果**：向下采样倾向于保留接近类别分布中心的样本，舍弃分布边缘的"可疑"样本。这使得数据集中各个类别的分布更加紧凑、边界更加清晰，从而提升分类器性能。

#### 3.1.4 Up-down Sampling 算法流程

```
算法 1: Up-down Sampling
───────────────────────────────────────
输入: 不平衡数据集 D, 最近邻数 N
输出: 重平衡数据集 D'

1. FOR 每个样本 x_i IN D:
       计算 x_i 到其他样本的欧氏距离
       找出 x_i 的 N 个最近邻
       统计 N 个最近邻中与 x_i 同类别的样本数 n
       根据公式 (1) 计算 x_i 的接受率 r_i
   END FOR

2. // 向上采样阶段
   WHILE 少数类样本数 < 目标数量:
       随机选择两个同类少数类样本 x_i 和 x_j
       根据公式 (2) 生成新样本 x' = (x_i×r_i + x_j×r_j) / (r_i + r_j)
       将 x' 加入数据集
   END WHILE

3. // 更新接受率
   重新计算所有样本的接受率

4. // 向下采样阶段（根据概率丢弃）
   FOR 每个样本 x_i IN D:
       以概率 p_discard = 1/r_i 决定是否丢弃 x_i
   END FOR

5. RETURN 重平衡数据集 D'
```

**算法特点说明**：
- 整个过程基于概率执行，因此**每次 Up-down Sampling 的结果都不同**——这天然保证了不同通道获得的数据具有差异性，从而实现了数据的多样性
- Up-down Sampling **不保证**输出数据完全平衡——向下采样旨在保留数据集的核心特征，而非强制平衡
- 论文建议**执行 C 次** Up-down Sampling，为 C 个通道分别提供数据

### 3.2 平衡森林（Balanced Forest, BF）

平衡森林是 DBCF 中每个通道级联结构使用的基础分类器。其核心创新在于设计了一种新的**平衡信息熵（Balanced Information Entropy）**，用于决策树的属性选择，从而消除数据不平衡对决策树分裂的偏置影响。

#### 3.2.1 传统信息熵的问题

传统的信息熵定义为：

$$\text{Ent}(D) = -\sum_{k=1}^{|y|} p_k \log_2 p_k$$

其中 $p_k$ 是类别 $k$ 在数据集 $D$ 中样本所占的比例。

**问题**：传统信息熵完全依赖各类别的样本数量比例。在不平衡数据中，多数类的 $p_k$ 远大于少数类的 $p_k$，导致多数类主导了熵的计算。信息增益和增益比同样受到影响——在选择分裂属性时，决策树倾向于选择对多数类有利的分裂方式，而**忽视少数类的判别信息**。

> **类比**：想象你在一个 99% 学生为男生、1% 为女生的班级中，试图通过"头发长度"来区分性别。由于男生数量碾压，即使"头发长度"对识别少数群体（女生）非常有效，传统信息熵也可能因为总体统计偏向男生而选择其他"更安全"的特征。

#### 3.2.2 平衡信息熵（Balanced Information Entropy）

为了解决上述问题，论文提出了**平衡信息熵**，其计算公式为：

$$\text{BEnt}(D) = -\sum_{k=1}^{|y|} \frac{\frac{x_k}{X_k}}{\sum_{j=1}^{|y|} \frac{x_j}{X_j}} \cdot \log_2 \left( \frac{\frac{x_k}{X_k}}{\sum_{j=1}^{|y|} \frac{x_j}{X_j}} \right)$$

其中：
- $|y|$：当前分支（节点）的类别数
- $|Y|$：数据集的总类别数
- $x_k$：集合 $D$ 中属于类别 $k$ 的样本数（当前节点的局部统计）
- $X_k$：整个数据集中属于类别 $k$ 的样本总数（全局统计）

**核心思想**：传统熵用 $p_k = x_k/|D|$（局部比例），而平衡熵用**归一化的全局比例** $\frac{x_k/X_k}{\sum x_j/X_j}$。

**直观理解**：
- $x_k/X_k$ 表示**当前节点中类别 $k$ 的样本占全局该类样本的比例**
- 除以 $\sum x_j/X_j$ 进行归一化，确保概率之和为 1
- **效果**：如果一个类别整体样本少（$X_k$ 很小），即使它在当前节点的局部数量不多（$x_k$ 小），其 $x_k/X_k$ 也可能很大，从而获得足够的"话语权"

> **类比**：传统熵是按"人数"投票，多数类人数多自然占优。平衡熵则是按"代表比例"投票——每个类别在各自群体内选出代表，无论群体大小，代表权相当。这样，即使少数类样本少，也能在分裂决策中发出足够响亮的声音。

#### 3.2.3 平衡森林的增益比计算

平衡森林中的决策树采用**增益比（Gain Ratio）** 作为分裂准则。对于属性 $a$ 的平衡信息增益比定义为：

$$\text{Gain}(D, a) = \text{BEnt}(D) - \sum_{v=1}^{V} \frac{|D^v|}{|D|} \text{BEnt}(D^v)$$

其中：
- $a$ 是属性的分裂阈值
- $V$ 是分裂产生的分支数（在本文中，$V = 2$，即为二叉决策树）
- $|D^v|$ 是分支 $v$ 中样本的数量
- $\text{BEnt}(D^v)$ 是分支 $v$ 的平衡信息熵

**小结**：平衡森林将传统决策树中的信息熵替换为平衡信息熵，从而在属性选择和分裂决策中**消除不平衡数据的统计偏置**。与标准随机森林相比，平衡森林在面对不平衡数据时能做出更公平、更合理的分裂决策。

### 3.3 多通道深度级联森林（Multi-Channel Deep Cascade Forest）

#### 3.3.1 级联结构（Cascade Structure）

DBCF 的每个通道是一个**级联森林**，其结构类似于深度神经网络中的逐层处理：

- **每层构成**：每个级联层包含 **4 个森林**，其中：
  - **2 个平衡森林（BF）**：采用平衡信息熵作为属性选择准则——"聪明"的森林
  - **2 个完全随机森林（Completely Random Forest）**：随机选择属性进行分裂——"随机"的森林

  这种"2+2"的组合具有深层含义：平衡森林负责精确分类，完全随机森林引入多样性（随机性），两者互补，防止模型陷入特定的偏置。

- **类向量的生成与拼接**：
  1. 对于每个森林，统计样本落入的叶子节点中各类别的比例，形成一个**类向量（Class Vector）**——维度等于类别数，每个元素是该类别的概率估计
  2. 4 个森林产生 4 个类向量，将它们**拼接（Concatenate）** 在一起
  3. 拼接后的向量**再与原始特征向量拼接**，作为**下一层的输入**

  **示例**：对于 4 类故障诊断问题：
  - 每个森林输出 1 个 4 维类向量
  - 4 个森林输出 4 个 4 维向量 → 拼接为 16 维
  - 加上原始特征向量（如 34 维）→ 50 维
  - 这 50 维向量作为下一层的输入

- **层间关系**：每一层以前一层的输出作为输入，自身输出传递给下一层。这意味着级联结构的中间层实际上作为**第二级学习器（Meta-learner）** 发挥作用——这是与 Stacking 集成方法思想高度相似的设计

#### 3.3.2 多通道集成

DBCF 通过执行 C 次 Up-down Sampling，为 C 个通道分别提供不同的训练数据。**论文通过试错法（trial and error）建议使用 2 个通道**：

- **通道越多**：分类器多样性越高，处理复杂分类问题的能力越强
- **通道越少**：模型效率越高，过拟合风险越低
- **通道数选择**：需根据实际分类问题的复杂度来确定

每个通道独立训练自己的级联结构，训练完成后将各通道的输出进行**平均**，得到最终类分布。类分布中**得分最高的类别**即为最终分类结果。

**优势**：与 gcForest 的单一通道不同，多通道设计天然实现了 Bagging 思想——用不同的数据训练不同的分类器。这既增加了**数据多样性**（不同通道看到不同的重采样数据），也增加了**分类器多样性**（不同通道的级联结构可能不同）。

#### 3.3.3 自适应层数生成与早停机制

DBCF 的级联层数是**自适应**确定的，不同通道的层数可以不同。具体做法是：

1. 将每个通道的训练数据分为两部分：**生长集（Growing Set）** 和**估计集（Estimating Set）**
2. 使用生长集训练新的一层
3. 使用估计集评估当前模型的性能
4. 如果性能不再提升，则**停止生长**
5. 否则继续添加新的级联层

这种自适应机制避免了手动设定层数的问题，并有效防止过拟合。在论文实验中，最大层数被设为 5。

### 3.4 DBCF 整体算法流程

```
算法: DBCF (Deep Balanced Cascade Forest)
─────────────────────────────────────────────
输入: 训练数据集 D_train, 通道数 C, 最大层数 L_max
输出: 训练好的 DBCF 模型

1. // 多通道数据准备
   FOR c = 1 TO C:
       D_c = Up-down_Sampling(D_train)  // 为每个通道生成重平衡数据
       将 D_c 划分为生长集 D_c_grow 和估计集 D_c_est
   END FOR

2. // 逐通道训练级联森林
   FOR c = 1 TO C:
       初始化第 c 通道的级联森林为空

       FOR l = 1 TO L_max:
           // 构建第 l 层的输入特征
           IF l == 1:
               X_input = 原始特征向量
           ELSE:
               X_input = [原始特征向量 || 第 l-1 层输出的类向量拼接]

           // 在第 l 层训练 4 个森林
           训练 2 个平衡森林 (BF)，每个含若干棵平衡信息熵决策树
           训练 2 个完全随机森林 (CRF)，每个含若干棵完全随机决策树

           // 生成类向量
           FOR 每个森林:
               对每个样本，计算其落入叶子节点的类分布
               生成类向量（维度 = 类别数）
           END FOR

           // 拼接输出
           将 4 个森林的类向量拼接 → 作为下一层输入或最终输出

           // 早停检查
           使用估计集评估当前通道性能
           IF 性能不再提升:
               BREAK  // 停止当前通道的生长
           END IF
       END FOR
   END FOR

3. // 最终预测
   对于测试样本 x:
       FOR c = 1 TO C:
           经过通道 c 的最后一层 → 获取类分布向量 pred_c
       END FOR
       最终预测 = argmax( mean(pred_1, pred_2, ..., pred_C) )

4. RETURN 训练好的 DBCF 模型
```

**算法要点解析**：

- **第 1 步**体现了 DBCF 的数据多样性：每个通道获得的是通过随机过程生成的、具有差异性的重平衡数据。这在本质上是对 Bagging 思想的实现。

- **第 2 步**体现了自适应深度的优势：不同通道可能因为有不同数据分布而在不同层数处停止。某些通道可能只需要 2 层就能收敛，而另一些通道可能需要 5 层——这种灵活性避免了"一刀切"式的超参数设定。

- **第 3 步**的最终预测是通过对多个通道的**平均**来实现的——这是集成学习中典型的"软投票"（Soft Voting）策略。这种策略比"硬投票"（Hard Voting）更稳定，因为它保留了每个通道的置信度信息。

### 3.5 特征提取：VMD 能量熵

DBCF 需要处理高维振动信号，为避免"维度灾难"和计算效率问题，论文采用了**变分模态分解（Variational Mode Decomposition, VMD）** 进行特征提取。

#### 特征提取流程：

1. **VMD 分解**：将原始振动信号分解为 $K$ 个本征模态函数（IMFs）。论文设置 $K=5$

2. **三类特征组合**：
   - **时域特征（12 个）**：如均值、方差、峰值、峭度等
   - **频域特征（11 个）**：如频谱重心、频谱方差等
   - **VMD 模态特征（2K+1 = 11 个）**：
     - 每个 IMF 的能量熵特征（$K$ 个）
     - 每个 IMF 的奇异值特征（$K$ 个）
     - 每个 IMF 的中心频率（$K$ 个，但编码方式不同，总计 $2K+1$）

3. **特征向量维度**：12 + 11 + 11 = **34 维**

4. **数据处理**：每个输入样本包含 1200 个采样点（0.1 秒的振动数据，采样率 12 kHz）

**为什么选择 VMD**：相比 EMD（经验模态分解），VMD 对噪声和采样的敏感性更低，分解更稳定。

## 四、实验结果与分析

### 4.1 评价指标

论文使用两个主要评价指标来评估不平衡分类结果：

#### G-mean（几何平均）

$$\text{G-mean} = \sqrt{\frac{TP}{TP+FN} \times \frac{TN}{TN+FP}}$$

- G-mean 是所有类别准确率的**几何平均值**
- 它同时考察了**正类准确率**（TPR = Sensitivity）和**负类准确率**（TNR = Specificity）
- 只有当正类和负类的分类准确率都较高时，G-mean 才会高——这对不平衡问题尤为重要
- 如果一个模型将所有样本都预测为多数类（负类），TPR≈0，G-mean≈0——这正是我们希望检测到的失败模型

#### AUC（曲线下面积）

ROC 曲线描绘了不同分类阈值下真阳性率（TPR）与假阳性率（FPR）的关系。AUC 是 ROC 曲线下的面积：

$$\text{AUC} = \frac{1 + \frac{TP}{TP+FN} - \frac{FP}{FP+TN}}{2}$$

- AUC 值越大，分类器性能越好
- AUC 等价于随机选择一个正样本和一个负样本时，分类器正确区分它们的概率——这一定义使它天然不受类别不平衡的影响
- AUC=1 表示完美分类，AUC=0.5 表示随机猜测

### 4.2 实验数据集

#### CWRU 轴承数据集

来自凯斯西储大学（Case Western Reserve University）电气工程实验室的公开数据集，包含 4 种状态：
- **NS**：正常状态（Normal State）
- **IRF**：内圈故障（Inner Race Fault）
- **BF**：滚珠故障（Ball Fault）
- **ORF**：外圈故障（Outer Race Fault）

电机转速范围为 1720-1797 RPM，不同负载条件。故障直径包括 0.007, 0.014, 0.021, 0.028 英寸。

#### MFS 数据集（机械故障综合模拟实验系统）

在华中科技大学实验室使用 SpectraQuest 公司的 MFS 设备采集。包含 5 类状态：NS, IRF, ORF, BF 和保持架故障（CF, Cage Fault）。转速范围为 10 Hz - 30 Hz。

#### 不平衡率设置

论文共构造了 **24 个实验数据集**（D1-D24），不平衡率（IR）范围从 2 到 90：

| 数据集 | 多数类 | 少数类 | IR |
|--------|--------|--------|-----|
| D1-D3 | 60 | 30/10/5 | 2/6/12 |
| D4-D6 | 60 | 30/10/5 | 2/6/12 |
| D7-D9 | 60 | 30/10/5 | 2/6/12 |
| D10-D14 | 500-900 | 100/50/10 | 5/12/9/18/90 |
| D15-D19 | 500-900 | 100/50/10 | 5/12/9/18/90 |
| D20-D24 | 500-900 | 100/50/10 | 5/12/9/18/90 |

**多数类**始终是正常状态（NS），**少数类**是各类故障状态。IR 定义为多数类样本数与少数类样本数之比。

### 4.3 对比方法

#### Case I：与通用故障诊断方法对比

- **ANN**：BP 学习算法训练的人工神经网络
- **WELM**：基于小波激活函数的极限学习机
- **SMOTE-SAE**：SMOTE 过采样结合堆叠自编码器
- **DBCF**：本文提出的方法（每层 4 个 BF，每个 BF 含 200 棵决策树，最大层数 5，2 个通道）

#### Case II：与决策树方法对比

- **Random Forest (RF)**：500 棵树
- **gcForest**：100 棵树，最大层数 5
- **DBCF**：同上设置

此对比特别设计了**小平衡数据集（SBD）、不平衡数据集（IMD）和大平衡数据集（LBD）**，以单独分析数据量和不平衡率的影响。

#### Case III：与前沿不平衡分类方法对比

- **WMODA**：数据重采样方法
- **IMH**：基于数据驱动的增量融合方法
- **CSKELM**：代价敏感极限学习机
- **DNCNN**：加权 Softmax 损失的深度归一化卷积神经网络
- **DFCM-MC**：深度模糊 C 均值聚类（半监督）
- **SMLCI**：谱元学习的无监督异质集成学习方法（无监督）
- **GAN-CNN**：增强型生成对抗网络 + 卷积神经网络

### 4.4 关键实验结果与发现

#### Case I 结果分析：

- **整体表现**：DBCF 在所有 24 个数据集上的平均精度达到 87.62%，远超 ANN (74.69%)、WELM (61.44%) 和 SMOTE-SAE (75.10%)
- **高不平衡场景**：在 IR > 10 的数据集上，DBCF 在精度、AUC 和 G-mean 三个指标中分别取得了 83.33%、91.67% 和 91.67% 的最优值占比
- **平均 AUC**：0.989（DBCF）vs. 0.894（ANN）vs. 0.852（WELM）vs. 0.943（SMOTE-SAE）
- **平均 G-mean**：0.921（DBCF）vs. 0.789（ANN）vs. 0.719（WELM）vs. 0.817（SMOTE-SAE）

#### 关键发现一：DBCF 的稳定性远优于对比方法

通过三维散点图和箱线图分析发现：
- DBCF 的样本点**紧密聚集**在坐标轴最大值附近
- 箱线图中**箱体更窄**（表明在不同数据集上结果差异小），红线更高（平均值更高）
- 这充分证明了 DBCF 在处理不平衡问题上的**准确性和稳定性**

#### 关键发现二：数据分布的重要性不亚于数据量（Case II）

- **反直觉发现**：gcForest 和 RF 在**小平衡数据集（SBD）上的表现优于在不平衡数据集（IMD）上的表现**——即使 IMD 的总数据量更大！
- 这说明**不平衡的数据分布对分类的破坏是普遍且严重的**——仅仅增加某些类别的数据可能破坏数据集的整体平衡性，反而导致更差的分类表现
- DBCF 在不同 IR 下的实验结果**非常接近**，证明 DBCF 有效改善了对不平衡问题的处理能力和稳定性

#### 关键发现三：DBCF 在极端不平衡场景下优势突出（Case III）

- 在类别数更多、IR 更高的场景下，DBCF 明显优于前沿对比方法
- 与 GAN-CNN 对比（使用相同数据源）：当 IR < 10 时表现相当，当 IR > 10 时 DBCF 展现明显优势
- DBCF 在 UCI 公共数据集上的优异表现表明该方法的**跨领域应用潜力**

### 4.5 模型效率分析

| 指标 | DBCF | ANN (batch=10) | ANN (batch=50) | WELM |
|------|------|----------------|----------------|------|
| 训练时间 | 中等 | 长 | 较短 | 最短 |
| 测试时间/样本 | ~0.0035s | ~0.0003s | ~0.0003s | ~0.0003s |
| 泛化能力 | 强 | 弱（需调参） | 弱（需调参） | 最弱 |

- DBCF 的训练效率不如 WELM 和 ANN（batch=50），但优于 ANN（batch=10）
- 测试阶段 DBCF 的速度慢于 ANN（约 10 倍），主要是因为基于决策树的推理不如矩阵运算高效
- 但 DBCF **不需要针对不同数据调整参数**，在实际应用中节省了大量人工调参成本
- 论文指出训练效率是 DBCF 的一个劣势，未来可通过**多分支决策树**和**并行计算框架**来改善

### 4.6 研究结论

1. DBCF 成功地融合了**深度级联森林**的思想，并从采样方法和决策树阈值评估函数两个维度进行了优化

2. **Up-down Sampling 和平衡信息熵之间产生了良好的正向协同效应**，这是 DBCF 模型性能出色的关键原因

3. 平均 AUC 达到 0.989，平均 G-mean 达到 0.921，分别比对比方法平均提升了 9.07% 和 13.57%

4. 分类结果**不仅取决于数据量，还受数据分布不均的影响**——现有研究未充分考虑这一问题，而 DBCF 成功地解决了它

5. DBCF 在**高不平衡率（IR > 10）场景下优势尤为明显**，超越了包括 GAN-CNN 在内的深度学习方法

## 五、方法总结与展望

### 5.1 DBCF 的优势基因

| 设计要素 | 解决的问题 | 实现手段 |
|---------|-----------|---------|
| 多通道架构 | 单通道缺乏数据多样性 | C 次 Up-down Sampling → C 个独立数据通道 |
| Up-down Sampling | 数据不平衡 | 基于接受率的生成（上采样）+ 概率丢弃（下采样） |
| 平衡信息熵 | 属性选择受数据分布偏置 | 用全局归一化比例替代局部比例 |
| 级联结构 | 深层特征提取 | 类向量逐层传递，自适应生长 |
| Bagging 集成 | 单一模型不稳定 | 多通道 + 多森林 + 差异化数据 |

### 5.2 未来改进方向

1. **多分支决策树**：目前平衡森林使用二叉决策树，可以替换为多分支决策树，并设计自适应方法确定分支数

2. **训练效率优化**：决策树训练不如矩阵运算高效，可以引入并行计算框架加速训练

3. **更多领域的应用验证**：论文仅验证了轴承故障诊断场景，结构健康监测、电网故障检测等领域可能同样适用

## 六、核心公式速查

| 公式 | 表达式 | 用途 |
|------|--------|------|
| 接受率 | $r_i = \frac{\sum_{j=1}^{n} d(x_i, x_j)}{\sum_{k=1}^{N} d(x_i, x_k)}$ | 衡量样本的类别代表性 |
| 新样本生成 | $x' = \frac{x_i \times r_i + x_j \times r_j}{r_i + r_j}$ | 基于接受率加权的合成样本 |
| 平衡信息熵 | $\text{BEnt}(D) = -\sum_{k=1}^{\|y\|} \frac{x_k/X_k}{\sum x_j/X_j} \log_2\frac{x_k/X_k}{\sum x_j/X_j}$ | 消除不平衡偏置的属性评估 |
| 平衡增益 | $\text{Gain}(D, a) = \text{BEnt}(D) - \sum_{v=1}^{V} \frac{\|D^v\|}{\|D\|}\text{BEnt}(D^v)$ | 平衡森林的分裂准则 |
| G-mean | $\text{G-mean} = \sqrt{\frac{TP}{TP+FN} \times \frac{TN}{TN+FP}}$ | 各类准确率的几何平均 |
| AUC | $\text{AUC} = \frac{1 + \frac{TP}{TP+FN} - \frac{FP}{FP+TN}}{2}$ | ROC 曲线下面积 |
