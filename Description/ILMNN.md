## 一、研究背景与动机

### 1.1 类别不平衡问题

在现实世界的分类任务中，类别不平衡（Class Imbalance）是一个普遍且严峻的挑战。许多应用场景都存在类别分布极度不均的情况，例如：

- 电力系统评估
- 疾病诊断（如骨质疏松症检测）
- 软件缺陷预测
- 图像识别

在不平衡数据集中，**多数类样本数量远超少数类样本**，导致分类器在训练过程中天然倾向于多数类，形成偏向多数类的决策边界。举例来说，当一个数据集的不平衡比（Imbalance Ratio, IR）达到 100:1 时，传统分类器可能将所有样本都预测为多数类，整体准确率看起来不错，但少数类的分类性能极差——**少数类样本几乎全部被误分为多数类**。

### 1.2 现有方法的局限性

已有大量研究致力于解决不平衡学习问题，主要分为以下几类：

1. **代价敏感方法（Cost-sensitive Methods）**：为不同类别的误分类设置不同的代价矩阵，但对噪声和离群点敏感。

2. **重采样方法（Resampling Methods）**：
   - **欠采样（Under-sampling）**：删除多数类样本。缺点：当少数类样本极小时，删除大量多数类样本会造成严重的信息损失。
   - **过采样（Over-sampling）**：生成少数类样本。代表性方法有 SMOTE（通过线性插值合成新样本）。缺点：可能在类重叠区域生成无效样本，甚至损害分类性能。

3. **集成学习方法（Ensemble Methods）**：如 EasyEnsemble、BalanceCascade 等方法结合采样策略与集成框架来改善性能。

### 1.3 研究动机与研究空白

过采样方法通常依赖 k-NN 分类器辅助样本选择，而 **k-NN 分类器的性能依赖于样本的局部分布**。因此，改善样本的局部分布对过采样方法至关重要。

近年来，**度量学习（Metric Learning）** 受到越来越多的关注。度量学习旨在学习一个特征空间，使得在该空间中相似样本距离更近，不相似样本距离更远。其中，**大间隔最近邻（Large Margin Nearest Neighbor, LMNN）** 是一种经典的度量学习方法，基于相对距离约束来优化样本的局部分布，提升 k-NN 分类器的性能。

然而，直接将度量学习应用于不平衡数据集存在以下**研究空白**：

1. **传统度量学习方法未考虑与过采样的结合**。LMNN 等传统方法学习的特征空间可能不利于过采样方法发挥作用。
2. **度量学习本身也存在类别不平衡问题**。多数类样本主导了损失函数，导致少数类样本在特征空间中被"压制"。
3. **LMNN 学习的特征空间内，类内样本分布过于聚集**，容易形成多个子簇，加剧类内不平衡问题。过采样在这样的空间中生成样本，会产生进一步的簇状分布，增加分类难度。

基于以上分析，论文提出了 **ILMNN（Imbalance Large Margin Nearest Neighbor）** 算法，通过改进 LMNN 并结合过采样，构建一个更适合不平衡数据过采样的特征空间。

## 二、核心贡献与方法

### 2.1 主要贡献

论文提出了三方面的核心贡献：

1. **提出 ILMNN 算法**：首次将度量学习专门设计为服务于过采样的特征空间学习器，发现一个适合过采样的特征空间。

2. **引入样本重加权策略**：根据样本的局部分布和类别频率，为关键样本（少数类样本和容易误分类的样本）分配更高权重，为多数类样本分配更低的权重，从而平衡不同类别对损失函数的贡献。

3. **引入 KL 散度约束**：使用 KL 散度（Kullback-Leibler Divergence）约束特征空间中的样本分布，使其与原始空间中的分布保持相似，缓解类内不平衡问题。

### 2.2 整体框架

ILMNN 的整体框架如下图所示（基于论文 Fig. 1 描述）：

```
输入：不平衡数据集 X ∈ R^{n×d}
  │
  ├─ 步骤1：计算原始空间中的样本分布 p_{ij}（公式10）
  │
  ├─ 步骤2：迭代优化投影矩阵 L
  │    ├─ 将数据投影到特征空间：X* = LX
  │    ├─ 计算样本权重 w_i（公式6, 8）
  │    ├─ 计算特征空间中的样本分布 q_{ij}（公式11）
  │    ├─ 计算 Loss_Weight（加权拉推损失）
  │    ├─ 计算 Loss_KL（KL 散度损失）
  │    ├─ 总损失 = Loss_Weight + μ_1×Loss_KL + μ_2×||M||_F^2
  │    └─ 梯度下降更新投影矩阵 L
  │
  ├─ 步骤3：得到最优投影矩阵 L
  │
  └─ 输出：在特征空间 X* = LX 上进行过采样和分类
```

核心思想：**先通过 ILMNN 学习一个适合过采样的线性特征空间，然后在这个特征空间中进行过采样生成平衡的训练集，最后训练分类器**。

## 三、方法具体实现

### 3.1 背景知识：马氏距离与 LMNN

#### 3.1.1 马氏距离（Mahalanobis Distance）

度量学习的目标是学习一个合适的距离度量。论文采用**马氏距离**的推广形式。对于数据集 $X=(x_1,...,x_n)$，维度为 $d$，两个样本 $x_i$ 和 $x_j$ 之间的马氏距离定义为：

$$d_M(x_i, x_j) = \sqrt{(x_i - x_j)^T M (x_i - x_j)}$$

其中 $M \in \mathbb{R}^{d \times d}$ 是一个**半正定矩阵**（$M \succeq 0$），可以分解为 $M = L^T L$，$L$ 为线性变换矩阵（投影矩阵）。当 $M = I$（单位矩阵）时，马氏距离退化为欧氏距离。

为简化计算，论文使用**平方马氏距离**：

$$d_M^2(x_i, x_j) = (x_i - x_j)^T M (x_i - x_j)$$

通过投影矩阵 $L$，原始数据可以线性变换到新的特征空间：$x^* = Lx$。在这个特征空间中，样本间的欧氏距离等价于原始空间中的马氏距离。

#### 3.1.2 LMNN 的损失函数

LMNN 将每个样本 $x_i$ 的 $k$ 个最近邻分为两类：
- **目标邻居（Target Neighbor）**：与 $x_i$ 同标签的最近邻 $x_j$
- **入侵者（Imposter）**：与 $x_i$ 不同标签的最近邻 $x_l$

三者构成三元组 $(x_i, x_j, x_l)$，记为 $(i,j,l) \in X_t$。

LMNN 的损失函数由两部分组成：

$$\varepsilon(M) = (1 - \mu)\varepsilon_{pull}(M) + \mu\varepsilon_{push}(M)$$

其中：

- **拉近损失（Pull Loss）**：缩小每个样本与其目标邻居的距离

$$\varepsilon_{pull}(M) = \sum_{j \sim i} d_M^2(x_i, x_j)$$

- **推远损失（Push Loss）**：使用铰链损失（Hinge Loss）确保入侵者与目标邻居之间保持至少一个单位的距离间隔

$$\varepsilon_{push}(M) = \sum_{(i,j,l) \in X_t} (1 - \theta_{il})\xi_{ijl}$$

$$\xi_{ijl} = \left[1 + d_M^2(x_i, x_j) - d_M^2(x_i, x_l)\right]_+$$

其中 $[z]_+ = \max(z, 0)$，$\theta_{il} \in \{0, 1\}$ 表示 $x_i$ 和 $x_l$ 是否属于同一类（同类别时 $\theta_{il}=1$，否则为 $0$）。$\mu \in [0,1]$ 控制拉近与推远的相对力度。

**直观理解**：LMNN 通过"拉近"同类样本、"推远"异类样本，使得 k-NN 分类器在新的特征空间中更容易做出正确分类。理想情况下，每个样本的 k 个最近邻都应该是同类的。

### 3.2 ILMNN 的核心改进一：样本重加权（Sample Reweighting）

#### 3.2.1 动机

在不平衡数据集中，少数类样本数量远少于多数类。如果对所有样本一视同仁，多数类样本将主导损失函数，导致：
- 分类器偏向多数类
- 少数类样本在特征空间中的分布得不到充分优化
- 后续过采样效果不佳

此外，靠近决策边界的样本更容易被误分类，应该给予更多关注。

#### 3.2.2 局部分布权重的计算

对于每个样本 $x_i$，计算其 $k$ 个最近邻集合 $K(x_i)$。定义 $D(x_i)$ 为 $x_i$ 的邻居中标签不同的样本集合。样本 $x_i$ 属于其他类别的概率（即"异类相似度"）计算为：

$$D_{sim}(x_i) = \frac{\sum_{x_d^M \in D(x_i^M)} e^{-\|x_i^M - x_d^M\|^2}}{\sum_{x_k^M \in K(x_i^M)} e^{-\|x_i^M - x_k^M\|^2}}$$

- 分母：$x_i$ 与其所有 k 个最近邻之间指数距离的和
- 分子：$x_i$ 与其中不同标签的邻居之间指数距离的和
- $D_{sim}(x_i) \in [0, 1]$

**直观理解**：$D_{sim}(x_i)$ 越大，说明 $x_i$ 越靠近不同类别的样本，即越容易被误分类。这个值可以理解为样本 $x_i$ 处于"危险区域"（靠近决策边界）的程度。

#### 3.2.3 综合权重的设计

为了避免如下问题：
- 当 $x_i$ 的 k 个最近邻都属于同一类时，$D_{sim}(x_i) = 0$，权重为零意味着该样本的局部分布不会被优化
- 多数类样本对损失函数的贡献过大

论文设计了如下的综合权重公式（$y_i = 1$ 表示多数类，$y_i = -1$ 表示少数类）：

$$w_i = \begin{cases} 1 + D_{sim}(x_i^M) & y_i = -1 \text{（少数类）} \\\\ \frac{|N_{min}|}{|N_{maj}|}\left[1 + D_{sim}(x_i^M)\right] & y_i = 1 \text{（多数类）} \end{cases}$$

其中：
- **常数项 1** 确保所有样本都有非零权重，避免局部优化的遗漏
- **$D_{sim}(x_i)$** 为靠近决策边界的样本赋予更高权重
- **$\frac{|N_{min}|}{|N_{maj}|}$** 为不平衡比的倒数（IR 的倒数），用于压低多数类样本的整体贡献，使得多数类与少数类对损失函数的贡献趋于平衡

**直观类比**：这就像教练在训练球队时，对那些容易失误的球员（靠近边界的样本）和人数较少的特殊球员（少数类样本）给予更多的训练关注，同时对人数较多的普通球员适当降低投入，使资源分配更均衡。

#### 3.2.4 加权后的损失函数

将样本权重 $w_i$ 融入 LMNN 的损失函数中：

$$Loss_{Weight} = \sum_{(i,j,l) \in X_t} w_i\left[(1 - \theta_{il})\xi_{ijl} + \sum_{j \sim i} d_M^2(x_i, x_j)\right]$$

**效果**：
- 少数类样本和容易被误分类的样本受到更大的"拉力"和"推力"
- 这些关键样本的同类邻居被更紧密地拉近，异类样本被更远地推离
- 多数类样本对损失函数的影响被有效抑制

### 3.3 ILMNN 的核心改进二：KL 散度约束

#### 3.3.1 动机

原始的 LMNN 存在一个缺陷：它会不断缩小锚点样本与其目标邻居之间的距离，导致**类内样本向锚点聚集，形成多个子簇**。这种簇状的类内分布加剧了**类内不平衡问题**（Intra-class Imbalance）。当过采样方法在这样的特征空间中生成新样本时，会在每个子簇内部生成更多样本，进一步强化了簇状分布，反而增加了分类的难度。

为解决这一问题，论文引入 KL 散度来约束特征空间中样本的分布，使其尽可能**保持原始空间中样本的局部近邻关系**。

#### 3.3.2 概率分布的定义

设 $x_i$ 为原始空间中的样本，$x_i^M = Lx_i$ 为特征空间中对应的投影样本。$P_i$ 和 $Q_i$ 分别表示样本 $x_i$ 在原始空间和特征空间中的邻居概率分布。

**原始空间中的邻居概率** $p_{ij}$（仅考虑同类别样本）：

$$p_{ij} = \frac{e^{-\|x_i - x_j\|^2}}{\sum_{\{l|y_i=y_l\}} e^{-\|x_i - x_l\|^2}}$$

**特征空间中的邻居概率** $q_{ij}$：

$$q_{ij} = \frac{e^{-\|x_i^M - x_j^M\|^2}}{\sum_{\{l|y_i=y_l\}} e^{-\|x_i^M - x_l^M\|^2}}$$

两个概率分布的定义都使用了 Softmax 形式的归一化指数距离。距离越近的样本对，其概率值越高；距离越远的样本对，概率趋近于零。

#### 3.3.3 KL 散度损失

样本 $x_i$ 在原始空间与特征空间中概率分布的 KL 散度为：

$$KL(P_i \| Q_i) = \sum_{\{j|y_i=y_j\}} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

KL 散度衡量的是两个概率分布之间的差异。其值越小，说明特征空间中的局部分布与原始空间越相似。

由于原始空间中的分布 $P_i$ 在训练过程中保持不变（$p_{ij}$ 是固定的），KL 散度可以**退化为交叉熵**（去掉常数项）：

$$KL(P_i \| Q_i) = \sum_{\{j|y_i=y_j\}} -p_{ij} \log q_{ij}$$

将所有样本的交叉熵求和，得到 **KL 散度损失**：

$$Loss_{KL} = \sum_i KL(P_i \| Q_i) = \sum_i \sum_{\{j|y_i=y_j\}} -p_{ij} \log q_{ij}$$

**直观理解**：KL 散度就像一个"分布保持器"，确保在拉近同类样本的同时，不破坏原始数据的局部近邻结构。这避免了样本过度聚集到一个点上，防止了类内子簇的过度形成，为后续过采样创造了一个更平滑、更均匀的类内分布。

### 3.4 ILMNN 的整体目标函数

将加权损失、KL 散度损失和正则化项组合，得到 ILMNN 的完整目标函数：

$$\min_M \sum_{j \sim i} w_i(1 - y_{il})\left[1 + d_M^2(x_i, x_j) - d_M^2(x_i, x_l)\right]_+$$

$$+ \mu_1 \sum_c \sum_{\{i,j|y_i=y_j\}} -p_{ij} \log q_{ij}$$

$$+ \sum_{j \sim i} w_i d_M^2(x_i, x_j) + \mu_2 \|M\|_F^2$$

$$\text{s.t. } M \succeq 0$$

其中：
- **第一项**：加权的推远损失（Push Loss），使用 hinge loss 确保不同类样本保持距离
- **第二项**：KL 散度约束项，$\mu_1$ 控制其重要性（论文推荐 $\mu_1 = 10$）
- **第三项**：加权的拉近损失（Pull Loss），拉近同类样本
- **第四项**：F-范数正则化项 $\mu_2 \|M\|_F^2$，防止过拟合（论文设置 $\mu_2 = 0.5$）

### 3.5 优化过程

#### 3.5.1 从 PSD 到梯度下降

原始 LMNN 使用半正定规划（Positive Semi-definite Programming, PSD）来优化 $M$，但 PSD 计算复杂度高。由于 $M$ 是半正定矩阵，可以分解为 $M = L^T L$，论文**直接对投影矩阵 $L$ 进行梯度下降**，效率更高。

#### 3.5.2 距离的导数

定义外积矩阵 $C_{ij} = (x_i - x_j)(x_i - x_j)^T$，特征空间中的平方距离可表示为：

$$d_M(x_i, x_j) = Tr(C_{ij}M)$$

对投影矩阵 $L$ 的导数为：

$$\nabla_L d_M(x_i, x_j) = 2L(x_i - x_j)(x_i - x_j)^T = 2LC_{ij}$$

#### 3.5.3 加权损失的梯度

$$\nabla_L^{t+1} Loss_{Weight} = 2L^t \sum_i w_i^t \left(\nabla_L \varepsilon_{push} + \nabla_L \varepsilon_{pull}\right)$$

其中：

$$\nabla_L \varepsilon_{pull} = \sum_{j \sim i} C_{ij}$$

$$\nabla_L \varepsilon_{push} = \sum_{(i,j,l) \in X_t} (C_{ij} - C_{il})$$

#### 3.5.4 KL 散度损失的梯度

首先，将 $q_{ij}$ 代入 KL 散度损失进行变形：

$$Loss_{KL} = \sum_{(i,j)} p_{ij}\left[d_M(x_i, x_j) + \log \sum_{\{i,l|y_i=y_l\}} e^{d_M(x_i, x_l)}\right]$$

交叉熵的导数为：

$$\nabla_L (p_{ij} \log q_{ij}) = \frac{p_{ij}}{q_{ij}} \nabla_L q_{ij}$$

最终得到：

$$\nabla_L^{t+1} Loss_{KL} = 2L \sum_{(i,j)} p_{ij} \left(C_{ij} - \sum_{\{i,l|y_i=y_l\}} q_{ij} C_{il}\right)$$

#### 3.5.5 总体梯度更新

$$\nabla_L^{t+1} Loss = \nabla_L^{t+1} Loss_{Weight} + \nabla_L^{t+1} Loss_{KL} + 4ML$$

利用梯度下降不断更新 $L$，直到收敛：

$$L^{t+1} = L^t - \eta \nabla_L Loss$$

### 3.6 算法流程

以下是 ILMNN 的完整算法流程，以中文伪代码呈现：

---

**算法 1：ILMNN（不平衡大间隔最近邻）**

**输入**：训练集 $X = (x_1, x_2, \ldots, x_n)$
**参数**：最近邻个数 $k$，权衡参数 $\mu_1$ 和 $\mu_2$
**初始化**：投影矩阵 $L = I$（单位矩阵）

**过程**：

1. **for** $i = 1, 2, \ldots, N$ **do**
2.     根据公式 (10) 计算原始空间中样本 $x_i$ 的邻居概率分布 $p_{ij}$
3. **end for**
4. **while** 未收敛 **do**
5.     将数据投影到特征空间：$X^* = LX$
6.     **for** $i = 1, 2, \ldots, N$ **do**
7.         根据公式 (6) 和 (8) 计算样本权重 $w_i$
8.         根据公式 (11) 计算特征空间中样本的邻居概率分布 $q_{ij}$
9.     **end for**
10.    根据公式 (14) 计算总体目标函数 $Loss$
11.    根据公式 (22) 更新投影矩阵 $L$：
        $$L^{t+1} = L^t - \eta \nabla_L Loss$$
12.    检查目标函数是否收敛
13. **end while**

**输出**：投影矩阵 $L$

---

**中文解释**：

- **步骤 1-3（预处理阶段）**：对每个样本，在原始空间中计算其与同类别样本之间的邻居概率分布 $p_{ij}$。这个分布在整个训练过程中保持不变，作为 KL 散度约束的"锚点"。

- **步骤 4-13（迭代优化阶段）**：
  - **步骤 5（投影）**：将原始数据通过当前投影矩阵 $L$ 映射到特征空间。
  - **步骤 6-9（计算权重和分布）**：在特征空间中重新计算每个样本的 $w_i$（基于局部异类密度和类别不平衡比）和 $q_{ij}$（同类的邻居概率分布）。
  - **步骤 10（评估损失）**：计算包含加权拉推损失、KL 散度损失和正则化项的总体目标函数值。
  - **步骤 11（梯度下降）**：利用链式法则计算损失函数对 $L$ 的梯度，沿负梯度方向更新 $L$。
  - **步骤 12（收敛判断）**：当目标函数值变化小于预设阈值时停止迭代。

### 3.7 时间复杂度分析

ILMNN 的时间复杂度由以下五个部分构成（$n$ 为样本数，$d$ 为特征维数，且 $d \ll n$）：

| 计算步骤 | 复杂度 |
|---------|--------|
| 数据投影（$X^* = LX$） | $O(nd^2)$ |
| 寻找样本邻居 | $O(dn^2)$ |
| 计算样本权重 $w$ | $O(n)$ |
| 计算 KL 散度 | $O(n^2)$ |
| 计算外积 $C_{ij}$ | $O(nd^2)$ |

总体时间复杂度：$T_{ILMNN} = O(nd^2 + dn^2 + n^2 + n + nd^2) = O(n^2)$（由于 $d \ll n$）

## 四、实验结果与分析

### 4.1 数据集

实验使用了来自 KEEL 和 UCI 的 **16 个真实世界数据集**，覆盖了不同的样本规模、特征维度、类别数和不平衡比（IR）。对于多类别数据集，通过合并类别将其转化为二分类（多数类 vs 少数类）问题。

### 4.2 对比方法

**度量学习方法**：
- **LMNN** [24]：经典大间隔最近邻方法（$k=5$, $\mu_1=0.5$, $\mu_2=0.5$）
- **ITML** [35]：信息论度量学习（约束数=80, $\gamma=1$）
- **IML** [53]：面向不平衡数据的 LMNN 变体（$k=5$, $a=b=0.5$, $m=100$, $\lambda=0.1$）

**过采样方法**（在度量学习学得的特征空间中进行）：
- **SMOTE** [28]：合成少数类过采样（$k=5$）
- **ADASYN** [29]：自适应合成采样（$k=5$）
- **MWMOTE** [30]：多数类加权少数类过采样（$k_1=k_2=k_3=5$）

**分类器**：
- k-NN 分类器（$k=3$）
- 高斯朴素贝叶斯分类器

### 4.3 评价指标

由于在不平衡问题中，总体准确率会偏向多数类，论文使用以下两个指标：

1. **G-means（几何均值）**：

$$G\text{-}means = \sqrt{\frac{TP}{TP + FN} \times \frac{TN}{TN + FP}}$$

其中 $TP$（True Positive）为少数类被正确分类的数量，$TN$（True Negative）为多数类被正确分类的数量。G-means 综合考虑了多数类和少数类的分类性能。

2. **AUC（Area Under ROC Curve）**：ROC 曲线下的面积，综合了精确率和召回率，越接近 1 表示性能越好。

实验采用**五折交叉验证**，报告平均值和方差。

### 4.4 ILMNN 参数设置

- 最近邻个数：$k = 5$
- KL 散度权衡参数：$\mu_1 = 10$
- 正则化参数：$\mu_2 = 0.5$
- 计算样本权重 $w$ 时考虑 4 个最近邻

### 4.5 主要实验结果

#### 4.5.1 与度量学习方法的对比

在 SMOTE 作为过采样方法、采用 k-NN 和朴素贝叶斯分类器的设定下：

1. **LMNN、ITML、IML 未能显著提升 SMOTE 的性能**。原因：这些方法从分类器的角度优化样本分布，而非从过采样的角度，学得的特征空间无法有效改善过采样的效果。

2. **ILMNN 大幅领先**：
   - 使用 k-NN 分类器时，在 **13/16 个数据集上获得最优 AUC**，在 **11/16 个数据集上获得最优 G-means**
   - 使用朴素贝叶斯分类器时，在 **10/16 个数据集上获得最优 G-means**
   - 在 AUC 和 G-means 的平均值和排名上均取得最佳

#### 4.5.2 与不同过采样方法的对比

采用 ADASYN 时：
- ILMNN 的平均 AUC **超出其他度量学习方法 1.5%**
- ILMNN 的平均 G-means **超出其他度量学习方法 2% 以上**

采用 MWMOTE 时：
- ILMNN 同样优于其他度量学习方法

这说明 ILMNN 学得的特征空间具有**对不同过采样方法的通用适配能力**。

#### 4.5.3 消融实验（Ablation Study）

为了验证各组件的作用，论文对比了四种变体：
- **LMNN**：原始方案
- **Weight-LMNN**：仅加入样本重加权，不加 KL 散度
- **KL-LMNN**：仅加入 KL 散度（$\mu_1=10$），不加样本重加权
- **ILMNN**：同时包含重加权和 KL 散度

结果：Weight-LMNN 和 KL-LMNN 在大多数数据集上都优于 LMNN，**ILMNN 在四种算法中表现最优**。验证了重加权策略和 KL 散度两个组件各自有效，且联合使用效果最佳。

#### 4.5.4 参数 $\mu_1$ 的影响

在 glass、ecoli4、climate、yeast、thoraric_surgery 和 winequality_red 六个数据集上考察了 $\mu_1$ 的影响（取值集合 $\{0, 0.5, 1, 2, 5, 10, 15, 20\})$：

- 当 $\mu_1$ 过小：KL 散度的贡献不足，性能主要受原始 LMNN 和重加权影响
- 当 $\mu_1$ 逐渐增大到 **10**：KL 散度的正则化效果达到最优
- 当 $\mu_1$ 过大：KL 散度主导损失函数，忽略了其他组件的作用，性能下降
- **推荐值**: $\mu_1 = 10$

#### 4.5.5 非参数统计检验

使用 **Friedman 检验** 和事后检验（Bonferroni-Dunn、Holm、Hochberg、Hommel 检验）验证 ILMNN 与对比算法之间是否存在显著差异：

- ILMNN 的**平均排名最优**
- 所有 p 值均小于显著性水平 $\alpha = 0.05$
- 结论：**ILMNN 在统计上显著优于其他对比算法**

## 五、总结与展望

### 论文总结

ILMNN 提出了一种将度量学习与过采样有机结合的不平衡分类解决方案：

1. **创新点一（样本重加权）**：基于局部异类密度和类别频率的双重权重机制，使模型更关注少数类和易误分类样本，同时抑制多数类的过度影响。

2. **创新点二（KL 散度约束）**：通过限制特征空间中的样本分布与原始分布保持相似，有效缓解了类内不平衡和子簇过度形成的问题。

3. **高效优化**：直接对投影矩阵 $L$ 进行梯度下降，避免了半正定规划的高计算复杂度。

### 未来工作

1. 结合其他距离度量（如 Wasserstein 距离）以获得更好的特征空间
2. 设计专门适配 ILMNN 的新型过采样方法
3. 将集成学习与 ILMNN 结合以处理不平衡数据分类问题
