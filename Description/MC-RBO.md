## 一、研究背景与动机

### 1.1 不平衡数据分类的挑战

在现实世界的模式分类任务中，最重要或最受关注的类别往往严重欠代表（underrepresented），这就是**类不平衡问题**（class imbalance problem）。大多数研究集中在**二分类**（binary）场景：样本数量多的类别称为**多数类**（majority class），样本数量少的类别称为**少数类**（minority class）。

传统的分类算法倾向于偏向多数类，因为以准确率（accuracy）或均匀损失函数（uniform loss function）为导向的训练过程会假设所有样本同等重要。为了达到最高准确率或最低损失，分类器自然会"忽略"少数类，导致模型泛化能力受损，甚至产生过拟合。

然而，类别之间的不平衡比例（Imbalance Ratio, IR）**并不是**导致学习困难的唯一原因：
- 如果不同类别的分布虽然在数量上不平衡，但在特征空间中**分离得很好**（well separated），构建高效分类器并不困难
- 真正的困难在于少数类样本往往形成**未知结构的稀疏小簇**（scattered small clusters of unknown structure）
- 训练集中少数类样本数量不足，导致学习算法无法获得足够的**泛化能力**（generalization level），从而产生**过拟合模型**（overfitted model）

### 1.2 多类不平衡的特殊挑战

当问题从二分类扩展到**多分类**（multiclass）时，挑战显著加剧：

1. **复杂的关系结构**：在二元问题中，类别之间的关系容易定义（多数 vs 少数）；而在多类问题中，类别之间的相互关系极其复杂。一个类别可能相对于某些类是少数类，相对于另一些类又是多数类，形成了多层次的"多重少数类"（multiminority）和"多重多数类"（multimajority）结构。

2. **二元分解的局限性**：将多类问题分解为多个二分类子问题（如一对其余 OVA 或一对一 OVO）是一种简单做法，但会丢失宝贵的**非成对（nonpairwise）数据特征视角**。OVO 方式会产生 $M(M-1)/2$ 个分类器，数量随类别数平方增长；OVA 方式将 $M-1$ 个类合并为负类，反而**加剧**了不平衡。

3. **数据级困难在多类场景中更加突出**：
   - **类别重叠**（class overlap）和**边界实例**（borderline instances）可能来自两个以上类别
   - **小分离簇**（small disjuncts）和**异常值**（outliers）可能同时影响多个类别的决策边界
   - 对单个类别的样本生成或删除操作，需要仔细分析它对其他类别实例的影响

### 1.3 现有过采样方法的局限性

过采样方法（oversampling）在不平衡分类中非常流行，因为它们以**预处理方式**工作——任何分类器都可以使用平衡后的数据集。但现有方法（包括 SMOTE 及其变体）存在共同缺陷：

1. **仅使用少数类的信息**：大多数方法在生成新样本时只考虑当前被过采样的类别特征，完全忽略了其他类别信息，导致：
   - 人工样本的放置位置不理想
   - 类别间的重叠可能增加
   - 原始类别分布可能发生偏移（dataset shift）

2. **过度依赖最近邻**：如 SMOTE 等方法基于最近邻（Nearest Neighbors, NNs）生成人工样本，对非典型数据分布、类别重叠和小分离簇非常敏感。在多类场景中，这些问题更加严重。

> **直观理解**：SMOTE 等方法的思路是"在少数类样本之间的连线上插值生成新样本"，但这个方法有两个致命缺陷：(1) 它完全无视多数类样本的位置——如果在少数类之间的连线上恰好有大量多数类样本，生成的新样本反而会混淆决策边界；(2) 当少数类本身形成多个不相连的小簇时，在两个不同簇的样本之间插值会产生毫无意义的噪声样本。

图 2（原文）生动地展示了这个问题：使用 STATIC-SMOTE 过采样后，生成的人工样本大量覆盖了多数类的聚类区域，导致训练后的分类器对少数类产生不合理的偏向。

### 1.4 本文动机

为了解决上述问题，本文提出了一种全新的思路：**不基于最近邻，而是利用所有类别信息来引导人工样本的生成**。核心思想是使用**势函数**（potential function）来建模每个点在特征空间中的"归属度"，并选择势函数差异最小的区域（即类别边界最不确定的区域）来生成新样本。

## 二、核心贡献与方法

### 2.1 主要贡献

1. **提出 MC-RBO 算法**：一种智能化的多类数据过采样方法，利用每个类别的局部数据特性来指导过采样。

2. **利用所有类别的信息**：首次在过采样过程中使用来自**所有类别**的信息来进行人工样本生成。这确保了新样本的放置更加精准，对少数类的增强更加有针对性。

3. **非最近邻的样本生成方法**：生成人工样本时不依赖少数类实例的最近邻关系，使 MC-RBO 对非典型数据分布具有鲁棒性。

4. **详细的计算复杂度分析**：展示了方法在预处理时间和不平衡数据处理改进之间的可靠权衡。

5. **全面的实验评估**：在 20 个多类不平衡基准数据集上进行实验，与多种现有最优方法进行全面比较。

### 2.2 总体思路：基于势函数的径向过采样

MC-RBO 的核心思想可以总结为一句话：**"在类别势函数差异最小的区域生成新样本"**。

直觉理解：想象特征空间中的每一个已有样本都像一个带有"能量场"（energy field）的点。这个能量场在样本点附近最强，随着距离增加而衰减。对于每个类别，我们可以计算空间中任意一点的"类别势"（class potential），表示该点被此类别的样本"吸引"的程度。两个类别的势函数之差（即**互类势**，mutual class potential）反映了该点属于哪个类别的不确定性——当差值接近零时，说明该点对两个类别的归属度相似，正是类别边界应该经过的位置，也就是最适合生成人工样本以增强少数类的区域。

## 三、方法具体实现

### 3.1 势函数的定义与计算

#### 3.1.1 高斯径向基函数（Gaussian RBF）

MC-RBO 使用高斯径向基函数（Gaussian Radial Basis Function）来建模每个样本点的"影响力"。RBF 是一个实值函数，其值仅取决于与中心点的距离。

给定：
- 一个观察样本集合 $X$
- 参数 $\gamma$ 表示单个 RBF 的扩散范围（spread）
- 空间中的一个点 $x$
- 使用 **L1 范数**（曼哈顿距离）作为距离度量

**势函数**（Potential Function）定义为：

$$\Phi(x, X, \gamma) = \sum_{i=1}^{|X|} e^{-\left(\frac{\|X_i - x\|_1}{\gamma}\right)^2}$$

其中：
- $|X|$ 是集合 $X$ 中的样本数量
- $X_i$ 是集合中第 $i$ 个样本
- $\|X_i - x\|_1$ 是 $X_i$ 和 $x$ 之间的 L1 距离（曼哈顿距离），即 $\sum_{j=1}^{m} |X_{i,j} - x_j|$
- $\gamma$ 是控制 RBF 扩散范围的参数
- $e^{-(\cdot)^2}$ 是高斯核函数

**公式含义的直观解释**：
- 对于集合 $X$ 中的每一个样本 $X_i$，计算它到点 $x$ 的 L1 距离，除以 $\gamma$ 后平方取负指数
- 当 $x$ 靠近 $X$ 中的许多样本时，每一项 $e^{-(\|X_i - x\|_1 / \gamma)^2}$ 都接近 1，因此 $\Phi$ 值大
- 当 $x$ 远离 $X$ 中的所有样本时，每一项都接近 0，因此 $\Phi$ 值小
- 势函数 $\Phi$ 本质上衡量了**点 $x$ 与集合 $X$ 中所有样本的累积邻近度**（cumulative proximity）

#### 3.1.2 $\gamma$ 参数的影响

$\gamma$ 参数控制单个 RBF 的扩散范围：
- **较大的 $\gamma$**：产生更平滑（smoother）的势函数，远处样本的影响力更大
- **较小的 $\gamma$**：产生集中在已有样本周围的势函数，远处样本的影响力较小

原文图 3 展示了不同 $\gamma$ 值下势函数的可视化效果：
- 无论 $\gamma$ 如何，势函数在类别聚类内部和附近取最高值
- 互类势（两个类别势函数的差值）在类别分布重叠的低确定性区域取最小绝对值

### 3.2 类别势（Class Potential）和互类势（Mutual Class Potential）

记 $X^{(c)}$ 为属于类别 $c$ 的样本子集合。

- **类别势**（Class Potential）：针对特定类别 $c$ 计算的势 $\Phi(x, X^{(c)}, \gamma)$
- **互类势**（Mutual Class Potential）：两个不同类别的势函数之差

在二分类场景中：
- **高互多数类势**（high mutual majority class potential）：多数类的势远大于少数类的势
- **高互少数类势**（high mutual minority class potential）：少数类的势远大于多数类的势
- **互类势接近零**：表示高度的不确定性——该点对两个类别的归属度相似，正是类别边界所在区域

$$\Phi_{mutual}(x) = \Phi(x, X_{maj}, \gamma) - \Phi(x, X_{min}, \gamma)$$

### 3.3 二分类径向过采样（B-RBO）

#### 3.3.1 算法思想

在二分类场景中，B-RBO 将人工少数类样本放置在**互类势接近零**（即 $|\Phi_{mutual}(x)| \approx 0$）的区域。这是一种折中策略——既不过分偏向多数类，也不过分偏向少数类，而是选择类别边界上最不确定的位置来增强少数类。

#### 3.3.2 优化算法：改进的爬山算法

B-RBO 使用**改进的爬山算法**（modified hill climbing algorithm）来寻找合适的位置并生成人工样本：

1. **初始化**：随机选择一个已有的少数类样本作为起始位置 $x_0$
2. **随机方向平移**：在随机选择的坐标轴方向上，将 $x_0$ 平移一个步长（step）
3. **比较互类势**：如果平移后的位置拥有更小的互类势绝对值（即 $|\Phi'_{mutual}| < |\Phi^0_{mutual}|$），则保留该位置
4. **迭代**：重复步骤 2-3 进行指定迭代次数（iterations）
5. **生成样本**：将最终位置作为一个新的人工少数类样本
6. **平衡**：重复以上过程直到类别分布完全平衡

#### 3.3.3 势函数近似（Potential Approximation）

为降低计算成本，B-RBO 使用**势函数近似**：不基于所有已有样本计算势函数，而只使用初始少数类样本的 $k$ 个最近邻来近似计算。

#### 3.3.4 B-RBO 伪代码及详细解释

**算法 1：B-RBO（Binary Radial-Based Oversampling）**

```
输入: 
  X_maj  — 多数类观察样本集合
  X_min  — 少数类观察样本集合
参数:
  γ       — 径向基函数的扩散范围
  step    — 优化步长
  iterations — 每个合成样本的迭代次数
  k       — 用于势函数近似的最近邻数量
输出:
  S       — 合成的少数类观察样本集合

函数 B-RBO(X_maj, X_min, γ, step, iterations, k):
    S ← ∅
    为 X_min 中的每个样本找到来自 X_maj ∪ X_min 的 k 个最近邻
    
    当 |X_min| + |S| < |X_maj| 时循环:   // 直到类别平衡
        x₀ ← 从 X_min 中随机选择一个观察样本
        X⁰_maj, X⁰_min ← 属于 x₀ 的 k 个最近邻中的多数类和少数类样本集合
        
        Φ₀ ← Φ(x₀, X⁰_maj, γ) − Φ(x₀, X⁰_min, γ)   // 计算初始互类势
        
        for i ← 1 to iterations:
            direction ← 在 m 维欧氏空间中随机选择一个标准基向量
            sign ← 从 {−1, 1} 中随机选择
            x' ← x₀ + direction × sign × step   // 沿选定方向平移
            
            Φ' ← Φ(x', X⁰_maj, γ) − Φ(x', X⁰_min, γ)   // 计算新位置的互类势
            
            if |Φ'| < |Φ₀|:   // 如果互类势绝对值减小（即更接近零）
                x₀ ← x'
                Φ₀ ← Φ(x', X⁰_maj, γ) − Φ(x', X⁰_min, γ)
            end if
        end for
        
        S ← S ∪ {x₀}   // 将优化后的位置加入合成样本集合
    end while
    
    return S
```

**伪代码逐行解释：**

- **第 6 行**：初始化合成样本集合 $S$ 为空集。
- **第 7 行**：为少数类中的每个样本预先计算其 $k$ 个最近邻（从所有训练样本中）。这一步的目的是后续可以用这些最近邻来**近似计算**势函数，而不需要动用全部样本，从而大幅降低计算成本。
- **第 8 行**：外层循环条件——只要少数类样本加上已生成的合成样本数量仍少于多数类，就继续生成新样本。这是为了实现**完全平衡**（即最终少数类总样本数 = 多数类样本数）。
- **第 9 行**：从少数类中**随机**选择一个样本作为优化的起点。这种随机选择保证了生成样本的多样性。
- **第 10-11 行**：提取 $x_0$ 的 $k$ 个最近邻，将它们按类别分为多数类部分 $X^0_{maj}$ 和少数类部分 $X^0_{min}$。后续的势函数计算只在这 $k$ 个邻居上进行。
- **第 12 行**：计算起始位置的**互类势**。注意这里计算的是多数类势减去少数类势，而不是绝对值。当这个值大于 0 时说明该点"更像多数类"，小于 0 时"更像少数类"，接近 0 时最不确定。
- **第 13-21 行**：内层优化循环——进行 `iterations` 次随机搜索，试图找到互类势绝对值更小的位置。
  - **第 14 行**：随机选择一个**标准基向量**（standard basis vector），即在 $m$ 个特征维度中随机选一个维度。这相当于只沿单个坐标轴方向移动。
  - **第 15 行**：随机选择移动的**方向**（正向或负向）。
  - **第 16 行**：沿选定方向移动一个步长，得到候选位置 $x'$。
  - **第 17 行**：计算候选位置的互类势。
  - **第 18-20 行**：如果候选位置的互类势绝对值更小（即更接近 0，说明该位置对两个类别的归属更不确定），则**接受**该位置。否则**保持**原位置不变。这是爬山算法的核心——只接受更好的解。
- **第 22 行**：将经过 `iterations` 次迭代优化后的最终位置加入到合成样本集合 $S$ 中。

> **直观理解爬山过程**：想象你在一个起伏的地形上行走，你的目标是走到海拔为零的"海平面"（即互类势接近零的位置）。每一步你随机选择一个方向走一步，如果新位置比当前位置更接近海平面，你就搬过去；否则你留在原地。经过足够多步后，你往往会移动到一个非常接近海平面的位置。

### 3.4 多类径向过采样（MC-RBO）

#### 3.4.1 多类扩展策略

MC-RBO 通过**迭代过采样**的方式将 B-RBO 扩展到多类场景。核心思路是**一次处理一个类别**，将该类别视为"少数类"，将已处理过的类别组成的"合并多数类"视为多数类。

#### 3.4.2 类别排序与合并多数类构建

1. **按样本数降序排序**：将所有类别按照拥有的样本数量从多到少排列。样本最多的类称为"多数类"。

2. **逐个处理少数类**：对于除多数类外的每个类别 $C_i$：
   - **构建合并多数类** $X_{maj}$：从所有**已经处理过**的类别（即样本数比 $C_i$ 更多的类别）中，各随机抽取 $\lfloor |X^{(C_1)}| / n_{classes} \rfloor$ 个样本。其中 $|X^{(C_1)}|$ 是最大类的样本数，$n_{classes}$ 是已处理过的类别数。
   - **等权表示**：每个已处理类别在合并多数类中拥有**相同数量**的样本，确保样本数较多的类别不会主导势函数的计算。
   - 调用 B-RBO 算法，以 $X^{(C_i)}$ 为少数类，以合并多数类为多数类，生成合成样本 $S_i$。
   - 生成的合成样本 $S_i$ 也会被加入到后续类别的合并多数类构建中。

#### 3.4.3 与 OVA 策略的对比

传统 OVA（一对其余）分解方法将所有其他类合并为多数类，但会导致大类别在势函数计算中的**主导地位**。MC-RBO 的合并策略有两个优势：
1. **降低计算成本**：合并多数类的样本数少于全部其他类的样本总数
2. **等权表示**：每个类别在合并多数类中拥有相同数量的样本，避免大类别主导势函数

#### 3.4.4 MC-RBO 伪代码及详细解释

**算法 2：MC-RBO（Multiclass Radial-Based Oversampling）**

```
输入:
  X       — 所有观察样本的集合，X⁽ᶜ⁾ 表示属于类别 c 的子集合
参数:
  γ       — 径向基函数的扩散范围
  step    — 优化步长
  iterations — 每个合成样本的迭代次数
  k       — 用于势函数近似的最近邻数量
输出:
  S       — 所有合成样本的集合，Sᵢ 表示第 i 类的合成样本

函数 MC-RBO(X, γ, step, iterations, k):
    S ← ∅
    C ← 所有类别的集合，按照每个类别对应的样本数量降序排列
    
    for i ← 1 to |C|:   // 遍历每个类别（从样本最多的到最少的）
        n_classes ← 样本数量比 Cᵢ 更多的类别数量
        
        if n_classes = 0:   // Cᵢ 是最大的类，不需要过采样
            Sᵢ ← ∅
        else:
            X_min ← X⁽Cⁱ⁾   // 当前类作为少数类
            X_maj ← ∅        // 构建合并多数类
            
            for j ← 1 to n_classes:
                从 X⁽ʲ⁾ ∪ Sⱼ 中随机选择 ⌊|X⁽¹⁾| / n_classes⌋ 个样本
                添加到 X_maj
            end for
            
            Sᵢ ← B-RBO(X_maj, X_min, γ, step, iterations, k)
        end if
    end for
    
    return S
```

**伪代码逐行解释：**

- **第 6 行**：初始化合成样本集合 $S$ 为空。$S$ 是一个二维结构，每个元素 $S_i$ 对应一个类别的合成样本集合。
- **第 7 行**：将 $C$ 中所有类别按样本数**降序排列**。这是一个关键步骤——确保了处理顺序是从"最有代表性"的类别开始，逐步到"最需要增强"的类别。
- **第 8-20 行**：遍历每个类别：
  - **第 9 行**：计算 `n_classes`——有多少个类别的样本数比当前类别 $C_i$ 更多。这些"更大的"类别都已经在之前的迭代中处理过了。
  - **第 10-11 行**：如果 $n_classes = 0$，说明 $C_i$ 是样本数最多的那个类（多数类），不需要过采样。
  - **第 12 行**：否则，将当前类别 $C_i$ 的样本赋值给 $X_{min}$ 作为少数类。
  - **第 13 行**：初始化合并多数类 $X_{maj}$ 为空。
  - **第 14-17 行**：构建合并多数类。对于每个已处理过的类别 $j$：
    - 从该类的原始样本 $X^{(j)}$ 加上已生成的合成样本 $S_j$ 中，**随机选择** $\lfloor |X^{(C_1)}| / n_{classes} \rfloor$ 个样本。
    - 这意味着每个已处理类别在合并多数类中拥有**完全相同数量**的代表，防止大类别主导势函数。
  - **第 18 行**：调用 B-RBO 算法进行过采样。这里 $X_{maj}$ 包含了来自多个已处理类别的等量样本，$\gamma$、step、iterations、$k$ 作为参数传入。

> **为什么从已处理类别中采样**：已处理类别是样本数最多的那些类，它们已经在之前的迭代中被增强过了。在处理更小的类别时，这些"较大的"类别共同构成"多数方"，因为相对于当前小类别，它们都是"多数类"。

#### 3.4.5 三种势计算策略的比较

原文还比较了三种不同的势函数计算策略：

| 策略 | 描述 | 性能 |
|------|------|------|
| **OVA+**（本文方法） | 从每个已处理类别中随机选择等量样本来构建合并多数类 | **最优** |
| **OVA** | 使用所有其他类别的全部样本计算势函数 | 速度太慢，容易被异常值和大类主导 |
| **OVO**（成对平均） | 对每对类别计算成对势函数然后取平均 | 性能不佳，因为忽略了非成对的类别特征 |

### 3.5 关键参数说明

| 参数 | 含义 | 建议 |
|------|------|------|
| $\gamma$ | RBF 扩散范围 | 较小的值产生集中势函数，较大的值产生平滑势函数；需根据数据调优 |
| `step` | 每次平移的步长 | 控制优化的精细程度 |
| `iterations` | 每个合成样本的优化迭代次数 | 越大优化越充分但计算成本越高；也影响合成样本距原始样本的远近 |
| `k` | 势函数近似的最近邻数量 | 较小的 $k$ 加速计算，但近似精度降低 |

### 3.6 计算复杂度分析

定义：
- $n$：总样本数
- $n_{maj}$、$n_{min}$：多数类和少数类样本数（二分类）
- $m$：特征数
- $i$：每个合成样本的迭代次数
- $k$：势函数近似的最近邻数
- $c$：类别数（多分类）

#### 不使用势近似

- 单次势计算复杂度：$O(m|X|)$（需要 $|X|$ 次 L1 距离计算，每次 $O(m)$）
- 互类势计算：$O(mn)$
- 需要生成 $n_{maj} - n_{min}$ 个合成样本，每个样本需要 $i$ 次互类势计算
- 最坏情况（$n_{min}=1$, $n_{maj}=n-1$）下的总复杂度：**$O(imn^2)$**

#### 使用势近似（$k$ 个最近邻）

使用势近似将单个互类势计算的复杂度从 $O(mn)$ 降至 $O(km)$（因为只用 $k \ll n$ 个邻居）。

但需要额外的 $k$NN 搜索步骤：
1. 计算少数类样本间的距离矩阵：$O(m n_{min}^2)$
2. 计算多数类与少数类间的距离：$O(m n_{maj} n_{min})$
3. 为每个少数类样本排序距离向量：$O(n_{min} n \log n)$

简化后的最坏情况复杂度：
$$O(mn^2 + n^2\log n + ikmn)$$

其中 $O(mn^2)$ 是距离矩阵计算，$O(n^2\log n)$ 是排序，$O(ikmn)$ 是合成样本生成。

#### 多分类最坏情况

当 $c-1$ 个类别各含 1 个样本，1 个类别含 $n-c+1$ 个样本时，MC-RBO 的总复杂度为：
$$O(c(mn^2 + n^2\log n + ikmn))$$

## 四、实验结果与分析

### 4.1 实验设置

#### 4.1.1 数据集

使用了 20 个来自 **KEEL 数据集仓库**的多样化多类不平衡基准数据集，这些数据集包含多种挑战性特征（原文 Table I）：
- 小分离簇（small disjuncts）
- 频繁的边界实例和噪声实例
- 类别重叠

数据集具有不同的 IR、样本数量和类别数量。

#### 4.1.2 对比方法

实验与三组方法进行了比较：

**第一组：多类采样方法**
- **SMOTE-all**：使用轮询方式（round-robin）对各类别进行 SMOTE 过采样
- **STATIC-SMOTE**（S-SMOTE）：基于敏感度的动态过采样
- **MBO**（Mahalanobis Distance Oversampling）：基于马氏距离的过采样
- **SMOM**：基于 k-NN 的合成少数类过采样算法，专门用于多类不平衡

**第二组：多类算法级方法**
- **HTree**（Multiclass Hellinger Decision Tree）：基于 Hellinger 距离的多类决策树
- **NB-SVM**（Near-Bayesian Support Vector Machines）：近贝叶斯支持向量机
- **AdaB.NC**（AdaBoost.NC）：基于 boosting 的集成方法（负相关学习）
- **SMOTEBag**：基于 bagging 的 SMOTE 集成方法

**第三组：二分类分解方法**
- 使用 OVO 分解 + 加权投票组合，结合四种采样方法：
  - RUS（随机欠采样）
  - SMOTE
  - Borderline SMOTE 1（BSMOTE）
  - ADASYN（自适应合成采样）

#### 4.1.3 基分类器

为验证 MC-RBO 的灵活性，使用了四种不同类型的基分类器：
- **C5.0**：决策树模型
- **MLP**：多层感知机（反向传播）
- **k-NN**：k 近邻分类器
- **NB**：朴素贝叶斯

#### 4.1.4 验证与参数选择

- 训练/测试划分：分层十折交叉验证（stratified 10-fold CV），重复 10 次
- 参数选择：在每个数据集上，使用内部分层三折交叉验证独立选择最优参数

#### 4.1.5 评估指标

使用了四种**针对倾斜数据设计的评估指标**（skew-insensitive metrics）：

**(1) 平均准确率（Average Accuracy, AvAcc）**

$$\text{AvAcc} = \frac{\sum_{i=1}^{M} \text{TPR}_i}{M}$$

其中 $M$ 是类别数，$\text{TPR}_i$ 是第 $i$ 类的真正率（True Positive Rate，即召回率）。AvAcc 是所有类别召回率的算术平均，确保每个类别对最终指标有同等贡献。

**(2) 类别平衡准确率（Class Balance Accuracy, CBA）**

$$\text{CBA} = \frac{\sum_{i=1}^{M} \frac{mat_{i,i}}{\max\left(\sum_{i=1}^{M} mat_{i,j}, \sum_{i=1}^{M} mat_{j,i}\right)}}{M}$$

其中 $mat_{i,j}$ 表示真实类别为 $i$ 但被预测为类别 $j$ 的样本数量。该指标在每一类中计算正确分类数与该类相关统计数据最大值之间的比率。

**(3) 多类 G-measure（multiclass G-measure, mGM）**

$$\text{mGM} = \sqrt[M]{\prod_{i=1}^{M} \text{recall}_i}$$

mGM 是所有类别召回率的**几何平均值**（geometric mean）。与算术平均不同，几何平均对任何类别上的极差性能更加敏感——如果一个类别的召回率很低，mGM 会显著降低。

**(4) 混淆熵（Confusion Entropy, CEN）**

$$\text{CEN} = \sum_{i=1}^{M} P_i \cdot \text{CEN}_i$$

其中：
- $P_i = \frac{\sum_{j=1}^{M} (mat_{i,j} + mat_{j,i})}{2 \cdot \sum_{k,l=1}^{M} mat_{k,l}}$：第 $i$ 类混淆的概率分布
- $\text{CEN}_i = -\sum_{j=1, j\neq i}^{M} (P_{i,j}^i \log_{2(M-1)}(P_{i,j}^i) + P_{j,i}^i \log_{2(M-1)}(P_{j,i}^i))$：第 $i$ 类的混淆熵
- $P_{i,j}^i = \frac{mat_{i,j}}{\sum_{c=1}^{M} (mat_{i,c} + mat_{c,i})}$，且 $i \neq j$

CEN 通过信息论视角评估分类器的混淆程度——CEN 值越低，表示分类器的混淆越少，性能越好。

#### 4.1.6 统计检验

- **成对比较**（单个数据集）：组合十折交叉验证 F 检验
- **多数据集比较**：Friedman 排序检验 + Shaffer 事后分析（post hoc）
- 置信水平：$\alpha = 0.05$

### 4.2 核心实验结果

#### 4.2.1 MC-RBO 中势函数计算策略的比较（OVA+ vs OVA vs OVO）

结果清楚地证明了本文提出的 **OVA+ 策略的优越性**：
- **OVA+**：仅从每个类别中选择一个随机子集，保持每个类别特征的同时加速计算，减少大类主导
- **OVA**（使用全部样本）：速度太慢，容易被异常值或不平衡扰动
- **OVO**（成对平均）：性能最差，因为缺乏非成对的类别特征相关性

#### 4.2.2 过采样比率对性能的影响（原文 Fig. 6）

MC-RBO 在**小过采样比率**下表现显著优于其他方法：
- 其他方法需要在过采样比率高于 200% 时才开始改善性能
- MC-RBO 在 **100% 的过采样比率**下就能提供稳定性能
- 这说明 MC-RBO 依赖于**智能的样本放置**，而不是样本数量——少数高质量的合成样本比大量随机放置的样本更有效

> **关键洞察**：MC-RBO 不需要大量地生成人工样本来弥补不平衡。它依靠精确定位，把每一个生成的样本放在最关键的位置——决策边界附近。这种做法不仅更高效（计算开销更少），也避免了引入过多"无用"样本导致的过拟合风险。

#### 4.2.3 基分类器选择的影响

MC-RBO 在所有四种分类器上都表现良好：

- **C5.0 决策树**：最佳表现。MC-RBO 的精确定位使得决策树在分裂搜索时更加高效，不会因数据偏移而过拟合
- **朴素贝叶斯**：非常受益。MC-RBO 生成的样本遵循各类别的底层密度分布，有利于概率估计
- **MLP 和 k-NN**：表现稍逊。这两类分类器受益于更多训练样本，而 MC-RBO 生成的样本数量较少。可以通过增加迭代次数来生成更多样本来弥补

#### 4.2.4 与多类采样方法的比较

MC-RBO **在所有基分类器和所有评估指标上均优于**所有多类采样方法（SMOTE-all、STATIC-SMOTE、MBO、SMOM）。

**原因分析**：所有对比方法都只使用当前被过采样的类别信息。在多类场景中，这种做法可能引入处于多个类别边界上的样本，甚至**增加实际的类别重叠**（increase actual class overlapping）。MC-RBO 使用来自所有类别的信息，因此能创建更高质量的合成样本。

#### 4.2.5 与多类算法级方法的比较

- 相对于 **HTree** 和 **NB-SVM**：MC-RBO 在几乎所有情况下显著更好。算法级方法在二分类中有效，但在多类场景中还远未成熟
- 相对于 **AdaB.NC** 和 **SMOTEBag**：这些是集成方法，在少数数据集上能比 MC-RBO 更好。但实际上 MC-RBO 在与集成方法竞争时表现出色——它本身不是集成方法，但可以轻松与任何集成学习算法结合以进一步提升性能

#### 4.2.6 与二分类分解方法的比较（OVO + 采样）

二分类分解方法的性能在所有方法中最差。尽管使用了先进的二分类采样技术（BSMOTE、ADASYN），将多类问题视为成对问题处理仍然丢失了许多关键信息：
- 两个以上类别的重叠现象
- 多个类别间的复杂决策边界
- 异常值和小分离簇的检测在二元分解中变得困难

### 4.3 实验总结

| 对比维度 | MC-RBO 的表现 |
|----------|---------------|
| vs 多类采样方法 | 全面显著优于 SMOTE-all、STATIC-SMOTE、MBO、SMOM |
| vs 算法级方法 | 优于 HTree 和 NB-SVM；与 AdaB.NC 和 SMOTEBag 竞争（后者为集成方法） |
| vs 二元分解方法 | 显著优于所有二元分解 + 采样组合（RUS/SMOTE/BSMOTE/ADASYN + OVO） |
| 基分类器适应性 | 所有四种分类器（C5.0、MLP、k-NN、NB）均表现良好，C5.0 和 NB 尤其受益 |
| 过采样比率 | 100% 即可达到稳定性能（其他方法需 200% 以上） |

## 五、总结与展望

### 5.1 方法优势总结

1. **全新的过采样思路**：MC-RBO 不依赖最近邻信息，而是利用所有类别的势函数信息来引导样本生成，从根本上避免了 SMOTE 类方法的固有缺陷。

2. **势函数的巧妙应用**：通过高斯 RBF 建模每个样本的影响力，将样本生成问题转化为"寻找互类势接近零的决策边界区域"的优化问题。

3. **灵活的迭代式多类处理**：按类别大小降序处理，使用等权采样的合并多数类构建策略，既保证了效率又避免了类别主导问题。

4. **计算效率可控**：通过 $k$-NN 近似势函数，大幅降低了计算复杂度，在实际应用中可以在预处理时间和性能提升之间找到良好平衡。

### 5.2 未来方向

1. 评估 MC-RBO 对**类别标签噪声**和**特征噪声**的鲁棒性
2. 探索使用**不同的相似度度量**（特别是针对高维数据的分数距离度量）是否能提升 MC-RBO 的性能
3. 提出基于径向函数的**不平衡分布新度量**，指导人工样本的放置
4. 将 MC-RBO 扩展到**增量学习/数据流分类**场景
5. 将 MC-RBO 嵌入到包含内置机制的**混合架构**中
