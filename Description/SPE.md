## 一、研究背景与动机

### 1.1 类别不平衡问题

在现实世界中，许多分类任务面临**类别不平衡（Class Imbalance）**的挑战。所谓类别不平衡，是指数据集中不同类别的样本数量差距悬殊。以下是一些典型的例子：

- **点击率预测**：用户点击广告的行为仅占全部行为的极小比例。
- **信用卡欺诈检测**：在数百万笔交易中，只有少数是欺诈行为。
- **医疗诊断**：患病人数远少于健康人数。
- **网络入侵检测**：入侵连接远少于正常连接。

传统的分类算法（如 C4.5、SVM、神经网络）在平衡数据集上表现良好，但在不平衡数据集上往往表现不佳。原因是这些算法以**整体准确率（Accuracy）**为优化目标，导致模型会偏向多数类，而忽略少数类——然而，少数类通常是更受关注的目标（如欺诈交易、疾病患者）。

### 1.2 现有方法的不足

解决类别不平衡问题的现有方法主要分为三类，但各自存在局限性：

**（1）数据层面方法（Data-level Methods）**
- 包括欠采样（Under-sampling）、过采样（Over-sampling）和混合采样（Hybrid-sampling）。
- 大多数方法依赖 k-近邻（k-NN）算法来获取数据分布信息。然而：
  - k-NN 需要预定义距离度量，而现实数据常包含**类别特征（categorical features）和缺失值（missing values）**，难以定义合适的距离。
  - k-NN 易受**噪声**干扰，无法准确反映数据底层分布。
  - k-NN 的计算复杂度随数据量**平方增长**，在大规模数据上极其缓慢。

**（2）算法层面方法（Algorithm-level Methods）**
- 如代价敏感学习（Cost-sensitive Learning），通过对少数类赋予更大的误分代价来修正模型的偏向。
- 缺点：需要领域专家预先设定代价矩阵，这在很多实际场景中不可行；且对神经网络等批次训练模型效果有限。

**（3）集成方法（Ensemble Methods）**
- 将数据/算法层面方法与集成学习结合。
- 由于底层仍使用了数据/算法层面方法，同样继承了它们的缺陷（计算慢、依赖距离度量、对噪声敏感等）。
- 例如 BalanceCascade 会在后期迭代中过度聚焦于已被正确分类的样本，导致**过拟合噪声**。

### 1.3 核心研究动机：难度因素的整合

论文指出，类别不平衡问题的难度不仅仅来自**不平衡比例（Imbalance Ratio, IR）**本身。即使两个数据集具有相同的不平衡比例，其分类难度也可能截然不同。其他关键因素包括：

- **类别重叠（Class Overlapping）**：当多数类和少数类在特征空间中高度重叠时，分类变得极其困难。
- **噪声样本（Noise Samples）**：数据中的噪声和异常值进一步恶化了分类性能。
- **模型容量差异**：不同分类器对同一数据集的敏感度不同，现有采样方法却是"模型无关"的（model-agnostic），忽略了分类器自身的容量。

因此，论文提出了一个核心概念——**分类硬度（Classification Hardness）**，将上述所有难度因素统一整合到一个框架中。

> **直观理解（类比）**：可以把分类硬度想象成学生的"错题难度"。不同学生对同一道题的掌握程度不同（类比不同分类器对同一样本的硬度不同）。自步学习就像让一个学生先从简单题做起，逐步挑战难题，同时始终保留一些简单题用于巩固基础。这样既能稳步提升，又不会因为一开始就做难题而"崩溃"（过拟合）。

## 二、核心贡献与方法

### 2.1 主要贡献

1. **问题分析**：深入分析了传统不平衡学习方法在真实大规模不平衡分类任务中失败的原因，并通过实验和可视化进行了验证。

2. **提出 SPE 框架**：提出了 Self-paced Ensemble（SPE），一种用于大规模不平衡数据分类的学习框架。SPE 可以与**任意标准分类器**（C4.5、SVM、GBDT、神经网络等）结合使用，具有以下特点：
   - **准确（Accurate）**：在不同场景下均表现优异。
   - **快速（Fast）**：计算效率高。
   - **鲁棒（Robust）**：对噪声、类别重叠、缺失值具有鲁棒性。
   - **自适应（Adaptive）**：能根据分类器容量自动调整采样策略。

3. **引入分类硬度概念**：通过考虑数据集上的分类硬度分布，SPE 的学习过程以一种**模型特定（model-specific）**的方式自动优化，无需预定义距离度量。

### 2.2 整体方法思路

SPE 的核心思想是：**通过自步（self-paced）方式协调（harmonize）数据硬度分布，对多数类进行欠采样，从而生成一个强集成分类器。**

方法的关键步骤如下：

```
第1步：用随机欠采样训练第一个基分类器 f_0
第2步：对于 i = 1, 2, ..., n:
    2.1：用当前集成模型 F_i 计算每个多数类样本的"分类硬度"
    2.2：按硬度将多数类样本分到 k 个桶（bin）中
    2.3：每个桶按"硬度协调 + 自步因子"机制进行欠采样
    2.4：用采样后的平衡子集训练新基分类器 f_i
    2.5：将 f_i 加入集成
第3步：返回最终集成分类器
```

## 三、方法具体实现

### 3.1 分类硬度（Classification Hardness）

#### 3.1.1 定义

设 $F$ 为已训练的分类器，$F(x)$ 表示分类器预测样本 $x$ 属于正类（少数类）的概率。分类硬度函数 $H$ 可以是任何**可分解**的误差函数（即总误差等于各样本误差之和）。常用的硬度函数包括：

- **绝对误差（Absolute Error, AE）**：
  $$H_{AE}(x, y, F) = |F(x) - y|$$

- **平方误差（Squared Error, SE / Brier-score）**：
  $$H_{SE}(x, y, F) = (F(x) - y)^2$$

- **交叉熵（Cross Entropy, CE）**：
  $$H_{CE}(x, y, F) = -y\log(F(x)) - (1-y)\log(1-F(x))$$

论文默认使用绝对误差作为硬度函数（$H \in [0, 1]$）。

#### 3.1.2 根据硬度对样本进行分类

根据硬度值，可以将多数类样本分为三种类型：

| 样本类型 | 硬度值特征 | 描述 | 处理策略 |
|----------|-----------|------|---------|
| **平凡样本（Trivial Samples）** | 硬度值很小 | 已被模型良好分类，单个贡献极小的误差 | 只需保留少量作为分布的"骨架"，其余可丢弃 |
| **噪声样本（Noise Samples）** | 硬度值很大 | 由不可区分的重叠或异常值导致，即使模型收敛后仍然存在 | 不应强迫模型去学习，否则会导致严重过拟合 |
| **边界样本（Borderline Samples）** | 硬度值中等 | 位于当前模型决策边界附近，是最有信息量的样本 | 应增大其权重以进一步提升模型性能 |

> **直观理解**：想象老师给学生出题。平凡样本 = 学生已经烂熟于心的简单题（大量重复训练价值不大）；噪声样本 = 出错了的题目（没有学习价值）；边界样本 = 恰好处于学生能力边缘的题目（最有训练价值）。

#### 3.1.3 硬度分布的优势

分类硬度分布有两大优势：

1. **弥合不平衡比例与任务难度之间的鸿沟**：相同不平衡比例的数据集可能难度迥异（如图2所示，非重叠数据集即便不平衡比例增大，难度仍低；而重叠数据集中随不平衡比例增大，难度急剧上升）。硬度分布能更好地反映这种差异。

2. **弥合采样策略与分类器容量之间的鸿沟**：不同的分类器对同一数据集的硬度分布不同。通过考虑硬度分布，SPE能以模型特定的方式优化各种分类器的最终性能。

### 3.2 自步欠采样（Self-paced Under-sampling）

#### 3.2.1 硬度协调（Hardness Harmonize）

首先，将多数类样本按硬度值均等划分为 $k$ 个桶（bin）：

$$B_{\ell} = \{(x, y) \mid \frac{\ell-1}{k} \leq H(x, y, F) < \frac{\ell}{k}\}, \quad \ell = 1, 2, \ldots, k$$

其中 $H \in [0, 1]$（不失一般性）。

在第 $\ell$ 个桶中的平均硬度贡献为：

$$h_{\ell} = \frac{\sum_{s \in B_{\ell}} H(x_s, y_s, F_i)}{|B_{\ell}|}, \quad \forall \ell = 1, \ldots, k$$

**硬度协调**的思想是：使每个桶的**总硬度贡献**相等。这意味着硬度低的桶（平凡样本多）因其单个样本硬度小，需要保留更多样本才能达到相同的总硬度贡献；而硬度高的桶（噪声样本）因其单个样本硬度大，只需少量样本即可。

> **直观理解**：想象每个桶是一个球队，每个球员（样本）的"实力"（硬度）不同。硬度协调要求每个球队的总实力相等。实力弱的球队需要更多球员，实力强的球队只需少数球员即可。

#### 3.2.2 自步因子（Self-paced Factor）

纯粹的硬度协调存在一个问题：随着训练进行，集成分类器逐渐拟合训练集，平凡样本的数量会越来越多。如果始终采用硬度协调，仍然会保留大量平凡样本，降低学习效率。

为此，引入**自步因子 $\alpha$**，其更新公式为：

$$\alpha = \tan\left(\frac{i\pi}{2n}\right)$$

其中 $i$ 为当前迭代轮次，$n$ 为总迭代次数（基分类器数量）。

$\alpha$ 的性质：
- 当 $i = 1$ 时，$\alpha = \tan(\frac{\pi}{2n}) \approx 0$（第一轮几乎是纯硬度协调）
- 当 $i = n$ 时，$\alpha = \tan(\frac{\pi}{2}) \to \infty$（最后一轮几乎只关注最难的样本）

利用 $\alpha$，定义第 $\ell$ 个桶的**未归一化采样权重**：

$$p_{\ell} = \frac{1}{h_{\ell} + \alpha}, \quad \forall \ell = 1, \ldots, k$$

- 当 $\alpha = 0$：$p_{\ell} = \frac{1}{h_{\ell}}$，纯硬度协调——各桶的总硬度贡献相等。
- 当 $\alpha \to \infty$：所有桶的 $p_{\ell}$ 趋近于相等——每个桶采样相同数量的样本，即**更关注难样本**（因为难样本所在的桶中样本总数少，在相同采样数量下每个难样本被选中的概率更高）。

最终，从第 $\ell$ 个桶中采样的数量为：

$$\text{第}\ell\text{桶采样数} = \frac{p_{\ell}}{\sum_{m=1}^{k} p_m} \cdot |P|$$

其中 $|P|$ 是少数类样本数，因此每次欠采样得到的多数类子集与少数类大小相等，实现平衡。

> **直观理解（类比）**：自步因子 $\alpha$ 就像一个"难度调节旋钮"。初始时旋钮在 0（侧重协调），学生主要学习和巩固中等难度的内容。随着学习推进，旋钮逐渐增大，学生越来越多地挑战难题，但始终会保留一些简单题作为基础。这种"循序渐进"的策略既保证了学习效率，又防止了过拟合。

### 3.3 算法伪代码及中文解释

#### Algorithm 1: Self-paced Ensemble

```
输入: 训练集 D, 硬度函数 H, 基分类器 f,
      基分类器数量 n, 分桶数 k

1.  初始化: P ← D 中的少数类样本集
           N ← D 中的多数类样本集

2.  用随机欠采样从 N 中采样 N'_0，使 |N'_0| = |P|
    用 N'_0 ∪ P 训练第一个基分类器 f_0

3.  for i = 1 to n do:
4.      当前集成模型: F_i(x) = (1/i) * Σ_{j=0}^{i-1} f_j(x)
5.      按硬度 H(x, y, F_i) 将多数类集 N 划分为 k 个桶:
        B_1, B_2, ..., B_k

6.      计算每个桶的平均硬度贡献:
        h_ℓ = Σ_{s∈B_ℓ} H(x_s, y_s, F_i) / |B_ℓ|,  ∀ℓ=1,...,k

7.      更新自步因子: α = tan(iπ / (2n))

8.      计算每个桶的未归一化采样权重:
        p_ℓ = 1 / (h_ℓ + α),  ∀ℓ=1,...,k

9.      从第 ℓ 个桶中采样:
        采样数 = p_ℓ / Σ_{m} p_m × |P|
        得到多数类子集 N'_i

10.     用 N'_i ∪ P 训练基分类器 f_i

11. end for

12. 返回最终集成: F(x) = (1/n) * Σ_{m=1}^{n} f_m(x)
```

#### 算法逐步中文解释

**第1步（初始化）**：
从训练集 $D$ 中分离出少数类集 $P$（正例）和多数类集 $N$（负例）。记 $P = \{(x,y) | y=1\}$，$N = \{(x,y) | y=0\}$。

**第2步（第一个基分类器）**：
由于还没有集成模型可用于计算硬度，第一轮采用最朴素的**随机欠采样（Random Under-sampling）**：从多数类 $N$ 中随机抽取与少数类 $P$ 等量的样本，组成一个平衡的训练子集来训练第一个基分类器 $f_0$。

**第4步（当前集成模型）**：
将前面所有已训练的基分类器的输出取平均，作为当前的集成模型 $F_i(x)$。这里采用的是简单平均（soft voting），即 $F_i(x) = \frac{1}{i}\sum_{j=0}^{i-1} f_j(x)$。

**第5步（按硬度分桶）**：
利用当前集成模型 $F_i$ 和硬度函数 $H$ 计算每个多数类样本的分类硬度，然后按硬度值将多数类样本均匀划分到 $k$ 个桶中。论文默认 $k=20$。

> **直观理解**：就像把学生的错题按难度从1到20分档——第1档是最简单的题，第20档是最难的题。

**第6步（计算平均硬度贡献）**：
对每个桶，计算其中所有样本的硬度平均值 $h_{\ell}$。这个值反映了该桶内样本的整体"难度水平"。噪声所在的桶 $h_{\ell}$ 高，平凡样本所在的桶 $h_{\ell}$ 低。

**第7步（更新自步因子）**：
用正切函数 $\tan$ 来控制自步因子 $\alpha$ 的增长。正切函数的特点是：在自变量接近 $\pi/2$ 时急剧增长到无穷大。这确保了 $\alpha$ 从 0 平滑过渡到 $\infty$。

选择 $\tan$ 函数的原因：
- 增长曲线平滑，不会突变。
- 初始增长缓慢（前期侧重硬度协调），后期增长迅速（后期侧重难样本）。
- 自然地将 $\alpha$ 映射到 $[0, \infty)$ 区间。

**第8步（计算采样权重）**：
$p_{\ell} = \frac{1}{h_{\ell} + \alpha}$ 是每个桶的采样权重。

- 当 $\alpha$ 很小（早期迭代）：$p_{\ell} \approx 1/h_{\ell}$，硬度高的桶权重低，采样少——避免噪声；硬度低的桶权重高，采样多——保留足够的"骨架"信息。
- 当 $\alpha$ 很大（后期迭代）：$p_{\ell} \approx 1/\alpha$（所有桶权重近似相等），但由于硬度高的桶中样本总数本来就少，在采样量相同的情况下，每个难样本被选中的概率更高——聚焦难样本。

**第9步（采样）**：
将采样权重归一化，然后按比例从各桶中采样。总采样量等于少数类样本数 $|P|$，从而保证训练子集的类别平衡。

**第10步（训练基分类器）**：
用采样得到的多数类子集 $N'_i$ 和少数类全集 $P$ 组成平衡的训练集，训练新的基分类器 $f_i$。

**第12步（返回集成）**：
将所有基分类器的输出取平均，得到最终的集成分类器。

### 3.4 关键设计思想总结

| 设计要素 | 解决的问题 | 实现方式 |
|----------|-----------|---------|
| **硬度协调** | 如何平衡不同难度样本的贡献？ | 使各硬度桶的总硬度贡献相等 |
| **自步因子 $\alpha$** | 如何从易到难逐步学习？ | 用 $\tan(i\pi/2n)$ 控制从协调到聚焦难样本的过渡 |
| **动态硬度更新** | 如何反映模型当前状态？ | 每次迭代都用最新的集成模型重新计算硬度 |
| **保留"骨架"** | 如何防止过拟合？ | 即使 $\alpha \to \infty$，每个桶仍有采样，保留了分布的全局信息 |
| **无需距离度量** | 如何处理类别特征和缺失值？ | 只用分类器的预测输出来计算硬度 |

### 4.1 数据集

论文使用了一个合成数据集和五个真实世界数据集：

#### 合成数据集

**Checkerboard 数据集**：$4 \times 4$ 的棋盘格数据，包含 16 个高斯分量。所有分量共享协方差矩阵 $0.1 \times I_2$。少数类样本数 $|P| = 1,000$，多数类样本数 $|N| = 10,000$（$IR = 10:1$）。通过调整协方差矩阵可以控制类别重叠程度（$cov \in \{0.05, 0.10, 0.15\}$）。

| **KDDCUP (DOS vs. R2L)** | 42 | 3,884,496 | 整数+类别型 | 3448.82:1 | AdaBoost |

### 4.2 对比方法

#### 基础重采样方法
- **RandUnder**（随机欠采样）
- **Clean**（邻域清理规则欠采样）
- **SMOTE**（合成少数类过采样技术）
- **NearMiss**、**ENN**、**TomekLink**、**AllKNN**、**OSS**（更多欠采样方法）

- **UnderBagging**：Bagging 中集成随机欠采样
- **SMOTEBagging**：Bagging 中集成 SMOTE

### 4.3 评估指标

由于准确率不适合不平衡场景，论文使用了以下专门针对不平衡分类的评估指标：

- **Recall（召回率）**：
  $$\text{Recall} = \frac{TP}{TP + FN}$$

- **Precision（精确率）**：
  $$\text{Precision} = \frac{TP}{TP + FP}$$

- **F1-score**：
  $$F_1 = 2 \cdot \frac{\text{Recall} \times \text{Precision}}{\text{Recall} + \text{Precision}}$$

- **G-mean（几何均值）**：
  $$\text{G-mean} = \sqrt{\text{Recall} \cdot \text{Precision}}$$

- **MCC（Matthews相关系数）**：
  $$MCC = \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

- **AUCPRC（Precision-Recall 曲线下面积）**

#### 4.4.6 超参数敏感性分析

SPE 有三个关键超参数：

1. **基分类器数量 $n$**：随着 $n$ 增大，性能持续提升并趋于稳定（实验范围 1-100）。
2. **分桶数 $k$**：实验测试了 $k \in [1, 50]$。当 $k < 10$ 时性能较差（因为硬度分布近似过于粗糙）；$k \geq 10$ 后性能稳定。论文默认 $k = 20$。
3. **硬度函数 $H$**：测试了绝对误差（AE）、平方误差（SE）和交叉熵（CE）三种，结果证明 SPE 对不同硬度函数的选择**不敏感**（鲁棒性强）。

## 五、总结与启示

### 5.1 论文核心思想

SPE 的精妙之处在于将**课程学习（Curriculum Learning）**的思想引入不平衡数据的集成学习中：

1. **分类硬度**统一了不平衡比例、类别重叠、噪声等多个难度因素。
2. **硬度协调**平衡了不同难度样本的贡献。
3. **自步因子**实现了从易到难（从协调到聚焦）的平滑课程过渡。
4. **动态硬度更新**使采样策略始终与当前模型状态同步。
5. **免距离度量**使方法适用于任意特征类型（包括类别特征和缺失值）。

### 5.2 方法优势

- 不需要预定义距离度量
- 计算效率高（无需 O(n^2) 的距离计算）
- 自适应不同分类器的容量
- 对噪声、缺失值、类别重叠具有强鲁棒性
- 可以即插即用地与任意标准分类器结合

### 5.3 局限与展望

- 论文仅考虑了**二分类**场景，多分类扩展需要进一步研究。
- 硬度函数的分解性质使其不能直接使用 AUC 等不可分解的指标。
- 自步因子的具体形式（$\tan$ 函数）可能还有优化空间。
