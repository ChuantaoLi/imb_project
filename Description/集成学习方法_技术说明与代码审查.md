# 11 个集成学习方法 — 技术说明与代码审查

> 对象：综述（Fachrie et al. 2025）涉及的 11 个集成学习方法，逐一给出论文出处、
> 算法原理、核心组件与参数、以及**论文↔代码保真审查**。
> 统一约定：bagging 型基学习器 = 决策树（论文 J48/C4.5→sklearn CART，剪枝/增益比差异已注明）；
> boosting 型弱学习器 = `DecisionTree(max_depth=3)`；集成规模 N=30。
> sklearn CART 与 Quinlan C4.5/J48 的差异（后剪枝、增益比）是不可避免的库适配，统一注明。

---

## 公共设定

- **集成规模**：N=30（与旧 5 模型一致）；冒烟模式自动降至 5–12。
- **基学习器**：bagging→`DecisionTreeClassifier`；boosting→深度 3 树桩；BPNN/RBFNN 等嵌入式保留。
- **聚合**：概率平均 / 加权投票 / Dempster 合成 / 动态选择 / 阈值移动，依方法而定。
- **输入**：runner 已 scale+encode（preencoded）。

## 1. PT-Bagging（pt_bagging.py）

- **出处**：Collell, Prelec, Patil (2018) *A simple plug-in bagging ensemble based on threshold-moving...* Neurocomputing 275. DOI 10.1016/j.neucom.2017.08.035
- **原理**：不是“各类平均概率后直接取 `argmax`”。按论文 `Algorithm 1`，先用标准有放回 bagging 学到**校准较好的后验概率**，再对每个类别应用独立阈值 `lambda_k`，按 `\hat P(y=k|x) / lambda_k` 排序后选最大者。无训练期重采样，不平衡完全在测试期决策阈值层面处理。
- **实现**：`fit()` 仅做普通 bootstrap bagging；`predict_proba()` 返回各基分类器后验平均；`predict()` 再按 `score_k = \hat P(y=k|x) / lambda_k` 做论文式 threshold-moving。默认 `threshold_mode='macro_accuracy'`，即按论文给出的闭式结果，将**训练集类先验** `P(y=k)` 作为各类阈值。实现中同时加入 `class_to_index_ / index_to_class_`，避免非连续标签下的类别错位。
- **参数**：`n_estimators=30, max_depth=None, threshold_mode='macro_accuracy', thresholds=None`。
- **保真**：bagging 后验平均、测试期 plug-in threshold-moving、多类 `lambda_k` 阈值决策三条主线均已落地。
- **近似**：论文同时讨论 `macro F1` 的近似阈值，但在当前项目默认路径中采用文中最明确、可闭式复现的 `macro_accuracy` 先验阈值；如需其它阈值方案，可通过 `threshold_mode='manual'` 传入自定义 `thresholds`。基学习器 J48 仍以 `sklearn CART` 近似。

## 2. MultiRandBal（multirandbal.py）

- **出处**：Rodríguez, Díez-Pastor, Arnaiz-González (2020) *Random balance ensembles for multiclass imbalance learning.* KBS 193. DOI 10.1016/j.knosys.2019.105434
- **原理**：不是 `Dirichlet` 一次性分配比例，也不只是 bagging。按作者公开实现，每轮先为每个类别独立采样一个 `Uniform(0,1)` 随机权重，再按其归一化结果得到该轮的目标类规模，并施加 `min_samples` 下界；当前类高于目标则随机欠采样，低于目标则用 `SMOTE` 补足。论文同时讨论 **bagging** 与 **boosting** 两种结合方式：bagging 下用多数投票，boosting 下按 AdaBoost 多类权重聚合。
- **实现**：`_random_balance_targets()` 复现作者实现中的独立随机权重归一化与最小样本数约束；`_random_balance_subset()` 对每类执行统一的欠采样 / `SMOTE` 补足；`predict()` 在 bagging 下改回**多数投票**；同时补上 `mechanism='boosting'` 路径，在每轮随机平衡后按多类 AdaBoost (`SAMME`) 风格更新样本权重并做 `alpha` 加权投票。
- **参数**：`n_estimators=30, k=5, mechanism='bagging', min_samples=2, max_depth=None`。
- **保真**：随机平衡目标生成、统一混合重采样、bagging 多数投票、boosting 组合路径均已落地。
- **近似**：作者公开 `Python` 代码主线是 bagging 版 `MultiRandBal`；当前 boosting 路径按照论文摘要与综述明确提到的 “combined with Boosting / RandBalBoost” 用标准多类 `SAMME` 形式实现，并显式保留为可切换模式，不再静默缺失。

## 3. AdaBoost.AD（adaboost_ad.py）

- **出处**：Li et al. (2024) *Multi-class imbalance classification based on data distribution and adaptive weights.* TKDE 36(10). DOI 10.1109/TKDE.2024.3384961
- **原理**：在标准 AdaBoost 框架上引入 3 个量：`γ(X,y)=N(y)/min_y' N(y')` 的类间失衡比、基于全局 `k-NN` 中同类邻居的广义密度 `ρ(X,y)` 及其类内归一化逆密度 `ρ^{-1}(X,y)`、以及由当前集成投票 softmax 得到的自适应间隔 `σ^{(t)}(X,y)`；样本权重按 `ω^{(t+1)}=exp(-γρ^{-1}σ^{(t)})·ω^{(t)}·exp(-|β_t|·1[h_t(x)=y])` 更新。
- **实现**：`k=5`；初始样本权重严格为 `1/n`；广义密度取前 `k` 个全局近邻中的同类近邻反距离均值后再做全局均值归一化；类内逆密度按作者公开代码的 `softmax(-ρ)` 后再做类内均值归一；基学习器为决策树；模型权重 `β_t=log(W_correct/W_wrong)`；预测为 `β_t` 加权多数投票，`predict_proba` 仅为适配项目评测接口，对相同票分做 softmax。
- **保真**：与论文公式及作者公开 `MATLAB` 代码一致，不再套用 `SAMME` 的 `log(K-1)` 权重公式，也不再把密度直接写成初始权重。
- **已知局限**（论文自述）：多多数类数据上性能差——本实现不回避。

## 4. OREMBoost（oremboost.py）

- **出处**：Zhu, Liu, Zhu (2023) TKDE 35(6)（OREM-M 的 boosting 变体，同源）。DOI 10.1109/TKDE.2022.3171706
- **原理**：将 **OREM** 嵌入 `AdaBoost`。每轮先按当前样本权重分布抽取 bootstrap，再用 **OREM-M** 对该训练子集做可靠区域过采样平衡，然后训练弱分类器；轮次误差仍在原始加权训练集上计算，最终按分类器表现得到的 `alpha` 做加权集成。
- **实现**：`fit()` 采用 `SAMME` 风格流程：加权 bootstrap → `OREMM._resample` → `DecisionTreeClassifier(max_depth=3)` → 在原始加权集上计算 `err` 与 `alpha` → 更新样本权重；`predict()` 使用 **alpha 加权投票**，`predict_proba()` 仅作为项目评测接口，将同一加权票分做 softmax。实现中还加入了 `class_to_index_ / index_to_class_` 显式映射，避免非连续多类标签下的投票错位。
- **参数**：`n_estimators=30, consecutive_majority=5, iteration_order='ascending', max_depth=3`。
- **保真**：boosting + 每轮 OREM-M 过采样 + 依据分类器表现加权组合三条主线均已落地。
- **近似**：论文全文未公开更细的 boosting 伪代码时，当前采用标准多类 `SAMME` 作为嵌入式 boosting 骨架；而 `OREM-M` 部分则已对齐作者公开 `OREM` 代码的 `CMR + clean subregion` 主线。

## 5. DES-MI（des_mi.py）

- **出处**：García et al. (2018) *Dynamic ensemble selection for multi-class imbalanced datasets.* Information Sciences 445–446. DOI 10.1016/j.ins.2018.03.002
- **原理**：N 棵 CART 在**随机平衡** bootstrap 上训练；另留 `DSEL` 能力评估集。测试时对每个查询样本取 `k` 个近邻，邻域样本按其所属类别在 `DSEL` 中的频率经 `1/(1+\exp(\alpha n_c))` 赋权，得到各基分类器的**加权局部正确率**；再选择前 `pct_accuracy` 比例的分类器做动态集成。
- **实现**：`_random_balance_subset()` 负责随机平衡训练子集；`fit()` 切出 pool-train / DSEL；`_estimate_competence()` 复现论文式类别频率 logistic 权重；`predict()` 用所选分类器**硬投票**，`predict_proba()` 用同一所选子集的概率平均。
- **参数**：`k=7, pct_accuracy=0.4, alpha=0.9, dsel_perc=0.5`。
- **保真**：随机平衡、加权邻域能力估计、按比例选择最优分类器、动态硬投票均已落地。

## 6. DRCW-ASEG（drcw_aseg.py）

- **出处**：Zhang et al. (2018) *DRCW-ASEG: one-versus-one distance-based relative competence weighting with adaptive synthetic example generation...* Neurocomputing 285. DOI 10.1016/j.neucom.2018.01.039
- **原理**：按论文做 **OvO 分解**；每个类对上的二分类器池由 bootstrap `CART` 组成。预测时，在对应类对的训练子集上取局部邻域；若局部失衡，则通过 **ASEG** 为该类对的少数类动态生成合成样本；再按邻域样本到测试点的距离计算**距离加权相对能力**，用于聚合该类对的二分类后验。
- **实现**：对每个 `(c_i, c_j)` 构建独立 bootstrap 分类器池和 `k-NN` 邻域索引；测试时在该类对子集上做 `ASEG`，然后以 `exp(-d)` 加权的局部正确率作为相对能力；各类对后验累加成全局多类得分。
- **保真**：`OvO + ASEG + distance-based relative competence weighting` 已落地。
- **近似**：论文全文未公开更细的类对耦合规则时，最终多类融合采用各 `OvO` 后验累加再归一化。

## 7. Easy-BPNN（easy_bpnn.py）— OvO + EasyEnsemble + BPNN（**嵌入式分类器**）

- **出处**：Zhang et al. (2016) *Empowering one-vs-one decomposition with ensemble learning for multi-class imbalanced data.* KBS 106. DOI 10.1016/j.knosys.2016.05.048
- **原理**：按论文先做 **OvO 分解**；每个类对子问题上使用 **EasyEnsemble**，即反复把多数类随机欠采样到少数类规模，并在每个平衡子集上训练一个 **BPNN**；最后将所有类对的二分类后验融合回多类输出。
- **实现**：对每个 `(c_i, c_j)` 构建独立的 BPNN 池；`_pair_balanced_subset()` 在类对子集上执行随机欠采样；基学习器为 numpy 手写单隐层 `BPNN`（50 隐层单元，sigmoid + softmax + 交叉熵反传，mini-batch SGD）；预测时先平均类对内 BPNN 后验，再把各类对后验累加并归一化。
- **保真**：`OvO + EasyEnsemble + BPNN` 主流程已落地，不再把论文的类对分解静默简化为单个多类平衡集成。
- **近似**：论文未公开更细的类对耦合细节时，最终多类融合采用各 `OvO` 后验累加再归一化；BPNN 仍以 numpy 手写实现替代深度学习框架。

## 8. EVINCI（evinci.py）— 实例子集级 NSGA-II 进化反转（heavy: NSGA-II）

- **出处**：Fernandes, de Carvalho (2019) *Evolutionary inversion of class distribution in overlapping areas for multi-class imbalanced learning.* Information Sciences 494. DOI 10.1016/j.ins.2019.04.052
- **原理**：先用**可变失衡比**随机采样生成候选训练子集；再用 **NSGA-II** 直接进化**样本保留掩码**，目标一是验证集平衡准确率最大化，目标二是削减**重叠区域中代表性较弱的多数类样本浓度**。各类规模始终不超过原始数据（不过采样）。
- **实现**：每个候选子集先按随机比例抽样、且每类不超过原始类规模；随后用 DEAP `selNSGA2 + eaMuPlusLambda` 在样本级二进制掩码上搜索；重叠惩罚由 `safe_level` 近似刻画，优先保留更具代表性的样本；每个进化后的子集训练一个 `CART`，最终对所有进化基分类器做概率平均。
- **参数**：`n_estimators=30, ga_pop=12, ga_gen=8, val_size=0.3`。
- **保真**：实例子集级进化、可变失衡比采样、重叠区多数类削减、进化后集成均已落地。
- **近似**：论文未公开更细的重叠度 / 代表性公式时，重叠区域用全局 `safe_level` 近似；NSGA-II 预算按工程可运行性封顶。

## 9. AMCS（amcs.py）— 8 类数据自适应路由 + FCBF/BPSO + AdaBoost.M1（heavy: BPSO）

- **出处**：Yijing et al. (2016) *Adapted ensemble classification algorithm based on multiple classifier system and feature selection...* KBS 94. DOI 10.1016/j.knosys.2015.11.013
- **原理**：① 按 `IR>=10 / 维数>=10 / 类数>=6` 将数据划为 8 类；② 每类数据走论文固定路线，在 `FCBF` 与 `BPSO` 间选择特征选择器，并固定基分类器为 `C4.5 / SVM / KNN / RBF-NN` 之一；③ 集成框架固定为 **AdaBoost.M1**，以 `FiltEX` 按样本权重重采样；④ 用每个弱分类器训练期的 **AUCarea** 作为权重做加权多数投票。
- **实现**：`_infer_type()` 复现 8 类路由；`_full_fcbf()` 复现 SU 相关性筛选 + 冗余删除；手写 `_bpso_select()` 做二进制粒子群选特征子集；`_train_adaboost_m1()` 复现 `FiltEX` 重采样 boosting；`predict_proba()` 输出 `AUCarea` 加权多数投票结果。
- **参数**：`n_estimators=20`；`BPSO` 默认 `particles=20, iters=10`，且 `w=0.729, c1=c2=1.49445`。
- **保真**：8 类数据自适应路由、FCBF/BPSO、AdaBoost.M1、FiltEX、AUCarea 加权投票均已落地。
- **近似**：① `C4.5` 以 `sklearn` 熵树近似；② `RBF-NN` 以 `k-means + RBF + 岭回归输出层` 复现；③ `BPSO` 的粒子数 / 迭代数采用作者公开代码默认值，显式保留可配置接口。

## 10. E-EVRS（e_evrs.py）— Bagging + MC-EVHS + Dempster 证据合成（heavy: DS）

- **出处**：Grina, Elouedi, Lefevre (2023) *Re-sampling of multi-class imbalanced data using belief function theory and ensemble learning.* IJAR 156. DOI 10.1016/j.ijar.2023.02.006
- **原理**：bagging 中每 bootstrap 用 **MC-EVHS** 证据重采样平衡；再将各基分类器的**软后验**映射为 DS 质量函数，并用 **Dempster 规则**做 classifier-independent 证据合成，而非简单平均或硬投票。
- **实现**：每个 bootstrap 先调 `MCEVHS._resample`；基分类器默认 `DT`，也支持 `SVM` 等概率型分类器；`predict_proba` 对每个测试点执行 “分类器后验 → 软 singleton 质量函数 + `Theta` 无知质量 → `dempster_combine` → `pignistic_proba`”。
- **保真**：`MC-EVHS + evidential classifier-independent fusion` 已落地，不再把整条后验压成仅保留 argmax 的硬化证据。

## 11. DPSE（dpse.py）— OvA 差分分区 + 置信度加权

- **出处**：Gao et al. (2021) *A multiclass classification using one-versus-all approach with the differential partition sampling ensemble.* EAAI 97. DOI 10.1016/j.engappai.2020.104034
- **原理**：OvA 分解；对每个二分类子问题，先按邻域信息把样本划为 `safe / borderline / rare / outlier`，再构造**等间隔差分采样数**序列；每轮对子集应用 `s-Random undersampling`（多数类优先删 `safe` 样本）与 `br-SMOTE`（少数类从 `borderline / rare` 样本生成）；最后按**类置信度**聚合各 OvA 头。
- **实现**：`_categorize_samples()` 用混合邻域同类计数划分四类样本；`_arithmetic_targets()` 显式生成差分采样数等间隔序列；`_ova_subset()` 对负类做 `s-Random undersampling`，对正类做 `br-SMOTE`；每个 OvA 头输出 `P(c)` 后在 C 个头间归一化。
- **参数**：`n_subsets=3, k=5`。
- **保真**：OvA、样本类型划分、等间隔差分采样、`s-Random undersampling`、`br-SMOTE`、类置信度融合均已落地。
- **近似**：① 论文未公开精确阈值时，四类样本划分按邻域同类数做确定性复现；② `br-SMOTE` 以边界/稀有样本为种子调用统一 `SMOTE` 生成器；③ 置信度加权仍采用各 OvA 头正类后验归一化。
