## 一、研究背景与动机

### 1.1 类别不平衡问题

在机器学习和数据挖掘领域，类别不平衡（class imbalance）是一个普遍存在且极具挑战性的问题。它的核心表现是：**数据集中某些类别（多数类/majority class）的样本数量远超其他类别（少数类/minority class）**。例如，在疾病诊断中，患病人数远少于健康人数；在欺诈检测中，欺诈交易远少于正常交易。

类别不平衡带来的核心困境是：标准的分类学习算法通常以整体准确率为优化目标，因此模型会严重偏向多数类，导致少数类的识别性能极差。然而，**恰恰是这些少数类样本的正确分类在实际应用中最为关键**——漏诊一个癌症患者或漏过一次欺诈交易的代价极其高昂。

除了样本数量不均本身，不平衡数据还常伴随以下"数据困难因素"（data difficulty factors）：
- **类内不平衡（within-class imbalance）**：少数类内部也存在某些子簇样本特别少的情况
- **类别重叠（class overlapping）**：不同类别的样本在特征空间中相互交错
- **代表性样本稀缺（scarce representative samples）**：少数类样本不足以覆盖其真实分布

### 1.2 现有方法概述

现有不平衡学习方法分为三大类：

| 类别 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| **数据级方法** | 过采样（增加少数类样本）或欠采样（删除多数类样本） | 易用、有效、与分类器无关 | 欠采样可能丢失重要信息 |
| **算法级方法** | 修改损失函数或决策阈值来强调少数类 | 不改变数据分布 | 与特定算法耦合 |
| **混合方法** | 同时改变数据分布和学习机制 | 综合优势 | 设计复杂 |

本文聚焦于**过采样技术**。相比欠采样，过采样是更根本的解决方案：不平衡分类困难的根源在于少数类信息不足，而过采样可以直接通过引入新样本来增强少数类的概念表达。此外，过采样不存在丢失重要多数类信息（从而影响多数类性能）的风险。

### 1.3 研究动机（三个层面）

**动机一：设计更有效的插值过采样算法**

插值过采样（interpolation oversampling）是最简单、最鲁棒、最流行的过采样方式，因为它只需要局部数据信息即可生成合成样本。相比之下，基于概率分布的过采样在少数类极端稀缺时难以准确估计分布，结构保持方法在高维场景下线性代数运算可能成为病态问题。

插值过采样的核心问题在于：**如何发现少数类的"潜在区域"（potential minority regions）**——即那些虽然当前没有少数类样本、但理论上应该属于少数类的特征空间区域。现有两种主流策略各有缺陷：

- **k近邻策略**（如SMOTE）：假设两个少数类近邻之间的区域都属于少数类。这个假设过强，容易被违反——离群点（outlier）和稀有案例（rare case）与大多数其他少数类样本都相距很远，它们与近邻之间的区域可能穿过多数类区域。
- **聚类策略**（如MWMOTE）：使用聚类算法识别少数类数据空间。缺点是聚类参数难以设置，且聚类可靠性高度依赖少数类数据是否呈现清晰的聚类结构。

论文提出，需要一种**不需要k近邻参数、也不需要聚类假设**的更有效的插值过采样算法。

**动机二：提升过采样技术处理多类不平衡数据的能力**

大多数过采样算法专为二分类设计，无法直接用于多类场景。一种直接方案是将多类问题分解为多个二类子问题（如one-vs-all或one-vs-one），但这样每个子问题仅有部分数据知识，通常不如原生多类方案。

现有的少数多类过采样方法普遍较为保守，强调避免合成少数类样本与原始多数类样本之间的重叠，但**忽略了不同少数类的合成样本之间也会发生类别重叠**。当需要生成大量合成样本时，这个问题可能变得非常严重。

**动机三：与集成学习方法建立正向协同效应**

过采样技术已被广泛与bagging和boosting等集成方法结合。实证研究表明，基于集成的解决方案通常优于单纯数据预处理方法。因此，将设计的过采样技术嵌入集成学习框架是有价值的。

## 二、核心贡献与方法概述

### 2.1 主要贡献

本论文提出了三个层次的方法体系：

| 方法 | 全称 | 适用场景 | 核心思想 |
|------|------|----------|----------|
| **OREM** | Oversampling with Reliably Expanding Minority class regions | 二类不平衡 | 两阶段定位少数类区域：候选区域探索 + 干净子区域识别 |
| **OREM-M** | OREM for Multiclass | 多类不平衡 | 在OREM基础上引入迭代生成过程，抑制不同少数类合成样本间的重叠 |
| **OREMBoost** | OREM + Boosting | 二类/多类不平衡（集成） | 将OREM嵌入boosting框架，每轮平衡训练数据后训练基分类器 |

### 2.2 方法总览

**OREM的核心思路**可以直观理解为：

想象在一片地图上（特征空间），少数类样本就像是散落的"安全据点"。我们的任务是扩展这些安全据点的疆域，但不能侵入"敌方领地"（多数类区域）。

OREM分两步完成这一任务：

1. **第一步（探索候选区域）**：以每个少数类样本为圆心，向外扩张，看能连续多远的距离不被多数类样本"阻断"。这个最大连续区域就是**候选少数类区域（CMR, Candidate Minority Region）**。用一个参数 $q$ 控制：当连续出现 $q$ 个多数类样本时，说明已经进入多数类密集区，应该停止扩张。

2. **第二步（识别干净子区域）**：候选区域内部可能包含多数类样本。OREM进一步在CMR内部检查：以少数类样本和CMR内每个候选辅助种子之间的中点为中心的小超球区域，是否包含了多数类样本。如果没有，这个子区域就是**干净的（clean）**，可以安全地用于生成合成样本。

## 三、方法具体实现

### 3.1 OREM算法详解

#### 3.1.1 总体结构

OREM算法的输入输出如下：

- **输入**：少数类样本集 $S_{min}$，多数类样本集 $S_{maj}$，计数参数 $q$，需要生成的合成样本总数 $z$
- **输出**：合成样本集 $S_{syn}$

OREM由三个函数组成：

```
算法1: OREM(S_min, S_maj, q, z)
─────────────────────────────────────────────
1. 对每个少数类样本 x_i，发现其候选少数类区域中的样本:
   C(x_i) ← DiscovCMR(x_i, S_min, S_maj, q)
   
2. 对每个少数类样本 x_i，识别干净子区域对应的辅助种子:
   A(x_i) ← IdeCleanReg(x_i, C(x_i), S_min)
   
3. 生成合成样本:
   S_syn ← Generate(A, S_min, S_maj, z)
```

#### 3.1.2 函数一：DiscovCMR —— 发现候选少数类区域（CMR）

**直观理解**：给定一个少数类样本 $x_i$，将其他所有样本按到 $x_i$ 的距离从小到大排序。从最近的样本开始逐个检查：如果连续遇到 $q$ 个多数类样本，说明已经碰触到多数类的密集区域，此时应停止。停止位置之前的所有样本就构成了 $x_i$ 的CMR内的样本。这些样本被称为 $x_i$ 的**候选辅助种子（candidate assistant seeds）**。

**中文伪代码**：

```
函数 DiscovCMR(x_i, S_min, S_maj, q):
────────────────────────────────────────────────
输入:
  x_i      — 当前考虑的少数类样本
  S_min    — 少数类样本集
  S_maj    — 多数类样本集
  q        — 计数参数（连续出现多少个多数类样本时停止）

输出:
  C(x_i)   — x_i 的候选辅助种子集合

步骤:
  1. 合并所有样本: S = S_min ∪ S_maj
  
  2. 计算 S\{x_i} 中每个样本到 x_i 的距离，
     按距离从小到大排序，得到有序列表:
     A(x_i) = {x_{i1}, x_{i2}, ..., x_{i(|S|-1)}}
     其中 x_{i1} 是最近邻，x_{i(|S|-1)} 是最远邻
     
  3. 初始化连续多数类计数器 count = 0，位置 t 未确定
  
  4. 遍历 k = 1, 2, ..., |S|-1:
     ├─ 如果 x_{ik} ∈ S_maj (是多数类样本):
     │    count ← count + 1
     │    如果 count == q:  (连续遇到q个多数类)
     │       t ← max{1, k-q}
     │       跳出循环
     └─ 否则 (是少数类样本):
          count ← 0   (重置计数器)
          
  5. 取前 t 个样本作为候选辅助种子:
     C(x_i) = {x_{i1}, x_{i2}, ..., x_{it}}
     
  6. 返回 C(x_i)
```

**函数解读**：
- $q$ 是唯一的参数。它的含义是"容忍度"——如果在某个方向连续遇到 $q$ 个多数类样本，就认为已经进入了多数类的密集区域，不必再往外扩展。反过来，如果多数类样本只是零星出现（连续不超过 $q-1$ 个），说明该区域是类别交叠区，仍有可能是少数类的潜在区域。
- $t = \max\{1, k-q\}$ 的含义：当第 $k$ 个样本触发了"连续 $q$ 个多数类"的条件时，CMR的边界应退回到这 $q$ 个连续多数类中的第一个之前的位置，即 $k-q$（如果 $k-q \geq 1$，否则至少保留最近的那个样本）。
- 对于一个离群少数类样本，其最近邻几乎都是多数类样本，因此 $k$ 会很小（可能在检查最初几个样本时就触发条件），CMR将非常小。这自动防止了在离群点周围扩散合成样本。
- 对于一个内部少数类样本，其近邻列表中多数类样本出现得很晚，CMR会很大——包含了大量少数类近邻样本。

#### 3.1.3 函数二：IdeCleanReg —— 识别干净子区域

**直观理解**：CMR确定了可能属于少数类的区域，但CMR内部有可能包含多数类样本。IdeCleanReg进一步检查：对于 $x_i$ 和 CMR内的每个候选辅助种子 $x_{ip}$，以它们的中点 $x_c$ 为球心、以它们距离的一半 $r_p$ 为半径构成的超球区域 $S(x_i x_{ip})$，是否包含任何多数类样本？如果不包含，则该子区域是"干净的"。

判断方法：检查在 $x_i$ 的近邻列表中排在 $x_{ip}$ 之前的多数类样本（即 $x_{i1}, ..., x_{i(p-1)}$ 中的多数类），是否落在这个超球区域内。如果没有任何一个多数类样本落入，$x_{ip}$ 对应的子区域就是干净的。

**中文伪代码**：

```
函数 IdeCleanReg(x_i, C(x_i), S_min):
────────────────────────────────────────────
输入:
  x_i      — 当前考虑的少数类样本
  C(x_i)   — x_i 的候选辅助种子集
  S_min    — 少数类样本集

输出:
  A(x_i)   — x_i 的（合格）辅助种子集

步骤:
  1. 初始化 A(x_i) = ∅ (空集)
  
  2. 遍历 p = 1, 2, ..., |C(x_i)|:
     
     a) 计算中点:
        x_c = (x_i + x_{ip}) / 2
        
     b) 计算半径:
        r_p = (1/2) × Distance(x_i, x_{ip})
        
     c) 假设子区域是干净的:
        flag_clean = 1 (true)
        
     d) 检查前 p-1 个候选种子中的多数类:
        遍历 l = 1, 2, ..., p-1:
          如果 x_{il} ∉ S_min (是多数类) 且 Distance(x_c, x_{il}) < r_p:
            flag_clean = 0  (发现多数类样本在子区域内)
            跳出内层循环
            
     e) 如果是干净的:
          A(x_i) ← A(x_i) ∪ {x_{ip}}   (将x_{ip}加入合格辅助种子)
          
  3. 返回 A(x_i)
```

**关键设计细节**：
- 只需要检查前 $p-1$ 个候选辅助种子中的多数类样本，因为后 $p+1, p+2, ...$ 个样本距离 $x_i$ 比 $x_{ip}$ 更远，它们不可能落在以 $x_i$ 和 $x_{ip}$ 为端点的子区域中。
- 如果一个候选辅助种子是少数类（属于 $S_{min}$），则不需要检查它，因为它本就属于少数类区域。
- 干净子区域的形成逻辑是：虽然CMR内部可能散布着多数类样本，但在某些特定方向上，两个少数类样本（或一个少数类与一个多数类）之间的区域是"干净"的——没有任何多数类样本落在这个区域内。

#### 3.1.4 函数三：Generate —— 生成合成样本

**直观理解**：在确定了每个少数类样本的合格辅助种子后，Generate函数在这些种子对应的子区域中随机生成合成样本。生成方式是标准的线性插值（如同SMOTE），但如果辅助种子是多数类样本，则插值的范围缩减为 $[0, \frac{1}{2}]$，即合成样本更靠近少数类原始样本。

**中文伪代码**：

```
函数 Generate(A, S_min, S_maj, z):
─────────────────────────────────────
输入:
  A         — 所有少数类样本的辅助种子映射
  S_min     — 少数类样本集
  S_maj     — 多数类样本集
  z         — 需要生成的合成样本总数

输出:
  S_syn     — 合成样本集

步骤:
  1. S_syn = ∅
  
  2. 当 |S_syn| < z 时循环:
       对每个 x_i ∈ S_min:
         
         a) 从 A(x_i) 中随机选择一个辅助种子 x_s
         
         b) 生成随机数 g ∈ [0, 1]
         
         c) 如果 x_s ∈ S_maj (是多数类样本):
              g = (1/2) × g    (将插值范围压缩到 [0, 0.5])
              
         d) 生成合成样本:
            x_syn = x_i + g × (x_s - x_i)
            
         e) S_syn ← S_syn ∪ {x_syn}
         
         f) 如果 |S_syn| == z:
              跳出循环
              
  3. 返回 S_syn
```

**关键设计解读**：

- **等量生成**：OREM为每个原始少数类样本生成大致相等数量的合成样本。这通过 `while` 循环中的 `for each` 实现——每轮循环中每个少数类样本各生成一个合成样本，直到总数达到 $z$。
- **多数类作为辅助种子的处理**：当辅助种子 $x_s$ 是多数类样本时（即该多数类样本位于少数类区域的边界上），插值系数 $g$ 被压缩到 $[0, 0.5]$，确保合成样本更靠近少数类原始样本 $x_i$。这比完全禁用多数类作为辅助种子更合理——因为边界多数类样本也携带着"类边界在哪里"的重要信息。
- **随机性**：每次从 $A(x_i)$ 中随机选择辅助种子，且插值系数 $g$ 也是随机的，保证了合成样本的多样性。

#### 3.1.5 OREM工作机制的深入剖析

论文将少数类样本分为三种类型，并分析了OREM如何自适应地处理它们：

```
少数类样本的三种类型:
┌──────────────────────────────────────────────────────────────┐
│  ① 内陆样本 (Inland samples)                                │
│     位于少数类簇的内部                                      │
│     → CMR 很大，几乎全是少数类                               │
│     → 大量辅助种子，大量干净子区域                           │
│     → 合成样本在其周围丰富地扩展少数类区域                   │
├──────────────────────────────────────────────────────────────┤
│  ② 边界样本 (Borderline samples)                            │
│     位于类别边界处                                          │
│     → CMR 中等大小，包含类别交叠区域                         │
│     → 通过干净子区域识别，谨慎选择辅助种子                   │
│     → 某些不安全的子区域被排除 (如图中S(x_b x_b1))           │
│     → 但边界的多数类样本也可作为辅助种子                     │
│     → 合成样本可向多数类区域方向推进类别边界                 │
├──────────────────────────────────────────────────────────────┤
│  ③ 离群点 (Outliers)                                       │
│     远离大多数其他少数类样本                                │
│     → CMR 非常小，因为近邻几乎全是多数类                     │
│     → 极少数辅助种子                                        │
│     → 防止在离群点周围扩散合成样本（避免噪声）               │
└──────────────────────────────────────────────────────────────┘
```

**OREM与传统k-NN方法的对比优势**：

- **不需要k参数**：k-NN方法使用统一的 $k$ 值对所有少数类样本找近邻。如果 $k$ 太小，对内陆样本会生成几乎重复的合成样本；如果 $k$ 太大，边界样本和离群点的过采样会产生严重的过度泛化问题。OREM通过 $q$ 参数（连续多数类计数）来自适应地确定每个样本的辅助种子数量，而不是使用统一的 $k$。
- **不需要聚类假设**：OREM不像聚类方法那样要求少数类数据呈现清晰的聚类结构，也不受限于合成样本只能落在原始少数类凸包内的限制。

### 3.2 OREM-M：OREM的多类扩展

#### 3.2.1 为什么需要OREM-M

OREM在二分类场景下通过只在干净子区域生成合成样本，有效减少了合成少数类样本与多数类样本之间的重叠。然而在多类场景下，还有一个OREM没有处理的问题：**不同少数类合成样本之间的类别重叠**。

在多类不平衡数据中，当多个少数类都需要过采样时，A类生成的合成样本可能落入B类的区域。这种重叠会使分类器更难区分不同的少数类。

#### 3.2.2 核心思想：迭代生成 + 最近邻拒绝

OREM-M在OREM的基础上增加了一个**迭代生成机制**：合成样本一个一个地生成，每生成一个就检查其最近邻——如果最近邻属于另一个少数类（无论是原始样本还是已生成的合成样本），则拒绝这个合成样本。更进一步，如果最近邻是另一个少数类的合成样本，还要把这个"侵入"的合成样本也删除。

这种机制在效果上形成了一种**"先到先得"的空间竞争**：少数类之间争夺干净的空白区域，较小的少数类（需要更多采样的类）有更高概率优先选择位置。

#### 3.2.3 OREM-M完整算法

**中文伪代码**：

```
算法2: OREM-M(S, q, zz)
═══════════════════════════════════════════════════════════
输入:
  S        — 全部训练样本集
  q        — 计数参数（与OREM相同）
  zz       — 长度为 |C| 的向量，zz[c] 表示需要为第c类
             生成的合成样本数量

输出:
  S_syn    — 合成样本集

───────────────────────────────────────────────────────────
主流程:
───────────────────────────────────────────────────────────

1. S_syn = ∅  (初始化合成样本集为空)

2. 预计算所有少数类样本的辅助种子:
   A ← PrepareCleanReg(S, zz)
   
   【说明】对每个需要进行过采样的少数类中的每个样本，
   调用DiscovCMR和IdeCleanReg计算其合格辅助种子。

3. while sum(zz) ≠ 0:  (还有合成样本需要生成)
    
    a) 计算采样分布:
       sampling_distr = zz / sum(zz)
       (各类被选中的概率 = 该类还需生成的样本数 / 总剩余样本数)
       → 较小的少数类（需要生成更多样本的类）有更高概率被选中
       
    b) 按采样分布随机选择一个少数类 c
       
    c) 从类c中随机采样一个样本 x_i^c
    
    d) 尝试生成一个合成样本:
       x_syn ← Generate(A(x_i^c), x_i^c, S\S_c, 1)
       (将除类c之外的样本全部视为"多数类"来生成合成样本)
       
    e) 找到 x_syn 在 S ∪ S_syn 中的最近邻 x_nn
       获取 x_nn 的类别标签 y_nn
       
    f) 检查与拒绝:
       如果 y_nn ≠ c 且 x_nn 是合成少数类样本:
         → 删除 x_nn (从 S_syn 中移除这个"侵入"的合成样本)
       否则:
         → S_syn ← S_syn ∪ {x_syn}  (接受该合成样本)
         
    g) zz[c] ← zz[c] - 1  (该类还需生成的样本数减1)

4. 返回 S_syn
```

**PrepareCleanReg 函数**：

```
函数 PrepareCleanReg(S, zz):
────────────────────────────────
输入:
  S        — 全部样本
  zz       — 各类需生成合成样本数

输出:
  A        — 所有样本的辅助种子映射

步骤:
  1. 将 S 按类划分为 S_1, S_2, ..., S_{|C|}
  
  2. 对每个类 c = 1, 2, ..., |C|:
      如果 zz[c] == 0: (该类不需要过采样)
        跳过
      对类c中的每个样本 x_i^c:
        a) 将类c作为"少数类"，其他所有类作为"多数类":
           C(x_i^c) ← DiscovCMR(x_i^c, S_c, S\S_c, q)
        b) 识别干净子区域:
           A(x_i^c) ← IdeCleanReg(x_i^c, C(x_i^c), S_c)
  
  3. 返回 A
```

**关键设计要点**：

1. **概率优先小类**：采样分布 `sampling_distr = zz / sum(zz)` 确保需要生成更多合成样本的少数类（通常是更小的类）有更高概率优先放置合成样本。这类似于"小的先占位置"。

2. **最近邻拒绝机制**：生成的合成样本如果在另一个少数类的合成样本附近，不仅拒绝当前样本，还删除那个"被侵入"的合成样本（第10-11行）。这是一种**双向清理**机制，进一步净化了特征空间。

3. **一次生成一个**：与OREM批量生成不同，OREM-M逐个生成合成样本，每步都进行最近邻检查。这确保了每次生成都不会破坏已建立的空间结构。

### 3.3 OREMBoost：将OREM嵌入Boosting框架

#### 3.3.1 设计动机

在Boosting框架中嵌入重采样技术有两个好处：
1. 每轮平衡训练数据，减少基分类器对多数类的偏向
2. 通过添加/移除样本增加训练数据的多样性，进而提升基分类器的预测多样性

#### 3.3.2 与OREM的集成方式

OREMBoost与传统boosting集成方法（如SMOTEBoost、RUSBoost）的框架相同，但有两个关键不同点：

1. **预计算辅助种子**（第1行）：在boosting迭代开始前，基于**全部训练数据**预先计算每个少数类样本的辅助种子。这确保了干净区域的可靠识别。

2. **利用轮次权重分布**（第8行）：每轮boosting中，使用预计算的辅助种子 $A$ 和当前轮的样本权重分布 $D_t$ 来指导过采样。

**中文伪代码**：

```
算法3: OREMBoost(S, q, zz, T)
═══════════════════════════════════════════════════════════
输入:
  S        — 训练集 {(x_i, y_i)}, y_i ∈ C
  q        — OREM的计数参数
  zz       — |C|维向量，各类需生成的合成样本数
  T        — 迭代轮数
  h        — 基分类器类型

输出:
  H(x) = argmax_{y∈C} Σ_{t=1}^{T} (log(1/β_t) × h_t(x, y))
  (加权投票的集成分类器)

───────────────────────────────────────────────────────────

1. A ← PrepareCleanReg(S, zz)   (预计算所有辅助种子)

2. 初始化样本权重:
   D_1(i) = 1/n,  i = 1, 2, ..., n
   
3. 初始化标签权重分布:
   w_{1}^{i,y} = D_1(i) / (|C| - 1),  i=1,...,n; y∈C\{y_i}
   (对每个样本，将其权重均匀分给所有错误的标签)

4. for t = 1 to T:     (Boosting主循环)
    
    a) 计算样本权重:
       W_t(i) = Σ_{y≠y_i} w_t^{i,y}
       q_t^{i,y} = w_t^{i,y} / W_t(i)   (y ≠ y_i)
       D_t(i) = W_t(i) / Σ_{i=1}^{n} W_t(i)
       
    b) 使用OREM过采样生成第t轮的平衡训练集:
       S_t ← OREMOver(S, D_t, A, zz)
       
    c) 在 S_t 上训练弱分类器 h_t
    
    d) 计算伪损失 (pseudo-loss):
       ε_t = (1/2) Σ_{i=1}^{n} D_t(i) ×
             (1 - h_t(x_i, y_i) + Σ_{y≠y_i} q_t^{i,y} × h_t(x_i, y))
       
       【解释】伪损失衡量的是分类器在多类标签上的加权错误率：
       - 对于每个样本，1 - h_t(x_i, y_i) 是真实标签上的"错误"
       - Σ q_t^{i,y} × h_t(x_i, y) 是错误标签上的"置信度"
       
    e) 计算 β_t = ε_t / (1 - ε_t)
       (β_t < 1 当且仅当 ε_t < 0.5)
       
    f) 更新标签权重:
       w_{t+1}^{i,y} = w_t^{i,y} × β_t^{(1/2)(1 + h_t(x_i, y_i) - h_t(x_i, y))}
       对 i=1,...,n; y∈C\{y_i}
       
       【解释】如果 h_t 在真实标签 y_i 上置信度高(+1)，在错误标签y上置信度低(0)，
       指数约为1，被误分类的样本对(y_i, y)的权重增大(乘以β_t<1的指数<1)
       实际上这是AdaBoost.M2的标准权重更新规则

5. 返回集成分类器 H(x)
```

**OREMOver 函数**：

```
函数 OREMOver(S, D_t, A, zz):
──────────────────────────────────
输入:
  S        — 原始训练集
  D_t      — 第t轮的样本权重分布
  A        — 预计算的辅助种子映射
  zz       — 各类需生成的合成样本数

输出:
  S_t      — 第t轮的平衡训练集

步骤:
  1. S_t = ∅
  2. 将 S 划分为各类的子集 S_1, ..., S_{|C|}
  
  3. 对每个类 c = 1, ..., |C|:
     a) 按权重分布 D_t(S_c) 有放回地从 S_c 中采样
        Ŝ_c ← 采样大小为 |S_c| 的样本集
        (高权重样本可能被多次选中，低权重可能不出现)
        
     b) 对 i = 1 到 zz[c]:
        随机从 Ŝ_c 中选一个样本 x_i^c
        x_syn ← Generate(A(x_i^c), x_i^c, S\S_c, 1)
        S_t ← S_t ∪ {x_syn}
        
     c) S_t ← S_t ∪ Ŝ_c   (加入原始样本)
  
  4. 返回 S_t
```

**关键设计分析**：

1. **预计算与在线生成的分离**：`PrepareCleanReg` 是最耗时的部分（需要识别干净子区域），放在循环之前只执行一次；而合成样本的生成（`OREMOver`）放在循环内，利用每轮的权重分布。这种分离大幅降低了时间复杂度。

2. **权重信息的使用**：`OREMOver` 中按 $D_t$ 分布有放回采样，使得被频繁误分类的样本有更高的出现概率，从而产生更多的合成样本——这符合boosting的"关注困难样本"的哲学。

3. **Ŝ_c 的变化增加多样性**：每轮的 Ŝ_c 取样于权重分布，因此每轮参与生成合成样本的原始样本集合不同，这增加了训练数据的多样性。

### 3.4 计算复杂度分析

设样本总数 $n$、少数类样本数 $n_{min}$、合成样本数 $n_s$。

**OREM的两个步骤**：

1. **找CMR**：对每个少数类样本 $x_i$，计算其到所有其他样本的距离：$O(n-1)$ 次距离计算。

2. **识别干净子区域**：每个少数类样本 $x_i$ 的CMR中最多有 $n_{cmr} = \min(q \times (n_{min}-1), n-1)$ 个候选辅助种子。检查第 $p$ 个候选种子对应的子区域时，需要验证前 $p-1$ 个中的多数类样本。距离计算次数为 $\sum_{p=1}^{n_{cmr}} (p-1) = \frac{n_{cmr}(n_{cmr}-1)}{2} \leq \frac{(n-1)(n-2)}{2}$。

**最坏情况复杂度**：$O(n_{min} \times n^2)$。

**实际复杂度**：论文在补充材料中通过实证分析发现，实际距离计算操作仅为 $O(n_{min} \times n)$ 的 7.123 倍（OREM）和 3.755 倍（OREM-M）。最坏情况需要CMR包含全部多数类样本，这在实践中几乎不可能发生。

### 4.1 OREM在二类不平衡数据集上的性能

#### 4.1.1 实验设置

**数据集**：28个来自UCI的真实世界二类不平衡数据集，不平衡率（IR）从1.87到14.60不等，包含低维和高维数据。

**分类器**：C4.5（决策树，使用Weka的J48实现，Laplace平滑、不剪枝）、NN（神经网络，Weka的MLP，500轮训练，学习率0.1，10个隐藏神经元）、SVM（LibSVM，线性核，参数C通过5折交叉验证在 $\{2^{-3}, 2^{-2}, ..., 2^{10}\}$ 范围内搜索）。

**评估指标**：F1、G-mean、AUC。每个数据集执行10次分层5折交叉验证的平均结果。

**对比方法**（8种代表性过采样算法）：

| 方法 | 类型 | 参数设置 |
|------|------|----------|
| SMOTE | k-NN插值过采样 | k=5 |
| MWMOTE | 聚类插值过采样 | k1=5, k2=3, k3=|S_min|/2 |
| INOS | 结构保持过采样 | k=15, Q=5, r=0.7 |
| RACOG | 概率分布过采样 | b=100, α=20 |
| wRACOG | 概率分布过采样 | 滑动窗口=10, 阈值=0.02 |

| GDO | 高斯分布过采样 | k=5, α=1 |
| FWSMOTE | 特征加权过采样 | k=5, Fisher特征排序 |

**统计分析方法**：Wilcoxon符号秩检验，显著性水平 $\alpha=0.05$ 和 $\alpha=0.1$。

**再平衡方式**：将少数类过采样至与多数类数量相同（完全平衡）。

#### 4.1.2 与代表性过采样方法的对比结果

表4（原论文Table 4）展示了Wilcoxon符号秩检验的p值。主要结论：

- **OREM在绝大多数情况下取得了统计上显著的优势**（标记为"++"的在 $\alpha=0.05$ 水平显著，"+\*"在 $\alpha=0.1$ 水平显著）。

- 在平衡准确率（BA）上排名**最好**
- 这表明OREM能在提高少数类准确率的同时，不过分损害多数类的准确率

#### 4.1.3 OREM消融实验（与变体对比）

论文设计了OREM的四种变体：

| 变体 | 修改方式 | 含义 |
|------|----------|------|
| OREM w/o S1 | 删除步骤1 | 所有其他样本都是候选辅助种子 |

**主要发现**（表5的Wilcoxon检验结果）：

- OREM在任何指标和分类器上都不显著劣于任何变体

**结论**：两步联合（先框定候选区域，再清洗）是最鲁棒的策略。

#### 4.1.4 参数敏感性分析

$q$ 是OREM的唯一参数。实验在7个不同IR的数据集上测试了 $q$ 从3到9（甚至更大）的性能变化：

- $q=5$ 或 $7$ 时性能最好
- $q \geq 9$ 后性能普遍下降——CMR过大，包含了太多空洞区域（hollow regions）
- **推荐**：$q \in [5, 7]$ 是合理的设置范围

**高维数据的局限性**：以上实验基于低维数据集。在高维数据（如时间序列和基因表达微阵列数据）上，由于距离度量的区分度降低，OREM的优势不明显。论文指出需要为高维不平衡问题设计专门的过采样方案。

### 4.2 OREM-M在多类不平衡数据集上的性能

#### 4.2.1 实验设置

**数据集**：21个多类真实世界不平衡数据集，包括UCI和序数回归基准数据集。

**评估指标**：macro-F1、MG（多类G-mean）、MAUC（多类AUC）。

**对比方法**：SMOTE、MDO（结构保持）、SMOM（论文前作）、MC-RBO（径向基）。

**再平衡方式**：定义各类的不平衡度（imbalance degree）为：

$$ID_{c_i} = \frac{\sum_{q \neq i} n_{c_q}}{(|C|-1) \times n_{c_i}}$$

其中 $|C|$ 是类别数，$n_{c_i}$ 和 $n_{c_q}$ 分别是类 $c_i$ 和 $c_q$ 的样本数。只对不平衡度 $>1.2$ 的类进行过采样，直至每类的不平衡度都不超过1.2。这避免了将所有类都过采样到与最大类相同大小（可能引入大量冗余合成样本）。

- 这验证了OREM-M在多类不平衡问题上的强竞争力

## 五、总结与未来方向

### 5.1 论文贡献总结

| 方法 | 核心创新 | 关键机制 |
|------|----------|----------|
| **OREM** | 两阶段可靠定位少数类区域 | (1) DiscovCMR：自适应探索候选区域，不需要k参数；(2) IdeCleanReg：识别干净子区域，排除多数类侵入 |
| **OREM-M** | 迭代生成+最近邻拒绝 | 逐个生成合成样本，防止不同少数类的合成样本之间重叠；小类优先的空间竞争策略 |
| **OREMBoost** | 将OREM嵌入boosting | 预计算辅助种子+权重引导的在线生成，形成正向协同 |

### 5.2 未来研究方向

1. **最优过采样度的确定**：OREM/OREM-M需要预设合成样本总数，且为每个原始少数类样本生成大致等量的合成样本。未来的研究可以在类级别和样本级别自适应地确定最优过采样度。

2. **利用多数类信息辅助定位少数类区域**：当少数类样本极端稀缺时，仅靠少数类的局部信息可能不可靠。可以考虑利用充足的多数类样本来帮助识别少数类的潜在区域。

3. **面向大规模不平衡数据的轻量级过采样算法**：利用全量数据设计高效的过采样方法，以处理大规模不平衡数据。

## 六、个人理解与核心思想提炼

OREM/OREM-M的方法论可以用一句话概括：**"先探索边界，再净化空间，最后安全填充"**。

从这个角度来看，OREM的设计哲学与很多工程实践相通：

- **CMR的发现**类似于"先划出一个大致的可信区域"——只要还没有密集遇到多数类，就认为这片区域仍有可能是少数类的领土
- **干净子区域的识别**类似于"在可信区域内排除雷区"——逐个检查每个子方向，确认没有多数类"地雷"后才安全通行
- **迭代生成的拒绝机制**（OREM-M）类似于"先到先占，后来者检查是否侵犯已有领土"

这套方法体系的优雅之处在于：
- **自适应性**：不用k参数统一所有样本，而是通过$q$参数让每个少数类样本根据自身的近邻分布情况自适应确定辅助种子
- **安全性**：两步确认机制（CMR探索+干净子区域识别）最大限度地降低了在多数类区域生成合成样本的风险
- **可扩展性**：从二类到多类再到集成，形成了完整的方法体系
