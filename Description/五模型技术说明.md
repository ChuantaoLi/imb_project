## 1. DBCF — 深度平衡级联森林

### 1.1 论文出处

> **Deep balanced cascade forest: A novel fault diagnosis method for data imbalance**
> Hao Chen, Chaoshun Li, Wenxian Yang, Jie Liu, Xueli An, Yujie Zhao
> *ISA Transactions* 126 (2022) 428–439

### 1.2 算法原理

DBCF 同时融合**数据层方法**与**算法层方法**，再叠加**深度级联结构**：

**(A) Up-down Sampling（§3.1，数据层）**
- **接收率**（Eq.1）：对样本 $x_i$ 取其 N 个最近邻，设其中同类邻居距离之和占全部邻居距离之和的比例为 $r_i$。
  $r_i$ 高 → 同类邻居主导邻域 → 核心样本；$r_i$ 低 → 异类侵入 → 边界样本。
- **上采样**（Eq.2）：在两个同类少数类父样本间加权插值，权重偏向接收率更高（核心）的父样本：
  $$x' = \frac{x_i \cdot r_i + x_j \cdot r_j}{r_i + r_j}$$
- **下采样**：按 $1/r_i$（重要性倒数）的概率丢弃样本，即丢边界保核心，"使边界清晰"；实现中不再引入额外的“原始样本数保底”，仅保留防止随机清空整类的最小安全回补。

**(B) Balanced Forest（§3.2，算法层）**
- 用**平衡信息熵**（Balance Information Entropy, Bent，Eq.3）作为分裂不纯度：
  $$ratio_k = x_k / X_k,\quad p_k = ratio_k / \sum_j ratio_j,\quad Bent(D) = -\sum_k p_k \log_2 p_k$$
  其中 $x_k$ 为节点内该类样本数，$X_k$ 为**当前通道平衡训练集**中该类总数。Bent 以"该类到达节点的全局占比"度量各类，使少数类与多数类同等重要。
- 分裂准则为 Bent 下的信息增益（Eq.4，二叉分裂 V=2）。Bent 无法注入 sklearn 编译树，因此决策树**从零实现**（向量化、$O(nC)$ 单特征扫描所有分裂点）。

**(C) 多通道级联森林（§3.3，深度结构）**
- C（=2）个通道，每个通道喂入**独立的一次 Up-down 采样**结果（bagging 式多样性）。
- 通道内按 gcForest 风格生长级联：每层 4 个平衡森林，每森林用 k 折交叉验证得到**无泄漏**的类别分布向量（4C 维），与原始特征拼接后送入下一层。
- 在"growing set"上生长，直到"estimating set"上准确率停止提升（自适应深度，最大 5 层）。
- 末层平均 4 个森林得到通道输出，2 个通道再平均得到最终预测。

### 1.3 核心组件

| 类/函数 | 作用 |
|---------|------|
| `reception_rate()` | 计算接收率 $r_i$（Eq.1），基于 k-d/ball 树 |
| `_weighted_pair_interpolate()` | 接收率加权插值生成少数类合成样本（Eq.2） |
| `up_down_sample()` | 单次 Up-down 采样 → 通道平衡数据集 |
| `BalancedTree` | Bent 不纯度二叉决策树（从零实现） |
| `BalancedForest` | BalancedTree 的 bagging 集成 = 一个平衡森林 |
| `CascadeForestChannel` | 单通道 gcForest 级联（k 折 OOF、自适应深度） |
| `DBCF` | 顶层封装：多通道 + Up-down 采样 + 级联 |

**顶层 `DBCF` 构造参数：**

> 此处统一适用的是"每森林树数 = 30"。

## 2. DDPM — 扩散模型数据增强故障诊断

### 2.1 论文出处

> **Denoising diffusion probabilistic model-enabled data augmentation method for intelligent machine fault diagnosis**
> Pengcheng Zhao, Wei Zhang, Xiaoshan Cao, Xiang Li
> *Engineering Applications of Artificial Intelligence* 139 (2025) 109520

### 2.2 算法原理

**(1) 类条件 DDPM（§2.1，扩散主体）**
- **前向过程**（Eq.1-4）：
  $$q(x_t \mid x_0) = \mathcal{N}\!\left(\sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I\right),\quad \bar\alpha_t=\prod_{i\le t}(1-\beta_i)$$
- **逆向过程**（Eq.5-10）：用神经网络参数化 $q_\theta(x_{t-1}\mid x_t)$。
- **训练目标**（Eq.11，简化 MSE）：
  $$L = \mathbb{E}\!\left[\big\|\epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon,\ t)\big\|^2\right]$$
- **采样**（Eq.12 / Algorithm 1，祖先去噪）：
  $$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\!\left[x_t - \frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right] + \sigma_t Z,\quad Z\sim\mathcal{N}(0,I)$$
- 线性 $\beta$ 调度，$T=1000$ 步。噪声预测器为 **类条件 1-D U-Net**（FiLM 条件注入时间步与类别）。
- 论文用 CWT 把 1-D 信号转 2-D 时频图后训练；本基准数据已是表格特征向量，因此这里实现的是**表格域适配版**：直接在特征向量上训练扩散模型。该实现保留论文的扩散目标、采样和增广思想，但不应被写成原论文 `CWT -> 2-D 图像` 管线的字面复现。

**(2) 数据增强**：用训练好的 DDPM 为每个少数类生成合成样本，补齐到多数类规模（过采样）。

**(3) 故障诊断分类器**：论文为 CNN 诊断头（3 conv + 3 pool + 2 FC，ReLU/dropout/softmax，Adam 1e-3，batch 64，300 epoch），当前代码默认也按该路径执行；`RandomForest(30)` 仅保留为统一评测外壳的可选适配器，不再作为默认值。

## 3. DEAHS — 动态集成 + 自适应分层采样

### 3.1 论文出处

> **Dynamic ensemble fault diagnosis framework with adaptive hierarchical sampling strategy for industrial imbalanced and overlapping data**
> Haoyan Dong, Chuang Peng, Lei Chen, Kuangrong Hao
> *Reliability Engineering and System Safety*, 2025

### 3.2 算法原理

DEAHS 由 **外层 + 内层 + 动态集成**三层组成：

**(外层) SAC 自适应欠采样**
- 用 Soft Actor-Critic 强化学习动态选择欠采样参数 $(\mu,\sigma)$。
- **状态**（Eq.5）：多数类训练/验证集损失的直方图（各 b 个箱）+ 验证集少数类准确率，维度 $2b+(C-1)$。
- **动作**：高斯混合采样参数 $(\mu,\sigma)$（Eq.8）。
- **奖励**：验证集上 [BA, G-mean, F1-macro, F1-micro] 提升的加权和。
- 欠采样（Eq.8）按高斯+均匀混合权重从多数类中抽取。

**(内层) 成员熵 + 加权过采样**
- **隶属度**（Eq.9）：$m_i^j = 1/\sum_k (d_i^j/d_i^k)^{2/(n-1)}$。
- **成员熵**（Eq.10）：$H(x_i)=-\sum_k m_i^k\log m_i^k$。
- **区域划分**（Eq.11-12）：阈值 $T_{ov}=\mu_H+\sigma_H$，熵高 → 重叠区，熵低 → 安全区。
- **类间散度**（Eq.13）：$S_B$。
- **加权过采样**（Eq.14-15）：重叠区少数类按贡献度 $\alpha_i=(x_i-\mu_j)^\top S_B(x_i-\mu_j)$ 加权过采样；安全区用 k-NN 插值（SMOTE 等价手工实现）。

**(集成)** 30 个 RandomForest 基分类器，平均概率集成（Eq.2）。

### 3.3 核心组件

| 类/函数 | 作用 |
|---------|------|
| `ReplayBuffer` | SAC 经验回放池 |
| `SACActor` / `SACCritic` | SAC 的高斯策略 Actor 与 Twin-Q Critic |
| `SACAgent` | Soft Actor-Critic 完整训练/更新 |
| `compute_membership_and_entropy()` | 隶属度（Eq.9）与成员熵（Eq.10） |
| `divide_regions()` | 安全/重叠区划分（Eq.11-12） |
| `compute_between_class_scatter()` | 类间散度 $S_B$（Eq.13） |
| `weighted_oversample()` | 加权 SMOTE 过采样（Eq.14-15） |
| `DEAHS` | 顶层框架：SAC 外层 + 内层过采样 + 动态集成 |

## 4. DeepSMOTE — 深度学习融合 SMOTE

### 4.1 论文出处

> **DeepSMOTE: Fusing Deep Learning and SMOTE for Imbalanced Data**
> Damien Dablain, Bartosz Krawczyk, Nitesh V. Chawla
> *IEEE Transactions on Neural Networks and Learning Systems*, 2023

### 4.2 算法原理

DeepSMOTE 与"自编码器后再 SMOTE"的两点关键区别：

1. **惩罚损失（Penalty Loss）**：训练时随机抽一个类，取 |b| 个同类样本编码后**置换顺序**再解码；解码器必须为每个槽重建**不同的**同类实例，迫使其学会解码 SMOTE 产生的"中间嵌入"——这正是 DeepSMOTE 无需判别器（区别于 GAN/WAE 过采样）的原因。
2. **SMOTE 在学习的潜空间中进行**：先编码 → 在潜空间 SMOTE 插值 → 解码回输入域。

**Algorithm 1 流程：**
- 训练编码器/解码器：每 batch 同时最小化重建损失 RL 与惩罚损失 PL，总损失 TL=RL+PL。
- 生成样本：每个少数类编码 → 潜空间 SMOTE → 解码 → 平衡训练集 → 训练分类器。

**表格适配**：论文的 DCGAN 卷积编解码器（BatchNorm + LeakyReLU/ReLU，Tanh 输出）面向图像。本基准为 StandardScaler 归一化的表格特征，故保留相同设计（编码器 BN+LeakyReLU、解码器 BN+ReLU）但改用 MLP + 线性输出头（Tanh 会裁剪标准化特征）。潜空间 SMOTE 与惩罚损失训练严格按 Algorithm 1 实现。

### 4.3 核心组件

| 类/函数 | 作用 |
|---------|------|
| `Encoder` | MLP 编码器（BatchNorm + LeakyReLU → 潜嵌入） |
| `Decoder` | 镜像 MLP 解码器（BatchNorm + ReLU，线性/Tanh 输出） |
| `MLPClassifier` | 下游 MLP 分类器（表格版的 ResNet-18 头） |
| `derangement()` | 无不动点的置换（保证惩罚损失非平凡） |
| `latent_smote()` | 潜空间中的标准 SMOTE 插值 |

## 5. SPE — 自步集成

### 5.1 论文出处

> **Self-paced Ensemble for Highly Imbalanced Massive Data Classification**
> Zhining Liu, Wei Cao, Zhifeng Gao, Jiang Bian, Hechang Chen, Yi Chang, Tie-Yan Liu
> 2020 IEEE 36th International Conference on Data Engineering (ICDE)

### 5.2 算法原理

**Algorithm 1（自步集成）：**
1. 在随机欠采样得到的平衡子集（|N'|=|P|）上训练 $f_0$。
2. 对 $i=1..n-1$：
   - 当前集成 $F_i(x) = \frac1i\sum_{j<i} f_j(x)$。
   - 按"硬度"$H(x,y,F_i)$（∈[0,1]）把多数类切成 k 个箱：$B_l = \{(x,y)\mid (l-1)/k \le H < l/k\}$。
   - 各箱平均硬度 $h_l$；自步因子 $\alpha=\tan(i\pi/(2n))$；箱权重 $p_l = 1/(h_l+\alpha)$。
   - 按权重从各箱采样共 |P| 个样本，训练 $f_i$。
3. 返回 $F(x)=\frac1n\sum_m f_m(x)$（平均集成）。

**硬度函数**（论文默认，§VI 脚注3）：绝对误差 $H=|F(x)-y|$，二分类。多类推广为 $H=1-F(x)[y]$（1 减真实类预测概率），与二分类绝对误差**完全一致**。k=20 箱。

**自步因子调度**：论文"首轮 $\alpha=0$、末轮 $\alpha\to\infty$"；本实现按官方实现 `alpha = tan(pi/2 * i/(n-1))`，n-1 个自步伐使末轮达到 tan(π/2)（趋向均匀"骨架"采样）。

### 5.3 核心组件

| 类/函数 | 作用 |
|---------|------|
| `SelfPacedEnsemble` | SPE 主体（Algorithm 1） |
| `_hardness()` | 多类硬度 $H=1-F(x)[y]$（等价二分类绝对误差） |
| `_allocate_counts()` | 最大余数法分箱配额（总和 = target，每箱 ≤ 容量） |
| `_random_balance_subset()` | 随机欠采样到平衡子集（Line 2） |
| `_self_paced_subset()` | 硬度分箱 + 自步伐欠采样（Lines 5-9） |

### 5.4 参数与默认值

**顶层 `SelfPacedEnsemble` 构造参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `base_estimator` | obj/None | `None` | 基分类器 f（sklearn 接口）；None → `RandomForest(n_estimators=30)` |
| `n_estimators` | int | `30` | 集成基分类器数 n（论文默认 10；统一为 30） |
| `n_bins` | int | `20` | 硬度箱数 k（论文默认 20） |
| `hardness` | str | `'absolute'` | 硬度函数：`absolute`/`squared`/`entropy`（论文默认 absolute） |
| `random_state` | int | `42` | 随机种子 |

**命令行参数（`main()`）：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--base` | `'rf'` | 基分类器：`rf`=RandomForest（默认）/`dt`=DecisionTree |

## 6. 五模型横向对比

| 维度 | DBCF | DDPM | DEAHS | DeepSMOTE | SPE |
|------|------|------|-------|-----------|-----|
| **方法层面** | 数据+算法+深度 | 数据（生成） | 数据+算法+集成 | 数据（生成） | 数据+集成 |
| **平衡机制** | Up-down 采样 | 扩散过采样 | SAC 欠采样 + 加权过采样 | 潜空间 SMOTE | 自步伐欠采样 |
| **核心创新** | Bent 平衡熵树 + 多通道级联 | 类条件 DDPM 增强 | RL 自适应采样策略 | 惩罚损失 + 潜 SMOTE | 硬度分箱自步伐 |
| **分类器** | 平衡级联森林（自身） | RF(30) / CNN | 30×RF(30) 集成 | RF(30) / MLP | 30×RF(30) 集成 |
| **是否用深度网络** | 否（树集成） | 是（U-Net + CNN） | 是（SAC MLP） | 是（自编码器） | 否（树集成） |
| **依赖 GPU** | 否 | 建议（CPU 可降参） | 否（SAC 轻量） | 建议 | 否 |
| **输出 CSV** | `DBCF_Results.csv` | `DDPM_Results.csv` | `DEAHS_Results.csv` | `DeepSMOTE_{rf\|MLP}_Results.csv` | `SPE_Results.csv` |
| **统一基头** | 不替换 | RF(30) | RF(30) | RF(30) | RF(30) |
