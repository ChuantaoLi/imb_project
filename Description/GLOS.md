## 一、研究背景与动机

### 1.1 类别不平衡问题

在机器学习的各类实际应用中，**类别不平衡（class imbalance）** 是一个普遍存在的问题。简单来说，数据集中某些类别（多数类，majority classes）拥有的样本数量远多于其他类别（少数类，minority classes）。虽然少数类样本数量少，但它们在问题中往往扮演着关键角色——例如在疾病诊断中，患病样本通常是少数类，但却是我们最希望正确识别的对象。

传统的分类算法在面对不平衡数据时，往往会将少数类样本错误地分类为多数类，因为算法倾向于"迎合"样本数量更多的类别。因此，**不平衡学习（imbalanced learning）** 的核心目标是：在保证多数类高准确率的前提下，尽可能正确分类少数类样本。

### 1.2 多类不平衡问题的特殊挑战

大多数不平衡学习方法都是针对**二分类（two-class）** 问题设计的，但直接应用到多分类场景会面临额外的困难：

- **(a) 类别间的关系不再清晰**: 一个类别相对于样本数更多的类别是少数类，但相对于样本数更少的类别又可能是多数类。这种"相对性"让问题的定义变得更加复杂。
- **(b) 类别边界模糊、重叠严重**: 多个类别之间的决策边界交织在一起，很难区分。
- **(c) 少数类代表性不足**: 少数类样本太少，难以捕捉其真实分布特征，导致模型难以学习。

Zhou 和 Liu 的研究（2006）也指出：几乎所有的技术在处理二分类不平衡问题时都是有效的，但直接用于多分类任务可能会失效甚至产生负面影响。因此，专门研究多类不平衡分类问题具有重要意义。

### 1.3 现有过采样方法的局限性

过采样（oversampling）是解决不平衡问题最常用的技术之一，其核心思路是**为少数类生成新的合成样本**。它不会丢失原始数据中的重要信息（不像欠采样），且独立于下游分类器，易于实现。

经典的过采样方法包括：

| 方法 | 核心思想 | 局限性 |
|------|----------|--------|
| **ROS**（随机过采样） | 简单复制少数类样本 | 不增加新信息，容易过拟合 |
| **SMOTE**（2002） | 在少数类样本及其K近邻之间进行线性插值 | 忽略其他类别的信息，可能导致合成样本与其他类别重叠 |
| **Borderline-SMOTE**（2005） | 只对边界上的少数类样本进行过采样 | 仅考虑局部分布 |
| **ADASYN**（2008） | 根据学习难度自适应地为每个少数类样本分配权重 | 对复杂多类场景不够鲁棒 |
| **Safe-Level-SMOTE**（2009） | 根据安全等级生成样本 |  |
| **MDO**（2015） | 利用协方差矩阵保持少数类的分布结构 | 易造成过度生成（overgeneration），损害多数类精度 |
| **MC-BRO**（2019） | 考虑所有类别的信息，在精度和召回率之间权衡 | |

**这些方法的共同问题是**：它们对所有少数类样本都使用**单一策略**来生成合成样本，完全忽视了不同少数类样本之间存在的**内在特征差异**（intrinsic characteristics）。比如，有些样本位于稀疏区域、有些位于类别边界、有些存在于小析取簇（small disjuncts）中——用同一种方式为它们生成样本，会导致部分合成样本冗余甚至无效，无法有效增强少数类的代表性，甚至可能损害多数类的分类精度。

### 1.4 本文的切入点

GLOS 提出了一种**全局-局部相结合**的过采样框架，核心创新在于：

1. 提出一个新的不平衡度量指标 **DID**（Discreteness-based Imbalance Degree，基于离散度的不平衡度），用于从类别级别区分多数类和少数类；
2. 根据每个少数类样本的**内在特征**，将其分为三类：Safe（安全型）、Borderline（边界型）、Small Disjunct（小析取簇型）；
3. 为每一类样本设计**专门的合成策略**，有针对性地生成新样本。

## 二、核心贡献与方法概览

### 2.1 主要贡献

1. **提出 DID 度量**：一个新的基于离散度的不平衡度指标，既可以清晰地区分多数类和少数类，又能自适应地确定每个少数类样本需要合成的样本数量。

2. **基于实例级离散度的样本选择**：通过比较每个样本的实例级离散度 $\lambda(x_i)$ 与所在类的类级离散度 $\theta_j$，筛选出"难学习"的少数类样本作为生成新样本的"主样本"（primary instances）。

3. **三类样本划分**：根据样本的局部分布特征，将选中的少数类样本划分为 Safe、Borderline 和 Small Disjunct 三类。

4. **三种针对性过采样策略**：
   - **MMO**（Majority-based Minority Oversampling）：为 Safe 样本设计，利用多数类的协方差矩阵生成新样本；
   - **AMBO**（Adaptive Multi-class Borderline Oversampling）：为 Borderline 样本设计，利用自适应线性插值推动决策边界；
   - **RRO**（Radial-based Random Oversampling）：为 Small Disjunct 样本设计，基于径向随机过采样扩展局部空间。

### 2.2 GLOS 整体流程

GLOS 的处理流程可概括为以下四个阶段：

```
原始数据 → 1. 实例选择 → 2. 实例划分 → 3. 针对性过采样 → 最终训练集
```

1. **实例选择**：计算 DID 和各类别的 $\theta_j$，将类别分为多数类和少数类；在每个类内部，选择 $\lambda(x_i) < \theta_j$ 的"难学习"样本作为 Selected 集；
2. **实例划分**：将 Selected 中的少数类样本按定义划分为 Safe、Borderline、Small Disjunct 三组；
3. **针对性过采样**：对三组样本分别用 MMO、AMBO、RRO 策略生成合成样本；
4. **构建训练集**：所有少数类 + 部分多数类样本 + 合成样本 = 最终训练数据。

> **直观类比**：可以把 GLOS 想象成一位有经验的教师，他会先诊断每个学生的学习困难类型。对于基础薄弱但处于孤立位置的学生（Safe），用一种教学策略；对于在知识边界挣扎的学生（Borderline），用另一种策略；对于分散在小团体中的学生（Small Disjunct），又用另一种策略。相比"一刀切"的教学方式，这种因材施教的方法能更有效地提升整体学习效果。

## 三、方法具体实现

### 3.1 DID：基于离散度的不平衡度量

#### 3.1.1 动机

传统的不平衡度量指标 **IR**（Imbalance Ratio）只描述最多数类和最少数类之间的样本数量比，无法反映数据内部的结构特征（如样本的紧密程度、分布一致性等）。而**标准差**可以度量数据的离散程度——一个类的离散度越低，说明其样本分布越稀疏（sparser），也就越难以学习。

#### 3.1.2 三层离散度的定义

GLOS 定义了三层离散度，由细到粗依次为：

**（1）实例级离散度（Instance-level Dispersion）—— $\lambda(x_i)$**

对于一个样本 $x_i \in \mathbb{R}^d$，定义以 $x_i$ 为中心、$R$ 为半径的超球体（hypersphere），$\lambda(x_i)$ 等于该超球体内与 $x_i$ 同类的样本数量：

$$\lambda(x_i) = \left|\{ x_i^n \mid \|x_i^n - x_i\|_2 \leq R, \; x_i^n \in c_j \land x_i \in c_j \}\right| \tag{3}$$

其中半径 $R$ 的定义为：

$$R = \alpha \cdot \min\{sd_1, sd_2, sd_3, \ldots, sd_d\} \tag{4}$$

其中 $sd_k$ 是数据集第 $k$ 个特征的标准差，$\alpha$ 是调节半径的超参数，推荐范围：

$$\alpha \in \left[1, \frac{\max(sd)}{\min(sd)}\right]$$

**直观理解**：$\lambda(x_i)$ 越小，说明 $x_i$ 的同类"邻居"越少，它处于越稀疏的区域，学习难度越大。

**（2）类级离散度（Class-level Dispersion）—— $\theta_j$**

对类别 $c_j$ 中所有样本的实例级离散度取平均值：

$$\theta_j = \frac{1}{C_j} \sum_{i=1}^{C_j} \lambda(x_i) \tag{2}$$

其中 $C_j$ 表示类别 $c_j$ 的样本数。

**直观理解**：$\theta_j$ 反映了整个类别 $c_j$ 的平均紧凑程度。$\theta_j$ 越小，说明该类整体上越松散（sparser），越难以学习——这样的类应被定义为**少数类**。

**（3）数据集级离散度——DID（Discreteness-based Imbalance Degree）**

对各类别的类级离散度按样本数加权平均：

$$DID = \sum_{j=1}^{m} \theta_j \cdot \frac{C_j}{N} \tag{1}$$

其中 $m$ 为类别总数，$N$ 为数据集总样本数。

**直观理解**：DID 是整个数据集的全局离散度基线。一个类的 $\theta_j$ 如果低于 DID，意味着它比数据集的"平均松散程度"还要松散，是真正的少数类。

#### 3.1.3 类别划分

利用 DID 将类别分为多数类和少数类：

$$
\begin{cases}
\text{Majority} = \{c_i \mid \theta_i \geq DID\} \\
\text{Minority} = \{c_i \mid \theta_i < DID\}
\end{cases}
\tag{5}
$$

**关键洞察**：这个划分不依赖于样本数量（不像传统的 IR），而是基于样本的**分布紧密程度**。一个类即使样本数量不少，但如果分布非常松散，也可能被划为少数类——这更贴合"学习难度"的本质。

---

### 3.2 实例选择（Instance Selection）

在每个类别内部，将样本分为 **Selected**（被选中，将用于生成新样本）和 **Rest**（剩余，作为辅助样本）：

$$
\begin{cases}
\text{Selected}_j = \{x_i \in c_j \mid \lambda(x_i) < \theta_j\} \\
\text{Rest}_j = \{x_i \in c_j \mid \lambda(x_i) \geq \theta_j\}
\end{cases}
\tag{6}
$$

**直观理解**：
- $\lambda(x_i) < \theta_j$ 意味着 $x_i$ 的局部密度低于本类的平均水平，它是本类中"更难学习"的样本；
- 这些 Selected 样本中的少数类样本成为**主样本**（primary instances），用于生成合成样本；
- Selected 中的多数类样本将被**移除**，因为它们可能造成额外的重叠，使少数类更难学习。

#### 合成样本数量的确定

对于每个被选中的少数类样本 $x_i$，其需要合成的样本数为：

$$syn\_num = \theta_j - \lambda(x_i)$$

> **设计动机**：$\theta_j - \lambda(x_i)$ 恰好度量了样本 $x_i$ 相对于类平均水平的"离散度缺口"。差值越大，说明该样本区域越需要补充样本。这种自适应的数量分配避免了生成过多冗余样本导致过拟合。

---

### 3.3 实例划分（Instance Partition）

虽然都是难学习的少数类样本，但它们的内在特征各不相同。GLOS 将它们分为三组。

首先需要引入跨类版本的实例离散度：

$$\lambda_D(x_i) = \left|\{ x_i^n \mid \|x_i^n - x_i\|_2 \leq R, \; x_i^n \in D \}\right| \tag{8}$$

与 $\lambda(x_i)$ 的区别在于：$\lambda_D(x_i)$ 统计的是以 $x_i$ 为中心、半径 $R$ 的超球体内**所有类别**的样本数（而不仅限于同类）。

#### 3.3.1 Safe（安全型）

定义如下：

$$\text{Safe} = \{x_i \mid x_i \in \text{Minority} \land \lambda_D(x_i) - \lambda(x_i) = 0 \land \lambda(x_i) \leq 5\} \tag{7}$$

**含义**：
- $\lambda_D(x_i) - \lambda(x_i) = 0$：在以 $x_i$ 为中心的邻域内**全是同类样本，没有其他类别的样本**。这意味着 $x_i$ 远离类别边界、远离其他类别的样本；
- $\lambda(x_i) \leq 5$：同类邻居很少（最多5个），说明处于稀疏区域。

**特征**：这类样本位于稀疏且孤立的区域，远离其他类别。它们对增加类的多样性有重要价值，但用 SMOTE 类方法容易过度生成、用高斯噪声容易过拟合。

#### 3.3.2 Borderline（边界型）

定义如下：

$$\text{Borderline} = \left\{x_i \mid 0.5 \leq \frac{\lambda(x_i)}{\lambda_D(x_i) - \lambda(x_i)} \leq 2\right\} \tag{9}$$

**含义**：令 $other = \lambda_D(x_i) - \lambda(x_i)$ 表示邻域内其他类样本的数量，则条件为：

$$0.5 \leq \frac{\lambda(x_i)}{other} \leq 2$$

即同类邻居和异类邻居的数量在同一数量级——说明该样本处于类别边界或重叠区域。

> 其中 0.5 和 2 是经验设定，在所有实验中统一使用。

**特征**：位于决策边界或类别重叠区域，是影响分类性能的关键样本。尤其在多分类任务中（类别数增加），边界样本的复杂性也随之增加。

#### 3.3.3 Small Disjunct（小析取簇型）

定义如下（通过排除法）：

$$\text{SmallDisjunct} = \{x_i \mid x_i \in c_j \land x_i \in \{\text{Selected}_j - \text{Safe} - \text{Borderline}\}\} \tag{10}$$

**特征**：这类样本将所在的类别分裂为不同的子簇（sub-clusters），导致类别代表性不足。它们可能位于其他类别的内部，也可能散落在所属类的各个小簇中。SMOTE 类方法容易合成冗余样本并导致过拟合，线性插值也不利于扩展其潜在分布区域。

---

### 3.4 三种过采样策略

#### 3.4.1 MMO：面向 Safe 样本的多数类引导少数类过采样

**设计动机**：Safe 样本虽然稀疏孤立，但它们远离其他类别，不容易造成重叠。MDO 虽然能保持样本的位置信息、增加多样性，但协方差矩阵不易获取。MMO 受 MDO 启发，但利用**多数类的协方差矩阵**来生成样本，并限制合成样本的区域，降低过度生成的风险。

**核心思想**：
1. 对每个 Safe 样本 $x_r$，以 $x_r$ 为中心、$R$ 为半径定义最大合成区域；
2. 计算每个多数类的协方差矩阵 $\Sigma_j$ 和均值 $mean_j$；
3. 在最大合成区域内生成新样本，新样本到每个多数类中心的**马氏距离（Mahalanobis distance）** 与 $x_r$ 到该多数类中心的马氏距离相等：

$$\sqrt{(x_{new} - mean_j)^T \Sigma_j^{-1}(x_{new} - mean_j)} = \sqrt{(x_r - mean_j)^T \Sigma_j^{-1}(x_r - mean_j)}$$

**中文伪代码（算法1：MMO）**：

```
算法1 MMO: Majority-based Minority Oversampling（基于多数类的少数类过采样）
--------------------------------------------------------------
输入: 参考样本 x_r, λ(x_r)
输出: 合成样本集合 X_syn

1.  syn_num ← θ_j - λ(x_r)            // 需要合成的样本数量
2.  while syn_num > 0 do
3.      for j = 1 to m do              // 对每个类别
4.          获取多数类j的均值 mean_j 和协方差矩阵 Σ_j
5.          dist_mean_j_xr ← √[(x_r - mean_j)^T Σ_j^(-1) (x_r - mean_j)]
                                        // 计算x_r到多数类j中心的马氏距离
6.          根据式(3)-(4)获取以x_r为中心、R为半径的超球体
7.          按以下两个条件生成新样本 x_new：
8.              条件1: √[(x_new - mean_j)^T Σ_j^(-1) (x_new - mean_j)] 
                         = dist_mean_j_xr
                    // x_new到多数类中心j的马氏距离与x_r相同
9.              条件2: |x_new - x_r| ≤ R
                    // x_new必须在x_r的R邻域内
10.         X_syn ← X_syn ∪ {x_new}
11.         syn_num ← syn_num - 1
12.     end for
13. end while
14. return X_syn
```

**直观解释**：MMO 相当于让合成样本"踩"在一个与参考样本 $x_r$ 相同距离的"等马氏距离轮廓"上，从而在不侵入多数类空间的前提下，安全地扩展少数类的分布范围。

#### 3.4.2 AMBO：自适应多类边界过采样

**设计动机**：Borderline 样本位于决策边界或类别重叠区域。SMOTE 类方法生成的样本能增强边界附近少数类的代表性，推动决策边界向多数类移动。但在多分类场景中，简单使用 SMOTE 可能会让**其他少数类**更难学习——因为你可能在向多数类推进边界的同时，侵入了另一个少数类的空间。AMBO 通过自适应方式处理这个问题。

**AMBO 的核心机制**：

1. 在以 $x_r$ 为中心、$R$ 为半径的超球体内，统计各邻近类的样本数 $num_c$；
2. 根据邻近类是多数类还是少数类，**调整权重**：
   - 若 $c$ 是多数类：$num_c \leftarrow num_c \times \frac{\theta_c}{\theta_i}$（放大权重，更关注多数类方向）
   - 若 $c$ 是少数类：$num_c \leftarrow num_c \times \frac{\theta_i}{\theta_c}$（缩小权重，减少对其他少数类的干扰）
3. 对 $num_c$ 进行归一化，得到每个邻近类的采样概率；
4. 计算 $D(x_r) = \min\{dist(x_r, x_i)\}$，即 $x_r$ 到邻域内最近异类样本的距离；
5. 根据采样概率从邻域中选择样本 $x$，沿 $x_r$ 到 $x$ 的方向进行**受控线性插值**：

$$x_{new} = x_r + (x - x_r) \times \frac{D(x_r)}{|x - x_r|} \times rand(0, 1)$$

**中文伪代码（算法2：AMBO）**：

```
算法2 AMBO: Adaptive Multi-class Borderline Oversampling（自适应多类边界过采样）
--------------------------------------------------------------
输入: 参考样本 x_r, λ(x_r)
输出: 合成样本集合 X_syn

1.  syn_num ← θ_j - λ(x_r)            // 需要合成的样本数量
2.  根据式(3)-(4)获取以x_r为中心、R为半径的超球体
3.  计算超球体内各邻近类的样本数 num_c   // c是类别索引
4.  if c ∈ Majority then
5.      num_c ← num_c × (θ_c / θ_i)    // 多数类方向：放大权重
6.  else
7.      num_c ← num_c × (θ_i / θ_c)    // 少数类方向：缩小权重
8.  end if
9.  归一化 num_c（使其和为1，作为选择邻近类c中样本的概率）
10. D(x_r) ← min{dist(x_r, x_i)}        // x_r到邻域内最近异类样本的距离
                                         // x_i为第2行定义超球体内的样本
11. syn_c ← syn_num × num_c             // 为每个邻近类分配的合成数
12. x_new ← x_r + (x - x_r) × [D(x_r) / |x - x_r|] × rand(0,1)
                                         // x是从邻近类c中随机选出的样本
                                         // rand(0,1)产生(0,1)间的随机数
13. X_syn ← X_syn ∪ {x_new}
14. return X_syn
```

**直观解释**：
1. 当参考样本 $x_r$ 周围有多个类别时，AMBO 会分别以不同的概率从不同类别中选取邻接样本进行插值；
2. 如果邻接样本来自**多数类**，AMBO 会放大其权重，让合成样本更偏向该方向，从而推动决策边界向多数类移动；
3. 如果邻接样本来自**其他少数类**，AMBO 会缩小其权重，减少对该少数类空间的侵占，保持少数类之间的初始结构；
4. 插值公式中乘以 $\frac{D(x_r)}{|x - x_r|}$ 确保合成样本不会跨越"安全距离" $D(x_r)$，始终比最近的异类样本更靠近 $x_r$。

#### 3.4.3 RRO：基于径向的随机过采样

**设计动机**：Small Disjunct 样本存在于小簇中，SMOTE 的线性插值容易生成冗余样本并过拟合，也不利于扩展潜在分布区域。RRO 采用径向随机生成的方式，有效扩展样本空间并显著减少冗余。

**RRO 的两种策略**：

1. **同簇场景**（邻域内只有同类样本，count = 1）：
   - 计算 $x_r$ 到邻域内其他同类样本的平均距离 $D_{avg}$；
   - 在以 $x_r$ 为中心、$D_{avg}$ 为半径的球体内随机生成新样本：
   $$|x_r - x_{new}| \leq D_{avg}$$

2. **异类邻近场景**（邻域内有其他类的样本，count > 1）：
   - 计算邻域内与 $x_r$ 同类的样本的均值 $mean_r$；
   - 计算 $mean_r$ 到邻域内最近异类样本的距离 $D_{max}$；
   - 在以 $mean_r$ 为中心、$D_{max}$ 为半径的球体内随机生成新样本：
   $$|mean_r - x_{new}| \leq D_{max}$$

**中文伪代码（算法3：RRO）**：

```
算法3 RRO: Radial-based Random Oversampling（基于径向的随机过采样）
--------------------------------------------------------------
输入: 参考样本 x_r, λ(x_r)
输出: 合成样本集合 X_syn

1.  syn_num ← θ_j - λ(x_r)            // 需要合成的样本数量
2.  根据式(3)-(4)获取以x_r为中心、R为半径的超球体
3.  计算超球体内不同类别数 count
4.  if count = 1 then                  // 邻域内只有同类
5.      计算 x_r 到邻域内其他同类样本的平均距离 D_avg
6.      在条件 |x_r - x_new| ≤ D_avg 下生成 x_new
7.  else                              // 邻域内有其他类
8.      mean_r ← 邻域内与x_r同类的样本均值
9.      D_max ← max(|mean_r - x|), target(x) ≠ target(x_r)
                                        // mean_r到最近异类样本的最大距离
10.     在条件 |mean_r - x_new| ≤ D_max 下生成 x_new
11. end if
12. 生成 syn_num 个样本并加入 X_syn
13. return X_syn
```

**直观解释**：
- RRO 不像 SMOTE 那样进行线性插值，而是在一个"安全球体"内随机生成样本；
- 当邻域内只有同类时，以 $x_r$ 为球心、平均间距为半径，自然扩展子簇；
- 当邻域内有异类时，以同类均值为球心、到最近异类的距离为半径，既扩展了子簇，又避免侵入其他类空间。

### 3.5 GLOS 完整算法

**中文伪代码（算法4：GLOS）**：

```
算法4 GLOS: Global-Local based Oversampling（基于全局-局部信息的过采样）
--------------------------------------------------------------
输入: 训练数据 X, 超参数 α
输出: 最终训练集 X_new

1.  根据式(2)计算每个类别j的类级离散度 θ ← {θ_1, θ_2, ..., θ_m}
2.  根据式(1)计算 DID                            // 全局不平衡度基线
3.  for j = 1 to m do                            // 遍历每个类别
4.      for i = 1 to C_j do                      // 遍历类别j的每个样本
5.          根据式(3)计算 λ(x_i^j)               // 该样本的实例级离散度
6.          if λ(x_i^j) ≤ θ_j then               // 该样本比类平均更稀疏
7.              Selected_j ← Selected_j ∪ {x_i^j} // 加入Selected集合
8.              if θ_j ≤ DID then                // 该类是少数类
9.                  将 x_i^j 划分到特定组 G ∈ {Safe, Borderline, SmallDisjunct}
                                                // 按式(7)(9)(10)
10.                 根据 G 使用对应的算法生成样本：
                      G = Safe     →  MMO
                      G = Borderline → AMBO
                      G = SmallDisjunct → RRO
11.             else                             // 该类是多数类
12.                 移除 x_i^j（多数类中的难学习样本）
13.             end if
14.         else
15.             Rest_j ← Rest_j ∪ {x_i^j}        // 加入Rest集合
16.         end if
17.     end for
18.     X_new ← X_new ∪ X_syn                    // 将合成的样本加入训练集
19. end for
20. return X_new
```

### 3.6 计算复杂度分析

GLOS 主要包含四个模块：

| 模块 | 计算复杂度 | 说明 |
|------|-----------|------|
| 类别划分（DID计算 + 分类） | $O(N_{max})$ | $N_{max}$ 是最大类的样本数 |
| 实例选择 | $O(N_{max})$ | |
| 实例划分 | $O(N_{Selected} \cdot N)$ | 需要考虑全局样本分布 |
| **MMO** | $O(N_{max} d^2 + N_{syn} d)$ | 需要矩阵分解，$d$ 为特征数 |
| **AMBO** | $O(N_{Primary} N + N_{syn} d)$ | |
| **RRO** | $O(N_{Primary} N + N_{syn} d)$ | |
| **总体** | $\max(O(N_{max} d^2), O(N_{Selected} N)) \approx O(N^2)$ | 瓶颈在实例划分或MMO |

## 四、实验结果与分析

### 4.1 实验设置

**数据集**：从 UCI 和 KEEL 仓库选取 21 个多类数据集，覆盖不同的 IR 值（1.48 ~ 173.40）、不同的类别数（3 ~ 11）、不同的样本量（106 ~ 9873）。

**对比方法**（5种）：
- SMOTE（$K=5$）
- Borderline-SMOTE（$K=5$）
- ADASYN（$\beta=1$）
- MDO（$K_1=5, K_2=10$）
- MC-BRO

**参数设置**：
- GLOS 的 $\alpha = 2$（在 Sonar 数据集上的初步实验确定此值较优，但不一定对所有数据集是最优的，推荐范围 $\alpha \in [1, \frac{\max(sd)}{\min(sd)}]$）
- 基分类器：C4.5 决策树（默认参数，对不平衡数据不敏感）
- 交叉验证：五折交叉验证 × 10次独立运行
- 合成数量：GLOS 和 MC-BRO 自确定；其他方法生成 $N_{max} - N_i$ 个样本
- 分解策略：OAA、OAO、OAHO、AandO 四种，取最佳结果

### 4.2 评价指标

考虑到准确率在不平衡场景下具有欺骗性，GLOS 使用了一系列专门的不平衡评价指标：

**（1）各类别的精确率和召回率**：

$$P_i = \frac{TP_i}{TP_i + FP_i} \tag{11}$$

$$R_i = \frac{TP_i}{TP_i + FN_i} \tag{12}$$

**（2）整体召回率指标 G-mean**：

$$G = \sqrt[c]{\prod_{i=1}^{c} R_i} \tag{13}$$

**（3）整体精确率指标 $P_{ave}$**：

$$P_{ave} = \frac{1}{c} \sum_{i=1}^{c} P_i \tag{14}$$

**（4）所有少数类的性能指标**：

$$P_{min}^{ave} = \frac{1}{c_{min}} \sum_{i=1}^{c_{min}} P_i \tag{15}$$

$$G_{min}^{ave} = \sqrt[c_{min}]{\prod_{i=1}^{c_{min}} R_i} \tag{16}$$

**（5）类别平衡准确率 CBA**（用于替代传统准确率，对类别不平衡不敏感）：

$$CBA = \frac{\sum_{i=1}^{c} \sum_{j=1}^{c} mat_{i,j}}{\max(\sum_{i=1}^{c} mat_{i,j}, \sum_{i=1}^{c} mat_{j,i})} \cdot \frac{1}{c} \tag{17}$$

其中 $mat_{i,j}$ 表示真实类别为 $i$、被预测为类别 $j$ 的样本数。

### 4.3 关键实验结果

#### 4.3.1 参数 $\alpha$ 的影响

在 Sonar 数据集上分析 $\alpha$ 的影响：
- 随着 $\alpha$ 增大，Safe 样本减少，Small Disjunct 和 Borderline 样本急剧增加（尤其是 Borderline）；
- 三个分类指标在 $\alpha = 2$ 时达到最优；
- 推荐 $\alpha \in [1, \frac{\max(sd)}{\min(sd)}]$，具体值可根据数据特征调整。

#### 4.3.2 GLOS vs 各方法

**从综合性能看**：
- GLOS 在所有方法中表现最优，尤其是在 $P_{ave}$、$G$、$G_{min}^{ave}$ 和 $G_{min}$ 上优势明显；
- MDO 虽然在少数类识别上较好（$G_{min}$ 较高），但严重损害多数类性能（$G = 0$），说明过度生成了；
- SMOTE 是除 GLOS 外表现最均衡的方法，可在数据复杂度较低时作为备选方案。

**从 Top-2 结果看**：
- 七项指标中，GLOS 在五项上排名第一；
- 在 $P_{min}^{ave}$ 和 $P_{min}$ 上 GLOS 排第二，但与第一的差距可忽略不计。

#### 4.3.3 在不同不平衡场景下的鲁棒性

通过修改 Segment 和 Texture 数据集构建三种场景：
1. **Normal**（正常）：多多数类 + 多少数类
2. **Multi-Minority**（多少数类）：多个少数类 + 一个多数类
3. **Multi-Majority**（多多数类）：多个多数类 + 一个少数类

结果：GLOS 在三种场景下均表现最优，尤其在 Multi-Minority 和 Multi-Majority 场景中优势更为显著；GLOS 在 $G$、$G_{min}^{ave}$、$G_{min}$ 和 CBA 上均获得最佳结果。

#### 4.3.4 Wilcoxon 统计检验

以显著性水平 $\alpha = 0.95$ 和 $\alpha = 0.90$ 进行 Wilcoxon 符号秩检验：

**召回率方面**：
| 指标 | GLOS 显著优于 |
|------|--------------|
| $G_{min}$ | Base, SMOTE, BorSMOTE, ADASYN ($\alpha=0.95$)；MC-BRO ($\alpha=0.90$) |
| $G_{min}^{ave}$ | 除 ADASYN 外的所有方法 ($\alpha=0.95$) |
| $G$ | 所有方法 ($\alpha=0.95$ 或 $\alpha=0.90$) |

**精确率方面**：
| 指标 | GLOS 显著优于 |
|------|--------------|
| $P_{min}$ | MDO ($\alpha=0.95$)；MC-BRO ($\alpha=0.90$) |
| $P_{min}^{ave}$ | MDO ($\alpha=0.95$)；Base ($\alpha=0.90$) |
| $P_{ave}$ | Base, ADASYN, MDO, MC-BRO ($\alpha=0.95$)；BorSMOTE ($\alpha=0.90$) |

GLOS 在综合指标（$G$、$G_{min}^{ave}$、$G_{min}$、CBA）上对几乎所有对比方法都有统计显著的改进。

## 五、总结与展望

### 5.1 GLOS 的优势

1. **因材施教**：不像现有方法对所有样本一视同仁，GLOS 根据样本的内在特征选择不同的合成策略；
2. **全局+局部兼顾**：DID 从全局视角评估不平衡程度，三个合成策略从局部视角精确生成样本；
3. **自适应合成数量**：通过 $\theta_j - \lambda(x_i)$ 自动确定每个样本需要合成的数量，避免过度生成；
4. **保持多类结构**：AMBO 考虑了多类之间的复杂关系，避免损害其他少数类的性能。

### 5.2 局限与展望

1. GLOS 依赖两个关键参数（$\alpha$ 用于 DID 计算，分类阈值 0.5/2 用于实例划分），论文给出了推荐值但未能完全消除参数依赖；
2. 未来研究方向：**根据数据复杂度自适应地确定参数**，减少人工调参的工作量；
3. 论文也启发了我们：深入了解不同数据特征，并针对这些特征对分类的影响进行专门处理，是更好地解决不平衡问题的重要方向。
