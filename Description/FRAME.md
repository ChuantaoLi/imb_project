## 一、研究背景与动机

### 1.1 类别不平衡问题

在机器学习中，大多数模型都基于一个隐含假设：训练数据中各类别之间的样本数量大致均衡。然而，现实世界中的数据往往不满足这一假设。例如，在癌症检测任务中，健康人群的样本数量远多于"患病"人群的样本数量；在故障诊断中，正常运行的样本远多于故障样本；在信用卡欺诈检测中，正常交易的样本远多于欺诈交易的样本。

当面对类别不平衡的数据集时，传统的机器学习模型通常会产生所谓的"**多数类偏差**"（Majority Bias）。多数类偏差指的是模型倾向于优先考虑或偏向预测多数类，而忽视少数类。这是因为模型的学习目标是**最小化整体误差**，而正确预测多数类即可轻松降低整体误差，代价则是牺牲少数类的预测精度。这种结果是次优的，因为在实际应用中，少数类（如疾病、故障、欺诈）往往是我们真正关注的类别。

为了量化类别不平衡程度，论文使用**不平衡率**（Imbalance Ratio, IR）来度量：

$$IR = \frac{|N|}{|P|}$$

其中 $|N|$ 和 $|P|$ 分别表示多数类（负类）和少数类（正类）的样本数量，且 $|N| \gg |P|$。

### 1.2 现有方法的局限性

传统的类别不平衡学习方法可以分为三大类：

**（1）数据层面方法**：通过增加少数类样本（过采样，如SMOTE）或减少多数类样本（欠采样）来平衡数据分布。然而，这些方法存在以下局限：
- 对大规模数据集计算开销大
- 依赖距离度量，对缺失值敏感
- 在有噪声的数据上容易引入额外噪声
- 需要显式的标签信息，不适用于半监督等缺少标签的场景

**（2）算法层面方法**：通过修改学习算法（如代价敏感学习）来增加少数类的惩罚权重。同样存在问题：
- 需要设计任务特定的代价矩阵
- 对批训练的神经网络不易实施
- 需要大量超参数调优

**（3）集成方法**：结合多个模型来提高鲁棒性。但也有局限：
- 计算开销大
- 在高维数据或复杂噪声分布下敏感性下降

### 1.3 深度潜在特征方法及研究空白

近年来，研究者将深度学习表示学习与类别不平衡技术相结合，在**潜在空间**（latent space）中进行平衡操作。潜在空间是神经网络从原始数据中提取的低维表示，具有更好的紧凑性和可分性。

然而，现有基于深度潜在特征的方法面临两大挑战：

1. **潜在空间可能受到数据噪声、离群点和缺失值的影响**，导致同类样本在潜在空间中分散，难以形成紧凑的聚类结构。
2. **现有研究忽略了同一类中不同样本的重要性差异**——靠近潜在空间中心的样本应具有更高的重要性，而边缘样本可能是噪声或异常点。

正是为了应对上述挑战，本文提出了 **FRAME**（Feature Rectification for clAss iMbalance lEarning）模型。

## 二、核心贡献与方法

### 2.1 核心贡献

1. **提出理论上可证明的潜在空间特征矫正模块**：
   - 与数据层面方法不同，FRAME在潜在空间（而非原始数据空间）中操作
   - 与算法层面方法不同，FRAME基于距离度量进行分类，无需修改学习算法
   - 能够有效中和原始数据中的噪声和缺失值，而不改变数据结构

2. **高度可扩展，无缝集成到多种学习范式**：
   - 全监督学习（Fully-Supervised Learning）
   - 半监督学习（Semi-Supervised Learning）
   - 联邦学习（Federated Learning）
   - 在20个公开二分类不平衡数据集（IR范围从2.46到578.88）以及两个大规模多分类数据集上验证了有效性

### 2.2 方法总览

FRAME的核心思想可以用一个类比来理解：**与其在嘈杂混乱的原始数据空间中直接做平衡，不如先将数据映射到一个"特征精炼厂"（潜在空间），在那里为每个类别找到几个"代表点"（质心），然后根据样本到这些代表点的距离来进行分类。**

FRAME模块由两个核心组件串联而成：

1. **质心学习模块**（Centroid Learning）：通过自注意力特征交互（Self-Attentive Feature Interactions），在潜在空间中为每个类别自动学习多个代表性质心，实现特征平衡
2. **基于距离的分类器**（Distance-Based Classifier）：根据样本到各质心的距离计算该样本属于每个类别的概率

下图直观对比了FRAME与现有方法的不同：

| 方法类型 | 操作空间 | 操作方式 |
|---------|---------|---------|
| 数据层面方法 | 原始数据空间 | 直接过采样/欠采样原始数据 |
| 算法层面方法 | 模型训练过程 | 通过特殊损失函数控制训练 |
| **FRAME** | **潜在特征空间** | **通过质心学习平衡特征，基于距离分类** |

## 三、方法具体实现

### 3.1 问题定义

考虑二分类不平衡问题。训练集中有两类：
- 多数类（负类）：$N = \{(x_N, y_N) \mid y = 0\}$
- 少数类（正类）：$P = \{(x_P, y_P) \mid y = 1\}$

不平衡率 $IR = \frac{|N|}{|P|}$，且 $|N| \gg |P|$。

目标是在潜在空间中通过特征矫正来提高两个类别的学习性能。

### 3.2 FRAME模块详解

#### 3.2.1 总览：从原始空间到潜在空间再到分类

FRAME的工作流程分为三个步骤：

**步骤一：参数化映射**。使用一个参数化映射 $\Phi: \mathcal{X} \rightarrow \mathcal{F}$，将原始数据从原始空间 $\mathcal{X}$ 转换到潜在特征空间 $\mathcal{F}$。该映射可以通过神经网络或核方法等多种模型实例化：

$$h_i = \Phi_\omega(x_i), \quad \forall x_i \in N \cup P$$

其中 $\omega$ 表示嵌入网络的参数，$h_i \in \mathbb{R}^{N \times F}$ 是转换后的潜在特征，$F$ 是潜在空间的维度。

**步骤二：质心学习**。在潜在空间中为每个类别计算多个质心，这些质心是潜在特征的加权平均，能够减少特征噪声。

**步骤三：基于距离的分类**。使用基于距离的分类器，根据样本到各质心的距离计算类别概率。

使用质心来表示类别具有多种优势：
- **计算效率高**：质心计算复杂度低
- **抗噪声抗离群点**：加权平均自然平滑了噪声
- **对缺失值鲁棒**：潜在空间的特征转换减轻了缺失值的影响
- **适合小样本训练**：特别适合类别不平衡学习

#### 3.2.2 质心学习：自注意力特征交互

这是FRAME最核心的技术组件。其目标是从潜在特征中为每个类别提取多个代表性质心。

**核心创新**：与传统的依赖预定义或固定准则（如k-means）的质心方法不同，FRAME使用**自注意力机制**来发现特征之间的高阶依赖关系，使其能够自适应地从复杂、不平衡的数据分布中学习。

**算法流程（两阶段过程）**：

---

**阶段一：原始数据到潜在特征的转换**

1. **数据输入与转换**：将原始数据集 $X = [x_1, \ldots, x_N] \in \mathbb{R}^{N \times D}$（$N$ 个样本，每个 $D$ 维）转换为潜在特征集 $H = [h_1, \ldots, h_N] \in \mathbb{R}^{N \times F}$，通过参数化映射 $\Phi: \mathcal{X} \rightarrow \mathcal{F}$。

2. **类别特定的潜在特征表示**：对于每个类别 $k$，定义 $H_k = [h_1, \ldots, h_{N_k}] \in \mathbb{R}^{N_k \times F}$，表示属于该类别的潜在特征。

---

**阶段二：自注意力特征交互生成质心**

1. **初始特征嵌入**：每个类别的潜在特征 $H_k$ 首先被嵌入到矩阵 $Z_k$ 中，使用由 $W_z$ 参数化的MLP（多层感知机）。

2. **投影到查询、键和值矩阵**：随后，$Z_k$ 被投影为查询（$q$）、键（$k$）和值（$v$）矩阵，使用两个独立的MLP：$\phi_{\text{MLP}_q}$ 和 $\phi_{\text{MLP}_{kv}}$，各自具有独立的参数集。

3. **分块与注意力分数计算**：这些矩阵被划分为更小的块（chunk）。对于每个块，模块计算 $q_c$ 和 $k_c$ 之间的点积，得到注意力分数 $\alpha_c$，然后对其进行归一化以获得注意力权重 $w_c$。这些权重表示块内每个元素的相关性/重要性。

4. **加权特征合成与残差连接**：模块将 $w_c$ 与 $v_c$ 相乘，合成加权特征，捕获高阶成对交互。同时引入一个残差连接（Residual Connection），将这些特征与原始潜在特征 $Z_k$ 相连，以保留信息并缓解梯度消失问题。

5. **质心计算与转换**：最后，应用另一个MLP（$\phi_{\text{MLP}_c}$）将增强后的特征转换，将自注意力矩阵和潜在特征转换为质心矩阵 $c_k$，表示每个类别的多个代表性点。

---

**数学公式**：

整个过程的数学表达为：

$$\alpha_k = \text{SA}(H_k)$$

$$c_k = \phi_{\text{MLP}_c}(\alpha_k H_k)$$

其中 $\text{SA}$ 表示自注意力交互模块，$c_k \in \mathbb{R}^{n_c \times 1 \times F}$ 是得到的质心，$n_c$ 是每个类别的质心数量。

**分块策略（Chunking Strategy）**：为了提高自注意力机制的内存效率，FRAME采用了分块策略。该技术将键和值划分为可管理的块，顺序计算点积并更新加权值和指数的运行总和，最终产生归一化的注意力结果。

**解释（中文伪代码）**：

```
算法：自注意力质心学习

输入：类别k的潜在特征 H_k ∈ R^{N_k × F}
输出：类别k的质心 c_k ∈ R^{n_c × F}

1. 嵌入层：
   Z_k = MLP_z(H_k)                    // 将潜在特征嵌入到矩阵Z_k

2. 自注意力计算：
   q = MLP_q(Z_k)                      // 投影为查询矩阵
   kv = MLP_kv(Z_k)                    // 投影为键值矩阵
   k, v = split(kv)                    // 分离键和值

3. 分块计算注意力（循环处理每个块）：
   FOR 每个块 c：
       q_c, k_c, v_c = chunk(q, k, v, chunk_size)
       α_c = dot(q_c, k_c^T)           // 计算注意力分数（点积）
       w_c = softmax(α_c / √d_k)       // 归一化为注意力权重
       output_c = w_c · v_c            // 加权求和

4. 残差连接：
   Z'_k = Z_k + concat(output_c)       // 残差连接保留原始信息

5. 质心生成：
   c_k = MLP_c(Z'_k)                   // 生成n_c个质心

返回 c_k
```

**为什么使用多个质心？** 使用多个质心的原因在于：单一质心假设每个类别的数据围绕一个中心呈球形分布，但在复杂的真实数据中，一个类别可能在潜在空间中形成多个子簇。多个质心可以更好地捕捉类别内的多样性和非球形分布结构。

#### 3.2.3 基于距离的分类器

传统的分类器通常使用一个全连接层产生每个类别的logit向量。假设特征表示为 $h(x) \in \mathbb{R}^{N \times F}$，分类器参数为 $W \in \mathbb{R}^{F \times k}$，则有：

$$l = W^T h(x) = [w_1^T h(x); w_2^T h(x); \cdots; w_k^T h(x)]$$

然后对每个类别应用softmax损失函数：

$$L = \sum_i \frac{N_i}{N} \mathcal{L}(D_i)$$

其中 $N_i$ 是第 $i$ 类的训练样本数，$N$ 是总样本数，$D_i$ 是属于第 $i$ 类的样本。

**问题**：如果存在类别不平衡且 $N_1 \leq N_2 \leq \cdots \leq N_k$，则会推导出 $L_1 \leq L_2 \leq \cdots \leq L_k$，意味着决策边界会向少数类偏移。

**FRAME的解决方案**：使用基于距离的分类器。对于给定的样本潜在特征 $H_s \in \mathbb{R}^{F \times L}$，其属于类别 $i$ 的概率计算如下：

$$p(y = i \mid H_s) = \frac{\exp(-\|H_s - c_i\|^2)}{\sum_k \exp(-\|H_s - c_i\|^2)}$$

其中 $\|\cdot\|$ 是 $H_s$ 和 $c_i$ 之间的距离函数（如欧氏距离）。

**直观理解**：样本离哪个类别的质心越近，就越可能属于该类别。这种方法天然地避免了对类别大小的依赖——因为概率只取决于距离，而与每类有多少个样本无关。这比传统的softmax分类器更加平衡。

#### 3.2.4 理论证明：对类别不平衡的鲁棒性

本节给出理论分析，证明FRAME的损失函数对类别不平衡具有内在鲁棒性。

**设定**：考虑一个数据集 $D$ 分为正类（少数类）样本 $P$ 和负类（多数类）样本 $N$。$N_p = |P|$，$N_n = |N|$，且 $N_n \gg N_p$。令 $h_i$ 表示数据点 $x_i$ 的潜在特征嵌入，$c_0$ 和 $c_1$ 分别表示负类和正类在潜在空间中的质心。

**正类样本的损失**定义为：

$$L(x_i) = \log\left(1 + \exp(-d(h_i, c_0) + d(h_i, c_1))\right)$$

其中 $d(u, v) = \|u - v\|^2$ 表示平方欧氏距离。

**定理**：整体损失函数 $L$ 主要由正类的类内聚类程度和正负类质心之间的类间距离决定，展示出对类别不平衡的鲁棒性。

**证明过程**：

**步骤1：正类累计损失**。所有正类样本的累计损失为：

$$L(P) = \sum_{i=1}^{N_p} L(x_i)$$

**步骤2：Jensen不等式下界**。利用 $\log(1 + \exp(t))$ 的凸性，由Jensen不等式：

$$L(P) \geq N_p \log\left(1 + \exp\left(\frac{1}{N_p} \sum_{i=1}^{N_p} \left[-d(h_i, c_0) + d(h_i, c_1)\right]\right)\right)$$

**步骤3：基于距离的简化**。展开平方欧氏距离：

$$L(P) \geq N_p \log\left(1 + \exp\left(-\frac{1}{N_p} \sum_{i=1}^{N_p} \|h_i - c_0\|^2 + \frac{1}{N_p} \sum_{i=1}^{N_p} \|h_i - c_1\|^2\right)\right)$$

令 $\bar{h} = \frac{1}{N_p} \sum_{i=1}^{N_p} h_i$ 表示正类样本的均值向量，进一步重写为：

$$L(P) = N_p \log\left(1 + \exp\left(-\|c_0\|^2 + \|c_1\|^2 + 2(\bar{h} - c_0)^T(c_0 - c_1)\right)\right)$$

**步骤4：最优性条件**。当且仅当对所有 $i \neq j$ 有 $-d(h_i, c_0) + d(h_i, c_1) = -d(h_j, c_0) + d(h_j, c_1)$ 时，不等式取等。等式在 $c_1 = \bar{h}$ 时达到最小值，表明正类样本紧密聚集在其均值周围时分离效果最优。

**步骤5：负类损失**。类似推导，负类样本的损失下界为：

$$L(N) \geq N_n \log(1 + \exp(-d(c_1, c_0)))$$

**步骤6：整体损失行为**。结合正类和负类的损失下界：

$$L = L(P) + L(N) \geq (N_p + N_n) \log(1 + \exp(-d(c_1, c_0)))$$

**讨论**：最终不等式表明，整体损失 $L$ 主要由以下因素决定：
- **类间距离** $d(c_1, c_0)$：正负类质心之间的距离
- **类内聚类程度**：$c_1$ 趋近于 $\bar{h}$ 的影响

最关键的是，**对类别大小 $N_p$ 和 $N_n$ 的依赖不显著**，这证明了FRAME模型对类别不平衡具有内在的鲁棒性。这一性质对于类别分布偏斜场景下的有效学习至关重要。

**通俗理解**：如果少数类的样本能够很好地聚集在一起（同类样本特征相似），且正负类的质心距离足够远（不同类特征差异大），那么无论多数类有多少个样本，分类器都能很好地工作。模型不需要依赖类别样本数量来做出判断，而是依赖特征的内在几何结构。

#### 3.2.5 理论证明：对缺失值的鲁棒性

为了分析FRAME对缺失值的鲁棒性，考虑**完全随机缺失**（Missing Completely at Random, MCAR）机制，即特征缺失的概率与观测数据和未观测数据均独立。

**符号定义**：
- $x_i \in \mathcal{X}$：带有缺失值的样本，缺失索引集为 $M_i$
- $x_i^o$：观测到的特征
- $x_i^m$：缺失的特征
- 在MCAR下：$P(M_i \mid x_i) = P(M_i)$

定义插补函数 $\Psi: \mathcal{X} \rightarrow \mathcal{X}'$，通过填充估计值来处理缺失值。例如，使用均值插补：

$$\Psi(x_i) = (x_i^o, \hat{x}_i^m), \quad \hat{x}_i^m = \mathbb{E}[x^m]$$

其中 $\mathbb{E}[x^m]$ 是从完整数据中计算的对应特征的均值。

**（1）对质心计算的影响**

令 $c_k$ 为用完整数据计算的类别 $k$ 的质心，$\tilde{c}_k$ 为用通过 $\Psi$ 处理的缺失数据计算的质心：

$$\|c_k - \tilde{c}_k\| = \left\| \frac{1}{N_k} \sum_{i \in \text{Class }k} \Phi(x_i) - \frac{1}{N_k} \sum_{i \in \text{Class }k} \Phi(\Psi(x_i)) \right\|$$

$$\leq \frac{1}{N_k} \sum_{i \in \text{Class }k} \|\Phi(x_i) - \Phi(\Psi(x_i))\|$$

**假设1**（Lipschitz连续性）：变换 $\Phi$ 是Lipschitz连续的，常数为 $L$：

$$\|\Phi(x) - \Phi(x')\| \leq L \|x - x'\|, \quad \forall x, x' \in \mathcal{X}$$

利用此假设：

$$\|c_k - \tilde{c}_k\| \leq \frac{L}{N_k} \sum_{i \in \text{Class }k} \|x_i - \Psi(x_i)\|$$

由于 $\Psi$ 仅修改缺失特征：

$$\|x_i - \Psi(x_i)\| = \|x_i^m - \hat{x}_i^m\|$$

**假设2**（有界插补误差）：

$$\|x_i^m - \hat{x}_i^m\| \leq B, \quad \forall i$$

因此：

$$\|c_k - \tilde{c}_k\| \leq \frac{L}{N_k} \sum_{i \in \text{Class }k} B = LB$$

这表明，使用完整数据和缺失数据计算的质心之间的差异由一个常数界定，说明缺失值对质心计算的影响是有限的。

**（2）对基于距离的分类器和性能的影响**

令 $p(y = k \mid x_i, c)$ 为使用完整数据和质心 $c$ 时样本 $x_i$ 属于类别 $k$ 的概率，$\tilde{p}(y = k \mid \Psi(x_i), \tilde{c})$ 为使用插补数据 $\Psi(x_i)$ 和质心 $\tilde{c}$ 时的概率。

基于距离的概率定义：

$$p(y = k \mid x_i, c) = \frac{\exp(-d(\Phi(x_i), c_k))}{\sum_j \exp(-d(\Phi(x_i), c_j))}$$

$$\tilde{p}(y = k \mid \Psi(x_i), \tilde{c}) = \frac{\exp(-d(\Phi(\Psi(x_i)), \tilde{c}_k))}{\sum_j \exp(-d(\Phi(\Psi(x_i)), \tilde{c}_j))}$$

假设距离 $d(\Phi(x_i), c_j)$ 和 $d(\Phi(\Psi(x_i)), \tilde{c}_j)$ 在有界范围 $[d_{\min}, d_{\max}]$ 内，利用指数函数的性质和三角不等式，以及 $\Phi$ 的Lipschitz连续性，可以推导概率差的上界：

$$|p(y = k \mid x_i, c) - \tilde{p}(y = k \mid \Psi(x_i), \tilde{c})| \leq C \cdot |d(\Phi(x_i), c_k) - d(\Phi(\Psi(x_i)), \tilde{c}_k)|$$

$$\leq C(L\|x_i - \Psi(x_i)\| + \|c_k - \tilde{c}_k\|) \leq 2CLB$$

其中 $C = \frac{\exp(-d_{\min})}{(\exp(-d_{\max}))^2}$ 是通过对指定范围内的指数函数应用中值定理导出的常数。

**与性能的联系**：考虑分类器的准确率。令 $y_i$ 为样本 $x_i$ 的真实标签。缺失值对准确率的影响可以界定为：

$$|\text{Accuracy} - \widetilde{\text{Accuracy}}| \leq \frac{1}{N} \sum_{i=1}^{N} |p(y = y_i \mid x_i, c) - \tilde{p}(y = y_i \mid \Psi(x_i), \tilde{c})| \leq 2CLB$$

这表明**缺失值对准确率的影响是有界的**，且取决于：
- $\Phi$ 的Lipschitz常数 $L$
- 插补误差界 $B$
- 常数 $C$

对其他指标（如F1分数或AUC）也可以导出类似的界。

### 3.3 FRAME在三种学习范式中的应用

#### 3.3.1 全监督学习（Fully-Supervised Learning）

在全监督学习设置下，首先使用嵌入网络 $\Phi_\omega$ 将原始数据投影到潜在空间，然后在潜在空间中平衡和分类不平衡特征。

**特征变换**：

$$h_i = \Phi_\omega(x_i), \quad \forall x_i \in N \cup P$$

其中 $\omega$ 表示嵌入网络的参数。

**联合框架**：在全监督的类别不平衡学习中，质心学习和分类目标被制定为一个联合框架。分类损失函数使用基于真实类别标签 $y \in \{1, 2, \ldots, k\}$ 的负对数概率：

$$L = -\sum_{(x_k, y_k)} \log(p(y = y_k \mid x_k, c))$$

其中 $(x_k, y_k)$ 表示一个样本，$c$ 是该样本对应类别的质心。

整个网络可以通过梯度下降算法以**端到端**（end-to-end）的方式，通过最小化训练样本上的分类损失来训练。神经网络的**反向传播算法**会自动计算损失函数的梯度并更新模型参数。

**训练流程（伪代码）**：

```
算法：全监督FRAME训练

输入：训练数据 (X_train, y_train), 质心数 n_c, chunk大小, epoch数
输出：训练好的模型

1. 初始化嵌入网络 Φ_ω, 质心学习模块 SA, 分类器参数

2. FOR epoch = 1 TO 总epoch数：
     a. 前向传播：
        H = Φ_ω(X_train)                  // 步骤1: 原始数据→潜在特征
        FOR 每个类别 k：
            c_k = SA(H_k)                 // 步骤2: 自注意力学习质心
        FOR 每个样本 i：
            p(y_i|h_i) = softmax(-||h_i - c||²)  // 步骤3: 距离分类

     b. 计算损失：
        L = -Σ log p(y_i | h_i, c)

     c. 反向传播：
        计算梯度 ∇L
        更新所有参数: ω = ω - η·∇L

3. 返回训练好的模型
```

#### 3.3.2 半监督学习（Semi-Supervised Learning）

半监督学习支持部分标注数据，假设标注数据和未标注数据中的类别是平衡的。然而，这一假设在现实中通常不成立。传统的类别不平衡方法（数据层面和算法层面方法）不适用于半监督学习。

**核心挑战**：使用未标注数据的最直观方法是为其生成伪标签，但当标注数据和未标注数据的类别不平衡率不同时，这会变得非常困难。

**FRAME的解决方案**：

给定未标注数据 $X_u \in \mathbb{R}^{N_u \times d}$（$N_u$ 是未标注数据的样本数），通过嵌入网络 $\Phi_\omega$ 获取潜在特征：

$$H_u = \Phi_\omega(X_u)$$

然后，通过自注意力机制学习未标注数据的质心：

$$c_u = \alpha_u H_u, \quad \alpha_u = \text{SA}(H_u)$$

其中 $c_u \in \mathbb{R}^{n_c \times 1 \times F}$ 是未标注数据的原型（prototype），$\alpha_u$ 是自注意力特征交互模块学习的权重。

**最后，用未标注数据的质心更新标注数据的质心**：

$$c^i_{\text{new}} = \frac{\alpha c_l + \beta c_u}{\alpha + \beta}$$

其中：
- $c_l$ 和 $c_u$ 分别是标注数据和未标注数据的质心
- $\alpha$ 和 $\beta$ 是两个**可学习参数**，控制标注和未标注数据质心的融合比例

**关键设计理念**：通过可学习的权重参数 $\alpha$ 和 $\beta$，模型可以自适应地决定在多大程度上信任标注数据的质心和未标注数据的质心。如果未标注数据质量高，模型可以增大 $\beta$ 赋予其更大权重；反之则可以更多地依赖标注数据。

**中文伪代码**：

```
算法：半监督FRAME训练

输入：标注数据 (X_l, y_l), 未标注数据 X_u
输出：训练好的模型

1. 初始化嵌入网络 Φ_ω, 自注意力模块 SA, 可学习参数 α, β

2. FOR epoch = 1 TO 总epoch数：
     // 处理标注数据
     H_l = Φ_ω(X_l)                      // 标注数据的潜在特征
     c_l = SA(H_l) · H_l                  // 标注数据的质心

     // 处理未标注数据
     H_u = Φ_ω(X_u)                      // 未标注数据的潜在特征
     c_u = SA(H_u) · H_u                  // 未标注数据的质心

     // 融合质心
     c_new = (α·c_l + β·c_u) / (α + β)  // 加权融合

     // 分类（仅对标注数据计算损失）
     p(y_i|h_i) = softmax(-||h_i^l - c_new||²)

     // 损失 + 反向传播
     L = -Σ log p(y_i | h_i^l, c_new)
     更新 Φ_ω, SA, α, β
```

#### 3.3.3 联邦学习（Federated Learning）

联邦学习（FL）是一种分布式学习范式，旨在保护数据隐私。在FL设置下：
- 数据层面方法不适用，因为它们需要数据分布等额外信息
- 算法层面方法相对更适用，但仍面临大量超参数调优的挑战

**FRAME-FL的设计**：将FRAME的全监督学习扩展以支持联邦学习，称为 **FRAME-FL**。

**架构**：FRAME-FL由多个**本地模型**（local models）和一个**全局模型**（global model）组成。
- **本地模型**：与全监督学习的FRAME模型相同，每个客户端使用自己的私有数据训练
- **全局模型**：通过聚合所有本地模型生成

**聚合方法**（加权平均法）：

$$\sum_{i=1}^{K} \frac{S_i}{\sum_{i=1}^{K} S_i} W_{c+1}^i \rightarrow W_{c+1}$$

其中：
- $W_{c+1}^i$：第 $i$ 个客户端在第 $c+1$ 个通信轮次的模型参数
- $W_{c+1}$：第 $c+1$ 轮通信后的全局模型参数
- $S_i$：第 $i$ 个客户端的训练样本数
- $K$：参与学习的客户端总数

样本数量越多的客户端，在全局聚合中的权重也越高。

**隐私保护机制**：
1. 每个客户端使用其加密的私有数据集训练本地神经网络
2. 每个本地模型在本地计算梯度下降更新，**仅向中央服务器共享模型参数**（不传输原始数据）
3. 客户端向服务器报告训练样本数量，仅用于计算聚合权重
4. **中央服务器不保留任何客户端的本地模型或训练数据**——在生成全局模型后立即丢弃

这种设计使得FRAME-FL既不需要数据分布信息，也不需要进行复杂的超参数调优，就能在联邦学习场景中处理类别不平衡问题。

## 四、实验结果与分析

### 4.1 数据集

实验使用10个基准不平衡学习数据集，来源于UCI和KEEL仓库。数据集的选取确保了普遍性和多样性，涵盖不同样本数量和变量数量，根据不平衡率（IR）分为四组：

| 不平衡程度 | IR范围 |
|-----------|--------|
| 轻微不平衡 | IR ≤ 10 |
| 中等不平衡 | 10 ≤ IR ≤ 20 |
| 高度不平衡 | 20 ≤ IR ≤ 100 |
| 严重不平衡 | IR ≥ 100 |

此外，还在长尾CIFAR-100上验证了多分类不平衡的性能。

### 4.2 评估指标

由于数据不平衡，传统的"准确率"不再适用。论文使用以下指标：

- **MCC（Matthews相关系数）**：

$$MCC = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP + FP)(TP + FN)(TN + FP)(TN + FN)}}$$

- **G-Mean（几何均值）**：

$$GMean = \sqrt{\left(\frac{TP}{TP + FN}\right) \times \left(\frac{TN}{TN + FP}\right)}$$

- **AUC（曲线下面积）**

其中 TP、FP、FN、TN 分别表示真阳性、假阳性、假阴性和真阴性。MCC是专门为评估不平衡数据集定制的二分类指标。

### 4.3 实验设置

- **框架**：PyTorch (v.1.8.0)
- **硬件**：32GB Tesla V100 GPU
- **嵌入网络**：单层MLP，128个滤波器
- **优化器**：Adam，学习率 $10^{-4}$
- **训练轮数**：全监督/半监督：1000个epoch；联邦学习：每客户端100个epoch，10个通信轮次
- **验证方式**：5次重复实验，使用交叉验证

### 4.4 全监督学习实验结果

#### 4.4.1 与SOTA方法对比

对比方法分为四组：
- **经典方法**：GDO（基于高斯分布的过采样）、SPE（自步集成欠采样）、DUBE（类间与类内不平衡集成）
- **梯度提升方法**：GDBT、XGBoost（结合focal loss）、LightGBM
- **深度损失函数**：BalanceSoftmax、Class-balance（考虑有效样本数的focal loss变体）、LDAM（标签分布感知margin损失）
- **简单分类器**：SVM、RF（随机森林）、DT（决策树）

**结论**：FRAME在所有三个指标上均优于对比方法。性能提升归因于三个核心因素：

1. **潜在特征空间操作**：相比直接在原始数据上操作的方法，在潜在空间中操作更有效地实现了数据平衡，减少了对噪声和离群点的敏感性，有助于准确界定决策边界。

2. **基于质心的距离分类器**：利用潜在空间中学习的质心进行距离分类，天然保证了平衡性和鲁棒性，无需额外的代价敏感或重加权机制。

3. **高效学习**：相比需要大量超参数调优的基于损失的方法，FRAME简化了潜在空间中的特征平衡过程，实现了端到端分类，具有更高的效率和更低的复杂度。

#### 4.4.2 缺失值鲁棒性实验

通过MCAR模型随机选择训练和测试集中的样本并将它们替换为零，模拟缺失数据。缺失率设为0%、25%、50%和75%。

**结论**：
- 随着缺失比例增加，所有方法的性能都下降
- **FRAME表现出了更强的鲁棒性**，特别是在高缺失率下
- FRAME的鲁棒性归因于：首先使用嵌入网络捕获原始数据的潜在特征，然后计算特征质心进行分类——这一过程最大化了缺失值对性能的负面影响

#### 4.4.3 样本噪声鲁棒性实验

注入高斯噪声（均值=0，方差分别为0.1、0.3、0.5），与DUBE对比。

**结论**：
- 两种方法在噪声增加时性能均下降
- **FRAME的下降幅度更小**
- 在中等噪声水平（方差=0.1）下，某些数据集上性能甚至略有提升（可能是噪声起到了轻微正则化作用）

#### 4.4.4 消融实验与敏感性分析

**消融实验**：移除特征矫正模块（质心学习），替换为线性分类器，形成变体"FRAME w/o C"（无质心学习模块的FRAME）。

**结论**：移除特征矫正模块后性能显著下降，证明了该模块在增强不平衡学习能力中的关键作用。

**敏感性分析**：改变质心数（number of centers）和块数（number of chunks）。

**结论**：
- 对大多数数据集，最优配置为：chunk数=256，质心数=2
- 使用多个质心的原因是处理潜在空间的分离问题
- 但如果潜在特征已经良好聚类，增加更多质心可能会降低性能（过度分割已聚类的特征）

### 4.5 半监督学习实验结果

对比五个领先的当代模型：
- **Π模型**：结合交叉熵和MSE损失来增强少量样本的深度学习
- **PL（伪标签）**：选择最高置信度的未标注样本
- **MT（Mean Teacher）**：通过平均模型权重减少标签依赖
- **VAT（虚拟对抗训练）**：使用虚拟对抗损失的无标签方法
- **ICT（插值一致性训练）**：通过插值引导决策边界

实验将数据按80/20分为训练/测试集，仅10%的训练数据有标签。

**结论**：FRAME在所有数据集上均取得最高性能。原因在于：
- 其他方法主要关注通过特殊损失函数管理类别不平衡和生成高质量伪标签
- FRAME通过**聚合并使用标注和未标注数据的质心**，充分利用了未标注样本中的信息
- 可以通过可学习参数 $\alpha$ 和 $\beta$ 灵活调整标注和未标注数据的权重

### 4.6 联邦学习实验结果

对比五个SOTA模型，这些模型都使用嵌入网络进行特征学习，但使用不同的损失函数处理类别不平衡：
- **FL_LDAM**：LDAM损失函数
- **FL_CB**：CB（Class-Balance）损失函数
- **FL_FOCAL**：Focal损失函数
- **FL_BaSoftmax**：BalanceSoftmax损失函数
- **FL_Ratio**：基于比率的损失函数

使用FedAvg作为聚合机制，3个客户端。

**结论**：FRAME在10个数据集中有8个表现最优。原因在于：
- FRAME使用质心直接对抗类别不平衡，从根本上解决问题
- 基线方法的损失函数可能缺乏直接和显式地解决类别不平衡的机制
- FRAME不需要数据分布信息，也不需要复杂的参数调优

### 4.7 讨论与局限性

**局限性**：

1. **质心数量的选择**：当前使用试错法确定每个类别的最优质心数。未来可开发自适应方法，根据数据分布或任务需求自动优化质心数。
2. **大规模类别场景**：模型尚未在ImageNet级别的海量类别数据集上验证。在多类别场景下，不同类别的质心可能趋于收敛，降低模型效果。
3. **距离度量**：当前使用欧氏距离。未来可探索更复杂的距离度量，如马氏距离（Mahalanobis distance）或基于核的方法。

## 五、总结

FRAME是一个通用且理论上有保证的潜在空间特征矫正框架，用于解决多种经典类别不平衡学习问题。其核心思想可以概括为"**先映射、再矫正、后分类**"：

1. **先映射**：利用嵌入网络将原始数据从原始空间映射到潜在特征空间
2. **再矫正**：利用自注意力机制在潜在空间中为每个类别学习多个代表性质心，实现特征层面（而非数据层面）的平衡
3. **后分类**：使用基于距离的分类器，根据样本到各质心的距离进行分类

FRAME的优雅之处在于其**通用性**：通过简单地扩展质心聚合策略，即可无缝应用于全监督、半监督和联邦学习三种范式，且在各种场景下都展示出对噪声和缺失值的强鲁棒性。理论分析证明了其对类别不平衡、缺失值和噪声的鲁棒性具有严格的数学保证。

**未来方向**包括：标签噪声学习、开放集识别、不完整信息学习，以及分布不一致问题（如领域自适应和迁移学习）中的应用。
