# SMOM 方向选择概率的核心流程

## 一句话本质

SMOM 不像 SMOTE 那样从 $k$ 个近邻中**随机**选方向生成合成样本，而是先算每个方向的"安全分"（选择权重），再按安全分高低**加权随机**选择方向——越安全的方向越容易被选中。

---

## 整体计算顺序（四阶段流水线）

```
阶段一：准备近邻信息（对所有 xi ∈ Sc）
    │
    ▼
阶段二：NBDOS 聚类 → 区分优良/困境实例
    │
    ▼
阶段三：仅为困境实例计算方向选择权重（三步走）
    │
    ▼
阶段四：权重归一化为概率 → 加权采样生成样本
```

---

## 阶段一：准备近邻信息

对每个类 $c$ 的实例 $x_i$，算三样东西：

| 计算结果 | 含义 | 用途 |
|----------|------|------|
| $x_i.N_{k_1}^c$ | 类 $c$ 内的 $k_1$ 个最近邻 | 候选方向池（往哪些方向生成） |
| $x_i.r_{k_1}$ | 到第 $k_1$ 近邻的距离 | 画一个"候选圈"，圈内才值得关注 |
| $x_i.F_s$ | 所有类中距离 $\leq x_i.r_{k_1}$ 的实例 | 第一轮过滤，缩小后续计算范围 |

---

## 阶段二：NBDOS 聚类分两类

用跨类别的 $x_i.N_{k_2}$ 判断每个 $x_i$ 处于什么环境：

- **优良实例 $Oi_c$**：位于类 $c$ 主导的"安全区"，周围主要是同类实例
- **困境实例 $Ti_c$**：处于多类混杂的"边界区"，周围有其他类侵入

> 优良实例 → 跳过阶段三，阶段四直接均匀随机选方向（反正哪都安全）
> 困境实例 → 进入阶段三，精打细算每个方向的安全性

---

## 阶段三：计算方向选择权重（核心）

为困境实例 $x_i$ 的每个候选方向 $x_i x_j$（$x_j \in x_i.N_{k_1}^c$），逐个计算权重。分**三种情况**，按优先级判断：

### 优先级判断流程

```
对每个 xj ∈ xi.N_k1^c：
    │
    ├── xj 是优良实例 且 xi 不是 xj 的近邻？
    │       ↓ 是
    │   直接给满分：sw = 1 + w1/e
    │   （解释：xi 紧挨着安全区，这个方向很干净）
    │
    ├── xi 是 xj 的近邻，且 xj 那边已算过 sw(xi)？
    │       ↓ 是
    │   直接复用：sw(xj) = sw(xi)
    │   （解释：xi→xj 和 xj→xi 是同一个 PN 邻域，不用重算）
    │
    └── 以上都不满足？
            ↓
        走通用计算路径（以下三步）
```

### 通用计算路径（情况 5.3）

```
第一步：第二轮过滤
    xi.Ss(xj) = { 从 xi.Fs 中再筛出距离 ≤ dist(xi, xj) 的实例 }
    效果：把考察范围进一步缩小到"比 xj 更近"的区域

第二步：dPN 精确定位
    NPN = { xi.Ss(xj) 中落在 PN 邻域内的实例 }
    PN 邻域 = 以 xi 和 xj 连线中点为球心、半距为半径的超球
```

## 一句话本质

SMOM 与 SMOTE 的根本区别：SMOTE 从 $k$ 个近邻中**随机均匀**选方向生成合成样本；SMOM 则先给每个方向算一个"安全性评分"（选择权重），再**按分加权随机**选择——安全的方向更可能被选中，危险的方向被抑制。

```
阶段一：备料 ──→ 阶段二：分类 ──→ 阶段三：算分 ──→ 阶段四：采样
 (近邻信息)      (优良/困境)      (选择权重)      (加权生成)
```

## 阶段一：备料——算近邻信息

对当前少数类 $c$ 的每个实例 $x_i$，算三样东西：

| 计算结果 | 怎么算 | 干嘛用 |
|----------|--------|--------|
| $x_i.N_{k_1}^c$ | 在类 $c$ 内找 $k_1$ 个最近邻 | 候选方向池 |
| $x_i.r_{k_1}$ | $x_i$ 到第 $k_1$ 近邻的距离 | 画候选圈半径 |
| $x_i.F_s$ | 所有类中，距离 $\leq r_{k_1}$ 的实例 | 第一轮过滤，圈外不管 |

> 直觉：以 $x_i$ 为圆心、到第 $k_1$ 个同类邻居的距离为半径画一个圈。**圈内**的实例才值得关心，圈外的太远，不影响 $x_i$ 的安全性判断。

---

## 阶段二：分类——NBDOS 聚类区分优良/困境

用跨类别的 $x_i.N_{k_2}$ 判断每个 $x_i$ 的环境：

| 类型 | 判定条件 | 含义 |
|------|----------|------|
| **优良实例** $Oi_c$ | 聚类标签 $\neq 0$（位于类 $c$ 主导区域） | 周围都是自己人，随便往哪生成都安全 |
| **困境实例** $Ti_c$ | 聚类标签 $= 0$（处于多类混杂边界） | 周围有其他类，需要精挑细选方向 |

> 优良实例**跳过阶段三**，直接进入阶段四均匀随机采样。只有困境实例才需要走阶段三的算分流程。

---

## 阶段三：算分——方向选择权重（核心）

### 3.1 总体思路

对困境实例 $x_i$ 的每个候选方向 $x_i x_j$（$x_j \in x_i.N_{k_1}^c$），逐一打分。打分依据是：**沿这个方向生成合成样本，对周围其他类（尤其是其他少数类）会造成多大困扰？**

核心工具：**PN 邻域** = 以 $x_i$ 和 $x_j$ 连线中点为球心、半距为半径的超球。用它近似替代"沿这个方向生成样本会落入的区域"。

### 3.2 三种情况的优先级判断

对每个 $x_j \in x_i.N_{k_1}^c$，按以下优先级判定：

```
优先级 1：xj 是优良实例 且 xi 不是 xj 的近邻？
    → 是：直接给满分，sw = 1 + w1/e
      含义：xi 紧挨安全区，往这个方向走很快就会进入"自己人地盘"
      
优先级 2：xi 是 xj 的近邻，且 xj→xi 方向已经算过了？
    → 是：直接复用，sw(xi→xj) = sw(xj→xi)
      含义：xi→xj 和 xj→xi 是同一个 PN 邻域，不重复算

优先级 3：以上都不满足
    → 走通用计算路径（3.3）
```

### 3.3 通用计算路径

```
第二步过滤：从 xi.Fs 中再筛出距离 ≤ dist(xi, xj) 的 → xi.Ss(xj)
    效果：把考察范围从"候选圈"缩小到"比 xj 更近的区域"
          ↓
dPN 精确定位：从 xi.Ss(xj) 中找出落在 PN 邻域内的实例 → NPN
          ↓
套公式 (2)：统计 NPN 中各类实例的分布 → 算出 sw
```

### 3.4 公式 (2) 的直观理解

公式 (2) 的输出是一个实数 $sw$。在做**相对比较**时（归一化），$sw$ 越大，该方向被选中的概率越高。

判断一个方向好不好的原则：**PN 邻域里其他类的实例越少、越单一 → 越安全 → sw 应该越高**。

具体看 PN 邻域里三个指标：

| 邻域特征 | 越安全的表现 | 越危险的表现 |
|----------|-------------|-------------|
| 其他少数类占比 $\tau_{mi}/\tau_c$ | 占比低 | 占比高（容易干扰其他少数类） |
| 少数类熵 $E_{mi}$ | 熵低（少数类种类少且集中） | 熵高（多个少数类均匀分布，概念模糊） |
| 多数类占比（由 $w_2$ 调低权重） | 占比低 | 占比高（但影响小于少数类） |

同时考虑**学习难度**：邻域里类 $c$ 的实例越稀疏 → 越需要合成样本 → 难度因子越大。

### 3.5 特例：全脏方向兜底（Step 6.1）

如果 $x_i$ 的所有 $k_1$ 个方向都经过了 PN 邻域且**没有一个邻域是纯类 $c$ 的**（即 $x_i$ 可能是噪声点），则：

- 把 $x_i$ **自己**加入候选方向，给满分 $sw = 1 + w_1/e$
- 含义：既然往哪走都不安全，干脆原地生成（类似复制），减少对外扩散的伤害

---

## 阶段四：归一化 → 加权采样 → 生成

### 4.1 归一化

对每个困境实例 $x_i$，把 $k_1$ 个方向的 $sw$ 值转成概率分布：

$$
x_i.P(x_j) = \frac{x_i.sw(x_j)}{\sum_{x_l \in x_i.N_{k_1}^c} x_i.sw(x_l)}
$$

- 满分方向（$1 + w_1/e$）在归一化后概率显著偏高
- 低分方向（邻域杂乱的）概率被压低

### 4.2 加权采样生成

| 实例类型 | 采样方式 | 原因 |
|----------|----------|------|
| 优良实例 $Oi_c$ | 均匀随机选方向 | 哪都安全，无需区分 |
| 困境实例 $Ti_c$ | 按 $x_i.P$ 加权随机选方向 | 安全方向优先，危险方向抑制 |

选定方向后，用标准 SMOTE 公式生成：

$$
si = x_i + (x_j - x_i) \odot \alpha, \quad \alpha \in [0,1]
$$

## 一句话总结

**优良实例随便选方向，困境实例按"哪个方向更安全"加权选方向——安全的优先，危险的靠边。这就是 SMOM 避免过度泛化的全部秘密。**
