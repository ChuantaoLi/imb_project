#### 模型关注的问题

1. 类别数量不平衡：多数类样本量远大于少数类，分类器优化整体准确率时天然偏向多数类，少数类的决策边界被挤压。
2. 类别重叠：不同类别的样本在特征空间中相互交错，边界区域存在类别歧义。现有研究证明，不平衡只在与其他困难因素，尤其是重叠结合时才真正损害分类性能。
3. 噪声与离群点：数据中存在标签噪声或远离任何类主体的离群点。过采样方法在这些点上生成合成样本会放大噪声效应；欠采样方法无法区分真正的多数类边界样本和错误标注样本。
4. 孤立子簇与类内不平衡：少数类样本并非均匀分布，而是形成多个孤立的小子簇。这些子簇远离少数类主体，但又不足以独立成类。分类器要么将其误分为多数类，要么过拟合到这些稀疏点。
5. 多类关系复杂：从二分类扩展到多分类时，类别间的关系不再简单地是"多数 vs 少数"，而是同一个类可能相对于某些类是少数类、相对于另一些类是多数类。OVA 和 OVO 这种分解策略会丢失类别间关系信息。
6. 过采样过度泛化：传统基于 k-NN 插值的过采样方法在两个少数类样本之间生成新样本时，忽略了多数类的分布信息。如果这两个少数类样本之间的区域恰好穿过多数类密集区，生成的就是噪声。

#### 模型解决情况

1. 类别数量不平衡：代价自适应（DBCF 的平衡信息熵）、分布感知（GLOS 的 DID）、根据迭代情况自适应调节抽样方式（SPE 的自步因子）、多个抽样数据集训练（imDEF 的 OREM_G）。
2. 类别重叠：势函数定位边界（MC-RBO）、能量模型限制扩张（MC-CCR）、隶属度熵量化重叠（DEAHS）、CMR 候选区筛选（OREM-M）、平移清洗代替删除（MC-CCR）
3. 噪声与离群点：基于密度的噪声识别（NROMM 中的 CFSFDP 模块）、基于能量的自然抑制（MC-CCR 小半径自动低配额）、对生成样本进行后处理（QC-SMOTE）、全局 DI 检测（SHSampler）
4. 孤立子簇与类内不平衡：Safe/Borderline/Small Disjunct 样本区域划分策略（GLOS）、内陆/边界/陷落样本区域划分策略（NROMM）、突出/困陷实例样本区域划分策略（SMOM）、改进的 KL 散度保持子簇结构（ILMNN）、
5. 多类关系复杂：类别相似度矩阵（SOUP）、DI/SI 全局关系（SHSampler）、多类熵感知权重（SMOM）、选择权重规避少数类间侵入（SMOM）、迭代抑制少数类间新重叠（OREM-M）
6. 过采样过度泛化：凸包区域生成样本（EB-SMOTE）、势函数引导替代随机插值（MC-RBO）、马氏距离保持分布形状（MDO）、IPQ 候选择优替代单次生成（QC-SMOTE）、选择权重风险评估替代均匀采样（SMOM）

#### 模型局限性

1. 生成质量与计算成本失衡：许多方法需要对两两样本进行距离计算，尽管可以通过近邻简化，但时间复杂度过高的模型无法推广到如网络入侵检测等大规模数据集场景中。
2. 对特征空间几何的过度简化：绝大多数方法依赖欧氏距离，类别重叠问题导致特征空间复杂。此外，对于样本区域的划分有些模型考虑得过于单一，仅依赖于距离度量难以准确刻画样本分布。
3. 数据采样不应只依赖于静态数据本身：许多过采样或欠采样模块均只在样本关系上计算和判断，像集成学习方法需要考虑基学习器的分类性能。此外，通过聚类方法确定簇中心也是基于静态数据计算的，可以考虑使用算法级的模块进行簇中心学习。
